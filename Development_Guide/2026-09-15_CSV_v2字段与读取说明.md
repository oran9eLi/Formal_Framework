# CSV v2 字段与读取说明

适用：`release/v1.0` 的 M2 日志实现。用于课堂传感器记录分析；实板导出和外部解析工具的适配在 M4 验收。

## 文件与兼容

- 数据文件改为 `YYMMDD_2.CSV`，未同步日期时为 `UNSYNC_2.CSV`，仍符合 FAT 8.3 文件名要求。
- 旧版 `_D.CSV` 保留，升级后的数据不追加到旧表头下。事件文件仍为 `_E.CSV`，未同步时为 `UNSYNC_E.CSV`。
- 每行共 **49 列**：原来的 36 列顺序和单位保持，末尾增加 13 列；`schema_version=2`。
- 读取器必须按表头名称取列，并检查版本与各域状态。固定 36 列或只匹配 `_D.CSV` 的工具需要更新。
- 仓库内已搜索 Python、Shell、PowerShell、Notebook、MATLAB 和 JavaScript 文件，未发现依赖此数据格式的可执行解析脚本；现有 SD 技术文档和 BME280 案例已增加本说明入口。外部工具尚未验证。

## 状态与样本时刻

| `*_state` | 含义 | 对应数据值 |
|---|---|---|
| 0 | 尚无快照 | 占位零值，不能参与测量统计 |
| 1 | 快照有效位/必要字段不合法 | 占位零值，不能参与测量统计 |
| 2 | 样本超过最大龄期 | 占位零值，原样本时刻仍保留 |
| 3 | 有效且未超时 | 可用测量值，包括真实的零值 |

`time_ms` 是生成本行的运行毫秒时刻；`*_sample_ms` 是所属数据域的样本时刻。两者不能混作采样时间。相邻行可能记录同一个仍新鲜的样本：状态 3 不代表本行一定有新采样，需要同时比较样本时间。设备重启会重新计时，32 位毫秒计数也会回绕，跨重启记录应分段分析。

| 数据域 | 状态列 / 样本时间列 | 当前最大龄期 | 额外有效性要求 |
|---|---|---|---|
| GNSS | `gnss_state` / `gnss_sample_ms` | 1500 ms | 原始 GNSS 有效且有定位；不用 IMU 更新时间给旧定位续期 |
| 姿态 | `attitude_state` / `attitude_sample_ms` | 200 ms | Navigation 的姿态有效位存在 |
| 温湿压 | `baro_state` / `baro_sample_ms` | 2500 ms | 温度 −100～150°C、气压 0～200000 Pa（不含端点）、湿度 0～100%；排除 NaN/无穷 |
| 主电池 | `battery_state` / `battery_sample_ms` | 2500 ms | 原快照有效位 |
| 动力电池 | `battery2_state` / `battery2_sample_ms` | 2500 ms | 原快照有效位 |
| 电机 | `motor_state` / `motor_sample_ms` | 500 ms | 原输出快照有效位 |

数值范围检查用于拒绝明显非法数据，不等于传感器精度认证。状态判断优先顺序是缺测、无效、过期、有效。

## 字段顺序与单位

以下列号从 1 开始。源码表头的最终定义在 `Storage/Src/storage_csv.c`。

| 列号 | 字段 | 单位或含义 |
|---|---|---|
| 1–4 | `time_ms,local_date,local_time,time_sync_state` | ms、YYYYMMDD、HHMMSS、时间同步枚举 |
| 5–7 | `gnss_valid,lat_e7,lon_e7` | 位置可用标志、纬度×10⁷、经度×10⁷ |
| 8–10 | `roll_deg,pitch_deg,yaw_deg` | 度；测量姿态，未扣本机屏幕相对基准；yaw 为相对偏航 |
| 11–13 | `temp_c,pressure_hpa,humidity_pct` | °C、hPa、%RH |
| 14–18 | `voltage_v,current_a,power_w,battery_pct,low_voltage` | V、A、W、%、低压标志 |
| 19–23 | `voltage2_v,current2_a,power2_w,battery2_pct,low_voltage2` | 动力电池，单位同上 |
| 24–28 | `motor1_pct,motor2_pct,motor3_pct,motor4_pct,motor_run_state` | 四路输出油门百分比、运行状态；不是转速测量 |
| 29–30 | `active_alarm_count,highest_fault_code` | 活动告警数量、最高严重度故障码 |
| 31–34 | `lora_rx_count,lora_tx_count,lora_parse_error_count,lora_send_error_count` | 接收/发送完成/解析错误/发送错误累计次数 |
| 35–36 | `storage_queue_count,storage_drop_count` | 队列占用、累计丢弃次数 |
| 37 | `schema_version` | 固定为 2 |
| 38–39 | `gnss_state,gnss_sample_ms` | 状态、ms |
| 40–41 | `attitude_state,attitude_sample_ms` | 状态、ms |
| 42–43 | `baro_state,baro_sample_ms` | 状态、ms |
| 44–45 | `battery_state,battery_sample_ms` | 状态、ms |
| 46–47 | `battery2_state,battery2_sample_ms` | 状态、ms |
| 48–49 | `motor_state,motor_sample_ms` | 状态、ms |

告警和通信/队列计数是运行元数据，不属于上述六个测量域的有效性列。不能用 `baro_state` 判断整行有效或无效。

## 课堂读取步骤

1. 打开 `_2.CSV`，确认 `schema_version` 为 2。
2. 分析温度时筛选 `baro_state=3`；保留 `baro_sample_ms` 作为采样横轴。同一样本时刻的重复记录按实验目的去重。
3. 遇到温度 0 时先查状态：3 表示真实 0°C；0/1/2 表示没有可用测量。
4. 断开传感器，观察状态变化；恢复后核对样本时间继续更新。不要把占位零值连成温度突然下降的曲线。
5. 地平仪相对归零不会改变 CSV 的测量姿态。分析报告应分别记录“测量角度”和“学生选择的显示基准”。
