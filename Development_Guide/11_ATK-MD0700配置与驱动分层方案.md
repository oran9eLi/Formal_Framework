# ATK-MD0700 配置与驱动分层方案

## 1. 已确认硬件

```text
MCU: STM32F407ZGT6
Display: 正点原子 ATK-MD0700 7寸 TFTLCD
Resolution: 800 x 480
LCD bus: FSMC 8080 16-bit
LCD controller: SSD1963 类控制器，原工程 PID 期望值 0x61
Touch: GT911 电容触摸
Touch bus: 软件 I2C
Backlight: 独立 GPIO/PWM 资源
```

RGB565 全屏数据量：

```text
800 x 480 x 2 = 768000 bytes
```

STM32F407ZGT6 内部 SRAM 无法容纳全屏帧缓冲，正式方案使用 LCD 内部
GRAM、局部刷新和小型固定行缓冲。STM32F407 不使用 DMA2D。

## 2. 统一管理原则

外设配置统一从 `bsp_config.h` 管理，但配置、MCU资源初始化和设备协议必须
分层。

```text
bsp_config.h
  -> HAL MSP
  -> BSP Init
  -> SSD1963 / GT911 Driver
  -> Display Renderer
  -> DisplayTask
```

### 2.1 `bsp_config.h`

负责回答：

- 外设是否启用。
- 使用哪个模块和控制器。
- 使用哪个 MCU 外设实例。
- 引脚、复用、DMA、中断和 FSMC Bank 分配。
- 默认运行参数和可调整参数常量。

建议配置形式：

```c
#define BSP_DISPLAY_ENABLE                 1U
#define BSP_DISPLAY_MODEL_ATK_MD0700       1U
#define BSP_DISPLAY_CONTROLLER_SSD1963     1U
#define BSP_DISPLAY_USE_FSMC_8080          1U
#define BSP_DISPLAY_BUS_WIDTH_BITS        16U

#define BSP_DISPLAY_WIDTH                800U
#define BSP_DISPLAY_HEIGHT               480U
#define BSP_DISPLAY_PIXEL_FORMAT_RGB565    1U

#define BSP_TOUCH_ENABLE                   1U
#define BSP_TOUCH_CONTROLLER_GT911         1U
#define BSP_TOUCH_USE_SOFT_I2C              1U
```

`bsp_config.h` 可以定义 FSMC Bank、地址线、GPIO、默认时序参数，但不得
执行初始化，也不得包含 SSD1963 初始化命令序列。

### 2.2 `stm32f4xx_hal_conf.h`

只启用 STM32 HAL 模块：

```c
#if BSP_DISPLAY_ENABLE
#define HAL_SRAM_MODULE_ENABLED
#endif
```

不得放入：

- LCD 命令和数据读写函数。
- SSD1963 初始化命令。
- GT911 软件 I2C 时序。
- 页面绘制和刷新逻辑。

### 2.3 HAL MSP

MSP 负责把已选择的资源连接到 MCU：

- 开启 FSMC、GPIOD、GPIOE、GPIOF、GPIOG 时钟。
- 配置 D0-D15、NE4、A6、NOE、NWE 的复用功能。
- 配置触摸 SCL、SDA、INT、RST GPIO 基础模式。
- 配置背光引脚或 PWM 定时器资源。
- 对应 DeInit 负责资源释放。

MSP 不设置 SSD1963 分辨率、像素格式或显示时序。

### 2.4 BSP Init

BSP 初始化时才设置运行参数：

- FSMC 16位数据宽度。
- 读写时序 `AddressSetupTime`、`DataSetupTime` 等。
- Memory Bank 和扩展写时序。
- LCD 命令/数据映射地址。
- 软件 I2C 延时参数。
- 背光初始状态或 PWM 占空比。

建议接口：

```c
typedef struct
{
    uint32_t bank;
    uint32_t address_setup;
    uint32_t data_setup_read;
    uint32_t data_setup_write;
    uint8_t bus_width_bits;
} BSP_LcdFsmcConfig_t;

Result_t BSP_LcdFsmc_Init(const BSP_LcdFsmcConfig_t *config);
void BSP_Lcd_WriteCommand(uint16_t command);
void BSP_Lcd_WriteData(uint16_t data);
uint16_t BSP_Lcd_ReadData(void);
```

默认参数可以来自 `bsp_config.h`，BSP Init 将其填入 HAL/FSMC 初始化结构。

### 2.5 Device Driver

`display_ssd1963.c` 负责：

- 读取和验证控制器 ID。
- SSD1963 PLL、LCD 时序和像素接口配置。
- 设置 800 x 480、RGB565 和显示方向。
- 设置写入窗口、写 GRAM、清屏和局部区域写入。

`display_gt911.c` 负责：

- GT911 复位和地址选择时序。
- 读取产品 ID、分辨率和触摸点。
- 校验、坐标转换和触摸事件生成。

设备驱动通过 BSP 接口访问硬件，不直接重复配置 GPIO/FSMC。

## 3. DisplayTask 所有权

```text
其他任务
  -> 发布完整 ViewModel / Touch Command
  -> DisplayTask
  -> Renderer
  -> SSD1963 Driver
  -> BSP FSMC
```

强制规则：

1. DisplayTask 是 FSMC LCD 唯一写入者。
2. GNSS、Alarm、Health 等任务不得直接调用绘图函数。
3. 页面数据先复制成完整 ViewModel，再开始刷新。
4. 一次控件刷新使用同一个 ViewModel 版本。
5. 新数据在刷新期间到达时，保留为下一版本。
6. 禁止在任务栈或静态区分配 768000 字节全屏帧缓冲。
7. 使用脏矩形、小型行缓冲和分步刷新预算。

## 4. 推荐实现顺序

1. 将 ATK-MD0700、FSMC、GT911 和背光资源加入 `bsp_config.h`。
2. 在 HAL 配置中只启用 SRAM/FSMC 所需 HAL 模块。
3. 在 MSP 中实现 FSMC、触摸和背光 GPIO 资源配置。
4. 实现 `bsp_lcd_fsmc.*`，初始化时填写 FSMC 参数。
5. 实现 `display_ssd1963.*` 和 LCD ID/纯色测试。
6. 实现 `display_gt911.*` 和触摸坐标测试。
7. 实现 ViewModel、Renderer、脏矩形和 DisplayTask。
8. 最后接入导航、传感器、告警和系统页面。

## 5. Debug 预留

Display 调试使用独立宏：

```c
#define DEBUG_DISPLAY_MONITOR_ENABLE  0U
```

可输出：

- LCD ID 和初始化结果。
- 单次局部刷新耗时及历史最大值。
- 刷新次数、超预算次数和丢弃版本数。
- GT911 触摸中断、有效触摸和 I2C 错误计数。
- DisplayTask 栈峰值和全局 Heap 使用情况。
