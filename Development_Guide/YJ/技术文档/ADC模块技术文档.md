# ADC 模块技术文档

## 1. 模块定位

ADC 模块用于采集电池电压并估算电量百分比。当前工程使用开发板 PA5 对应的 `ADC1_IN5`，外部接飞控电流计的 `VOLT` 输出，电流计 `GND` 与开发板 `GND` 共地。

正式数据链路如下：

```text
电池
  -> 飞控电流计 VOLT 分压输出
  -> PA5 / ADC1_IN5
  -> BSP_ADC
  -> Sensor_Power
  -> Battery Topic
  -> Display / MAVLink / Storage / Business
```

## 2. 硬件连接

| 信号 | 连接 |
|---|---|
| 电流计 GND | 开发板 GND |
| 电流计 VOLT | 开发板 ADC/PA5 |
| 电流计 CURR | 当前未接入 |
| 电流计 5V | 当前不接入 PA5 |

注意事项：

- PA5 只能输入 0 到 3.3V，不能直接接 10V 到 12V 电池。
- 必须使用电流计 `VOLT` 这类已经分压后的电压信号。
- 电池同时给电流计和开发板供电时，读数比空载电池电压低约 0.2V 属正常范围，属于线材、接头、负载和共地压降造成的工作状态压降。
- 校准应以开发板工作时电源输入口处电压为基准。

## 3. 当前配置

| 项目 | 当前值 |
|---|---|
| ADC 外设 | ADC1 |
| ADC 通道 | ADC_CHANNEL_5 |
| 引脚 | PA5 |
| 参考电压 | 3300 mV |
| ADC 分辨率 | 12 bit |
| 平均次数 | 8 次 |
| 分压比例 | `10080 / 1000` |
| 采集周期 | 1000 ms |
| 所属任务 | `sensor` |

关键配置位于 `Bsp/Inc/bsp_config.h`：

```c
#define BSP_ADC_DIVIDER_NUM       10080U
#define BSP_ADC_DIVIDER_DEN       1000U
```

## 4. 电压计算

BSP 层读取 ADC 原始值后，先换算 PA5 引脚电压，再乘以外部分压比例得到电池电压：

```text
pin_mv = raw * 3300 / 4095
voltage_mv = pin_mv * 10080 / 1000
```

Sensor 层保存 `Power_Snapshot_t`：

| 字段 | 单位 | 说明 |
|---|---|---|
| `voltage_v` | V | 电池电压 |
| `percent` | % | 电量百分比 |
| `low_voltage` | 0/1 | 低电压标志 |
| `sample_time_ms` | ms | 采样时间 |
| `rx_sequence` | 次 | 成功采样序号 |
| `error_count` | 次 | ADC 读取错误计数 |

## 5. 电量显示规则

当前电量显示按用户实测电池范围设置：

| 电压范围 | 电量显示 |
|---|---|
| `< 9.9V` | 0% |
| `9.9V <= V < 10.2V` | 5% |
| `10.2V <= V < 10.5V` | 10% |
| `>= 12.55V` | 100% |
| `10.5V <= V < 12.55V` | 从 10% 到 100% 线性换算后按 5% 档位显示 |

为了避免电量在临界点来回跳变，模块采用两级稳定处理：

1. 电压滤波：`3/4` 旧值 + `1/4` 新值。
2. 档位确认：候选电量档位必须连续 10 次进入新档位才更新显示。

因此电压仍保持较细精度输出，电量百分比则稳定在 5% 档位。

## 6. 异常与恢复

- `BSP_ADC_ReadVoltageMv()` 失败时，`error_count` 增加。
- Battery 模块的 OFFLINE 由 Health 根据超时统一判断。
- `Sensor_Power_RequestReinit()` 只设置请求标志，实际初始化在下一次 Service 中执行。

## 7. 验收要点

- 使用电流计 `VOLT -> PA5` 后，ADC 显示应接近电池工作状态电压。
- 如果单独测试准确、同时供电偏低约 0.2V，优先检查负载压降和共地，不直接改软件比例。
- 电量显示必须满足 9.9V 以下 0%、9.9V 到 10.2V 为 5%、10.2V 到 10.5V 为 10%、12.55V 以上 100%。
- 电量必须按 5% 档位显示，且连续 10 次确认后才换档。
- 当前只测电压，`CURR` 电流信号尚未接入。
