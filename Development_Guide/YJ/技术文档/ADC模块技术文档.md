# ADC 模块技术文档

## 1. 模块定位

ADC 模块用于采集电池电压并估算电量百分比。当前工程使用开发板 PA5 对应的 `ADC1_IN5`，外部接飞控电流计的 `VOLT` 输出，电流计 `GND` 与开发板 `GND` 共地。

正式数据链路如下：

```text
电池
  -> 飞控电流计 VOLT 分压输出
  -> PA5 / ADC1_IN5
  -> BSP_ADC
  -> Sensor_Power
  -> Battery Topic
  -> Display / MAVLink / Storage / Business
```

## 2. 硬件连接

| 信号 | 连接 |
|---|---|
| 电流计 GND | 开发板 GND |
| 电流计 VOLT | 开发板 ADC/PA5 |
| 电流计1 CURR | PC0 / ADC3_IN10，第一电池电流采样 |
| 电流计2 CURR | PC1 / ADC3_IN11，第二电池电流采样 |
| 电流计 5V | 不接入 PA4/PA5/PC0/PC1；是否作为供电输出需按硬件方案单独确认 |

注意事项：

- PA5 只能输入 0 到 3.3V，不能直接接 10V 到 12V 电池。
- 必须使用电流计 `VOLT` 这类已经分压后的电压信号。
- 电池同时给电流计和开发板供电时，读数比空载电池电压低约 0.2V 属正常范围，属于线材、接头、负载和共地压降造成的工作状态压降。
- 校准应以开发板工作时电源输入口处电压为基准。

### 3.1 电流采样配置

两块 12.6V 电池各串联一块无人机 Power Module 电流计，每块电流计只测对应电池的总输出电流。

| 对象 | ADC 外设 | ADC 通道 | 引脚 | 数据含义 |
|---|---|---|---|---|
| 第一电池电流 | ADC3 | ADC_CHANNEL_10 | PC0 | 开发板、传感器和外设总电流 |
| 第二电池电流 | ADC3 | ADC_CHANNEL_11 | PC1 | 四个无刷电机动力总电流 |

BSP 层新增 `bsp_adc_current`，只负责 PC0/PC1 原始 ADC 采样和 ADC 引脚电压 mV 换算。电流计零点、`mV/A` 比例、死区、滤波和功率计算均在 Sensor Power 层完成。

默认配置为 `0A = 0mV`、`100mV/A`，仅作为软件占位值。实物接线后必须按电流计实际输出标定。

## 4. 电压与电流计算

BSP 层读取 ADC 原始值后，先换算 PA5 引脚电压，再乘以外部分压比例得到电池电压：

```text
pin_mv = raw * 3300 / 4095
voltage_mv = pin_mv * 10080 / 1000
```

Sensor 层保存 `Power_Snapshot_t`：

| 字段 | 单位 | 说明 |
|---|---|---|
| `voltage_v` | V | 电池电压 |
| `current_ma` | mA | 电池电流；PC0/PC1 采样失败时保持 0 |
| `power_mw` | mW | 电池功率，由电压和电流计算 |
| `percent` | % | 电量百分比 |
| `low_voltage` | 0/1 | 第一电池低电压标志，按 10.3V/10.5V 回差连续确认 |
| `sample_time_ms` | ms | 采样时间 |
| `rx_sequence` | 次 | 成功采样序号 |
| `error_count` | 次 | ADC 读取错误计数 |

## 5. 电压校准与电量显示规则

Sensor 层在 BSP 分压换算之后增加二次校准，配置集中在 `Sensor/Inc/sensor_power_config.h`：

| 配置项 | 默认值 | 说明 |
|---|---|
| `POWER_CAL_GAIN_NUM / POWER_CAL_GAIN_DEN` | `1000 / 1000` | 电压比例校准，默认不改变读数 |
| `POWER_CAL_OFFSET_MV` | `0` | 电压固定偏移，单位 mV，可为负值 |
| `POWER_LOAD_COMPENSATION_ENABLE` | `0` | 是否启用负载压降补偿 |
| `POWER_LOAD_COMPENSATION_MV` | `200` | 负载补偿值，单位 mV，默认按约 0.2V 预留 |

当前电量显示按用户实测电池范围设置为曲线表：

| 电压点 | 电量显示 |
|---|---|
| `<= 9.90V` | 0% |
| `10.20V` | 5% |
| `10.50V` | 10% |
| `10.80V` | 20% |
| `11.10V` | 30% |
| `11.40V` | 40% |
| `11.70V` | 50% |
| `11.95V` | 60% |
| `12.15V` | 70% |
| `12.30V` | 80% |
| `12.45V` | 90% |
| `>= 12.55V` | 100% |

曲线点之间使用线性插值，最终结果仍按 5% 档位四舍五入显示。

为了避免电量在临界点来回跳变，模块采用两级稳定处理：

1. 电压滤波：`3/4` 旧值 + `1/4` 新值。
2. 档位确认：候选电量档位必须连续 10 次进入新档位才更新显示。

因此电压仍保持较细精度输出，电量百分比则稳定在 5% 档位。

第二电池动力电池曲线为：

| 电压点 | 电量显示 |
|---|---|
| `<= 10.50V` | 0% |
| `10.55V` | 5% |
| `10.65V` | 10% |
| `10.80V` | 20% |
| `10.95V` | 30% |
| `11.10V` | 40% |
| `11.30V` | 50% |
| `11.50V` | 60% |
| `11.75V` | 70% |
| `12.00V` | 80% |
| `12.30V` | 90% |
| `>= 12.60V` | 100% |

第二电池低压预警使用滤波电压和连续确认：低于 `10.80V` 连续确认后置位 `low_voltage2`，高于 `11.00V` 连续确认后清除，避免四个无刷电机负载瞬态导致告警跳变。

第一电池低压预警同样使用滤波电压和连续确认：低于 `10.30V` 连续确认后置位 `low_voltage`，高于 `10.50V` 连续确认后清除，避免开发板电池在临界电压附近因 ADC 抖动或负载瞬态反复告警。

## 6. 异常与恢复

- `BSP_ADC_ReadVoltageMv()` 失败时，`error_count` 增加。
- Battery 模块的 OFFLINE 由 Health 根据超时统一判断。
- `Sensor_Power_RequestReinit()` 只设置请求标志，实际初始化在下一次 Service 中执行。

## 7. 验收要点

- 使用电流计 `VOLT -> PA5` 后，ADC 显示应接近电池工作状态电压。
- 如果单独测试准确、同时供电偏低约 0.2V，优先检查负载压降和共地，不直接改软件比例。
- 第一电池电量显示必须满足 9.9V 及以下为 0%、10.2V 为 5%、10.5V 为 10%、12.55V 及以上为 100%；低压预警按 10.3V/10.5V 回差连续确认。
- 第二电池电量显示必须满足 10.5V 及以下为 0%、10.8V 为 20%、12.60V 及以上为 100%，低压预警按 10.8V/11.0V 回差连续确认。
- 电量必须按 5% 档位显示，且连续 10 次确认后才换档。
- 电流计 `CURR` 已接入：第一电池为 PC0 / ADC3_IN10，第二电池为 PC1 / ADC3_IN11。
- `CURR` 最大输出电压必须小于等于 3.3V；若电流计输出为 0 到 5V，必须外部分压后再接入 PC0/PC1。
- 电流显示必须经过实物标定，重点确认 0A 零点和每 1A 对应的 ADC mV 变化。
