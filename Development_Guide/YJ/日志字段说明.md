# 日志字段说明

本文档用于解释 SD 卡日志中的 CSV 字段、模块名称、状态值和故障码。当前日志分为两类：

- `YYMMDD_D.CSV`：DATA 数据日志，按周期记录传感器和系统状态，例如 `260622_D.CSV`。
- `YYMMDD_E.CSV`：EVENT 事件日志，只在异常触发、状态恢复或关键事件发生时记录，例如 `260622_E.CSV`。
- `UNSYNC_D.CSV` / `UNSYNC_E.CSV`：RTC/GNSS 日期尚未有效时的兜底文件；时间有效后自动切换到按日期命名的文件。

## 通用时间字段

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| `time_ms` | 板子本次开机后的运行时间，单位 ms；重启后从 0 重新开始。 | `1192` 表示开机后 1.192 秒 |
| `local_date` | 本地日期，格式 `YYYYMMDD`。 | `20260622` |
| `local_time` | 本地时间，格式 `HHMMSS`。 | `154727` 表示 15:47:27 |

## EVENT 日志字段

| 字段 | 含义 |
| --- | --- |
| `event_type` | 事件类型。`ALARM_ACTIVE` 表示异常触发；`STATUS_RECOVERED` 表示模块恢复在线。 |
| `source` | 事件来源模块，例如 `IMU`、`BARO`、`STORAGE`。 |
| `state` | 当前模块状态，见“状态值对照表”。 |
| `fault` | 当前故障码，见“故障码对照表”；恢复事件为 `0`。 |
| `severity` | 严重度，见“严重度对照表”；恢复事件为 `0`。 |
| `active` | `1` 表示异常处于触发状态；`0` 表示状态恢复。 |
| `count` | 同类事件累计触发次数。 |
| `message` | 事件说明，例如 `imu_offline`、`storage_queue_drop`。 |

## DATA 日志字段

| 字段 | 含义 |
| --- | --- |
| `time_sync_state` | 时间同步状态，由时间服务定义。 |
| `gnss_valid` | GNSS 位置是否有效，`1` 有效，`0` 无效。 |
| `lat_e7` / `lon_e7` | 经纬度，单位为 degree * 1e7。 |
| `roll_deg` | 横滚角，单位 degree。 |
| `pitch_deg` | 俯仰角，单位 degree。 |
| `yaw_deg` | MPU6050 姿态估计得到的相对偏航角，单位 degree。 |
| `temp_c` | BME280 温度，单位摄氏度。 |
| `pressure_hpa` | BME280 气压，单位 hPa。 |
| `humidity_pct` | BME280 相对湿度，单位 %。 |
| `voltage_v` | 电池电压，单位 V。 |
| `current_a` | 第一电池电流，单位 A，来源为 PC0/ADC3_IN10 电流计输出。 |
| `power_w` | 第一电池功率，单位 W，由第一电池电压和电流计算。 |
| `battery_pct` | 电池电量百分比。 |
| `low_voltage` | 第一电池低电压标志；滤波电压低于 `10.30V` 连续确认后置 `1`，高于 `10.50V` 连续确认后恢复 `0`。 |
| `voltage2_v` | 第二电池电压，单位 V，来源为 PA4/ADC2 独立采样链路。 |
| `current2_a` | 第二电池电流，单位 A，来源为 PC1/ADC3_IN11 电流计输出。 |
| `power2_w` | 第二电池功率，单位 W，由第二电池电压和电流计算。 |
| `battery2_pct` | 第二电池电量百分比，使用动力电池独立曲线；`10.50V` 为 0%，`12.60V` 为 100%。 |
| `low_voltage2` | 第二电池低电压标志；滤波电压低于 `10.80V` 连续确认后置 `1`，高于 `11.00V` 连续确认后恢复 `0`。 |
| `motor1_pct` 到 `motor4_pct` | 四路电机目标油门百分比。 |
| `motor_run_state` | 电机输出状态。 |
| `active_alarm_count` | 当前活动告警数量。 |
| `highest_fault_code` | 当前最高优先级故障码。 |
| `lora_rx_count` / `lora_tx_count` | LoRa/MAVLink 接收和发送计数。 |
| `lora_parse_error_count` / `lora_send_error_count` | LoRa 解析和发送错误计数。 |
| `storage_queue_count` | Storage 队列当前待写记录数量。 |
| `storage_drop_count` | Storage 队列累计丢弃记录数量。 |

## 模块名称对照表

| source | 含义 |
| --- | --- |
| `GNSS` | 定位模块 |
| `IMU` | 姿态传感器，MPU6050 |
| `BARO` | 气压/环境模块，BME280 |
| `BATTERY` | 第一电池电压/电流/电量模块，PA5/ADC1 + PC0/ADC3 |
| `BATTERY2` | 第二电池电压/电流/电量模块，PA4/ADC2 + PC1/ADC3 |
| `LORA` | LoRa 通信模块 |
| `STORAGE` | SD 卡存储模块 |
| `DISPLAY` | 屏幕显示模块 |
| `NAV` | 导航/姿态 topic 数据源 |

## 状态值对照表

| state | 名称 | 含义 |
| --- | --- | --- |
| `0` | `UNINITIALIZED` | 尚未初始化 |
| `1` | `STARTING` | 正在启动或自检 |
| `2` | `ONLINE` | 在线且主功能可用 |
| `3` | `DEGRADED` | 降级运行，功能部分可用 |
| `4` | `OFFLINE` | 超时或失联 |
| `5` | `FAILED` | 失败，需要恢复或人工处理 |
| `6` | `DISABLED` | 配置关闭，不参与运行 |

## 严重度对照表

| severity | 名称 | 含义 |
| --- | --- | --- |
| `0` | `INFO` | 信息 |
| `1` | `WARNING` | 警告 |
| `2` | `ERROR` | 错误 |
| `3` | `CRITICAL` | 严重 |
| `4` | `FATAL` | 致命 |

## 常见 message 对照表

| message | 含义 |
| --- | --- |
| `imu_offline` | 姿态传感器离线 |
| `imu_recovered` | 姿态传感器恢复在线 |
| `baro_offline` | 气压/环境模块离线 |
| `baro_recovered` | 气压/环境模块恢复在线 |
| `gnss_degraded` | GNSS 降级，例如未定位 |
| `lora_offline` | LoRa 通信离线 |
| `lora_recovered` | LoRa 通信恢复在线 |
| `storage_degraded` | Storage 降级 |
| `storage_recovered` | Storage 恢复在线 |
| `sd_write_failed` | SD 写入失败 |
| `sd_sync_failed` | SD 文件同步失败 |
| `storage_queue_full` | Storage 记录队列已满 |
| `storage_queue_drop` | Storage 队列丢弃计数增加，说明至少有日志记录未能入队 |
| `low_voltage` | 第一电池低电压 |
