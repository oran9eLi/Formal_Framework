# ADC 电源模块教学建议

## 1. 教学定位

本文面向 CNS 教学实验箱中的 ADC 电源模块，教学对象为大专层次、低空方向相关专业学生。

本模块不应只作为“电池电压显示”功能使用，而应作为低空飞行器电源监测、安全告警和动力负载影响分析的教学实验模块。

学生学习本模块后，应能回答以下问题：

- 电源电压数据在飞控中代表什么？
- 飞控为什么要区分开发板电池和动力电池？
- 电压下降会对飞控、传感器、通信和电机造成什么影响？
- ADC 如何把模拟电压变成数字数据？
- 代码如何把 ADC 数据转换为电压、电量和低压告警？
- 日志数据如何帮助分析电源异常？

## 2. 当前工程链路

当前工程已有两路电池采样：

| 电池 | 用途 | 采样引脚 | 采样链路 |
|---|---|---|---|
| 第一电池 | 开发板 / 飞控系统供电 | PA5 / ADC1_IN5 | `BSP_ADC -> Sensor_Power -> Battery Topic` |
| 第二电池 | 四个无刷电机动力供电 | PA4 / ADC2_IN4 | `BSP_ADC2 -> Sensor_Power2 -> Battery2 Topic` |

正式数据链路如下：

```text
电池电压
  -> 外部分压电路
  -> STM32 ADC 引脚
  -> BSP ADC 原始采样
  -> Sensor 层电压换算、电量估算、低压判断
  -> Framework Battery / Battery2 Topic
  -> Business API / Display / MAVLink / SD-CSV
```

当前业务层可读取的主要字段：

```c
voltage_mv
battery_percent
low_voltage

voltage2_mv
battery2_percent
low_voltage2
```

## 3. 教学目标

### 3.1 数据意义

学生应理解两类电池的不同意义：

| 数据 | 飞控中的意义 | 数据变化影响 |
|---|---|---|
| 飞控电池电压 | 保障主控、传感器、通信模块运行 | 电压过低可能导致系统重启、传感器异常、通信中断 |
| 动力电池电压 | 保障四个无刷电机输出推力 | 电压下降会导致电机推力下降，严重时可能触发电调保护 |
| 电量百分比 | 对剩余电量的估算 | 用于判断是否继续实验或准备停止 |
| 低压告警 | 飞控对电源风险的判断 | 提醒用户降低负载、停止实验或排查电源 |

### 3.2 原理理解

学生应理解 ADC 电源模块的基本原理：

```text
ADC 原始值
  -> 引脚电压
  -> 分压还原电池电压
  -> 校准补偿
  -> 电压滤波
  -> 电量曲线估算
  -> 低压告警判断
```

### 3.3 使用能力

学生应能够：

- 看懂显示界面中的电压、电量和告警状态。
- 看懂 SD-CSV 中电源字段的含义。
- 通过电压变化判断电机负载对电池的影响。
- 通过日志分析低压告警发生的时间和原因。
- 阅读少量关键代码，理解 ADC 换算、滤波和低压防抖原理。

## 5. 建议低压状态分级

当前工程已有低压 flag，但对学生来说 `low_voltage = 1` 不够直观。建议教学显示层增加文字化分级。

### 5.1 第一电池分级

| 状态 | 电压范围 | 教学解释 |
|---|---|---|
| 正常 | `> 10.50V` | 飞控供电较安全 |
| 低压预警 | `10.30V ~ 10.50V` | 电压接近风险区，应关注系统稳定性 |
| 严重低压 | `< 10.30V` | 可能影响主控、传感器或通信稳定性 |

### 5.2 第二电池分级

| 状态 | 电压范围 | 教学解释 |
|---|---|---|
| 正常 | `> 11.00V` | 动力电池余量较安全 |
| 低压预警 | `10.80V ~ 11.00V` | 不建议继续长时间大油门 |
| 严重低压 | `10.50V ~ 10.80V` | 电机推力可能明显下降 |
| 临界低压 | `< 10.50V` | 应停止动力实验，避免过放或电调保护 |

说明：分级显示可先在教学页面实现，不一定立即改变底层 topic 结构。

## 6. 建议教学实验

### 6.1 实验一：ADC 电压采样实验

#### 实验目标

让学生理解 ADC 只能读取数字量，真实电池电压需要通过分压和软件换算得到。

#### 学生观察数据

- ADC raw。
- ADC 引脚电压。
- 软件换算电池电压。
- 万用表实测电压。
- 误差。

#### 讲解要点

```text
STM32 ADC 输入范围是 0~3.3V。
电池电压通常高于 3.3V，不能直接接入 ADC。
必须先经过分压电路，再由软件按比例换算回电池电压。
```

#### 代码讲解

```c
pin_mv = raw * 3300 / 4095;
voltage_mv = pin_mv * divider_num / divider_den;
```

教学解释：

- `raw` 是 ADC 采样得到的数字值。
- `3300` 是参考电压，单位 mV。
- `4095` 是 12 位 ADC 最大值。
- `divider_num / divider_den` 是分压还原比例。

### 6.2 实验二：电量百分比实验

#### 实验目标

让学生理解电量百分比是估算值，不是精确剩余容量。

#### 学生观察数据

- 电池电压。
- 电量百分比。
- 电量档位变化。

#### 讲解要点

```text
电池电压和剩余容量不是严格线性关系。
飞控常用电压曲线估算电量。
为了避免显示跳动，电量通常按固定档位显示。
```

当前工程中：

- 第一电池：`9.90V = 0%`，`12.55V = 100%`。
- 第二电池：`10.50V = 0%`，`12.60V = 100%`。
- 电量显示按 `5%` 档位输出。

### 6.3 实验三：低压告警防跳变实验

#### 实验目标

让学生理解低压告警为什么不能瞬时触发。

#### 学生观察数据

- 电压在阈值附近波动。
- 滤波后电压。
- 低压状态。
- 告警触发时间。
- 告警恢复时间。

#### 讲解要点

```text
真实飞行中，电机启动、加速、负载变化都会造成瞬时电压跌落。
如果电压刚低于阈值就立即告警，系统会频繁误报警。
所以飞控通常使用滤波、连续确认和恢复回差。
```

当前工程低压逻辑：

```text
第一电池：
低于 10.30V 连续确认 -> 低压告警
高于 10.50V 连续确认 -> 告警恢复

第二电池：
低于 10.80V 连续确认 -> 低压告警
高于 11.00V 连续确认 -> 告警恢复
```

可讲解代码：

```c
filtered_voltage = old * 3 / 4 + new * 1 / 4;
```

以及：

```text
连续 N 次满足低压条件后才切换告警状态。
连续 N 次满足恢复条件后才解除告警。
```

### 6.4 实验四：动力电池负载影响实验

#### 实验目标

让学生理解动力电池电压变化对低空飞行器动力系统的影响。

#### 学生操作

```text
电机未启动
低油门
中油门
高油门
停止电机
```

#### 学生记录

- 动力电池电压。
- 动力电池百分比。
- 动力电池低压状态。
- 电机目标油门。
- 日志事件。

#### 观察现象

```text
电机启动瞬间，电压下跌。
油门越大，电压越低。
停止电机后，电压回升。
```

#### 飞控意义

```text
动力电池电压下降会影响电机可用推力。
严重低压时，飞行器可能无法维持高度或姿态控制。
```

## 7. 建议代码讲解范围

面向大专低空方向学生，代码讲解建议控制在“能看懂原理”的深度，不需要展开全部 HAL 初始化。

### 7.1 ADC 换算

讲解文件：

- `Bsp/Src/bsp_adc.c`
- `Bsp/Src/bsp_adc2.c`

讲解重点：

```c
pin_mv = ((raw * BSP_ADC_REF_MV) + (BSP_ADC_RAW_MAX / 2U)) / BSP_ADC_RAW_MAX;
voltage_mv = (pin_mv * BSP_ADC_DIVIDER_NUM) / BSP_ADC_DIVIDER_DEN;
```

### 7.2 电压滤波

讲解文件：

- `Sensor/Src/sensor_power.c`
- `Sensor/Src/sensor_power2.c`

讲解重点：

```text
新电压不会直接替换旧电压，而是和旧值做加权平均。
这样能减少 ADC 抖动和瞬时负载变化造成的显示跳动。
```

### 7.3 电量曲线

讲解重点：

```text
根据电压查表或插值，估算电量百分比。
电量百分比是飞控辅助判断，不是精确容量计量。
```

### 7.4 低压确认

讲解重点：

```text
连续多次低于阈值才告警。
连续多次高于恢复阈值才解除。
中间区间保持当前状态。
```

## 9. 推荐优先级

建议按以下顺序推进：

1. 新增电源教学页面。
2. 增加低压状态文字分级。
3. 增加 ADC 采样链路可视化数据。
4. 补充动力电池负载实验记录模板。
5. 整理代码讲解文档。
6. 后续接入 `CURR` 电流检测。

最优先的是前两项，因为它们直接影响学生能否看懂数据在飞控中的意义。
