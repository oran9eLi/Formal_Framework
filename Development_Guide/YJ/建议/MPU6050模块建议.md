# MPU6050 模块教学建议

## 1. 教学定位

MPU6050 模块建议定位为 CNS 教学实验箱中的“姿态感知与姿态数据理解”模块。面向大专低空方向学生时，教学目标不应只强调算法复杂度，而应让学生能够使用模块、看懂数据在飞控中的意义，并理解数据变化会怎样影响飞行器控制。

学生完成本模块学习后，应能够回答以下问题：

- `Roll`、`Pitch`、`Yaw` 分别表示什么飞行姿态。
- 加速度计和陀螺仪分别测量什么物理量。
- 为什么静止时加速度计仍会测到约 `1g`。
- 为什么 MPU6050 的 `Yaw` 只能作为相对偏航角，不能直接当作指南针航向。
- 为什么姿态解算前需要静止校准。
- 姿态数据异常时，对低空飞行器控制会产生什么风险。

## 2. 当前工程数据链路

当前工程中，MPU6050 数据从驱动层进入 Framework，再被姿态解算、显示、通信和日志等模块使用。建议教学时直接展示这条链路，让学生理解“传感器原始数据”如何变成“飞控可用姿态”。

```text
MPU6050 芯片
    -> Sensor_MPU6050 驱动
    -> Platform Adapter 坐标与单位转换
    -> IMU FIFO
    -> Estimator 姿态解算
    -> Navigation / Attitude Topic
    -> 显示、MAVLink、SD-CSV 日志、Business API
```

建议课堂重点解释以下数据：

| 数据 | 含义 | 教学解释 |
|---|---|---|
| `accel_mg[3]` | 三轴加速度，单位 `mg` | 静止时主要反映重力在机体系三个轴上的投影。 |
| `gyro_mdps[3]` | 三轴角速度，单位 `mdps` | 反映机体绕三个轴旋转的快慢，只在姿态变化时明显变化。 |
| `temperature_cdeg` | 芯片温度，单位 `0.01 degC` | 可用于说明温度会影响传感器零偏。 |
| `roll_deg100` | 横滚角，单位 `0.01 deg` | 左右倾斜角度，是飞控横向平衡的重要输入。 |
| `pitch_deg100` | 俯仰角，单位 `0.01 deg` | 抬头或低头角度，会影响前后运动和升降趋势。 |
| `yaw_deg100` | 相对偏航角，单位 `0.01 deg` | 表示相对转向变化；由于无磁力计，不能长期当作绝对航向。 |
| IMU 状态/FIFO 状态 | 数据是否新鲜、是否积压 | 用于说明飞控不仅看数值，还要判断数据是否可信。 |

## 3. 建议教学显示内容

建议在实验箱显示界面增加一个“姿态教学页”，将数据和含义放在同一页中，避免学生只看到数字却不知道用途。

```text
姿态角
Roll       +3.20 deg     左右倾斜
Pitch      -1.45 deg     抬头/低头
Yaw(Rel)   +18.60 deg    相对转向

角速度
Gyro X     +0.30 dps
Gyro Y     -0.10 dps
Gyro Z     +2.80 dps

IMU 状态
状态       正常
校准       已完成
数据延迟   8 ms
```

建议界面中使用简短提示说明数据影响：

- `Roll` 变大：机体左右倾斜，飞控需要通过左右侧电机差速修正。
- `Pitch` 变大：机体抬头或低头，会影响前后运动和升降趋势。
- `Yaw(Rel)` 变化：机体发生转向，但 MPU6050 不能长期提供绝对航向。
- `IMU 离线` 或数据延迟过大：姿态不可可靠使用，飞控应限制控制或进入保护状态。

## 4. 建议实验设计

### 4.1 姿态角认识实验

实验目的：让学生建立 `Roll / Pitch / Yaw` 与机体动作的对应关系。

实验步骤：

1. 将实验箱水平放置，观察 `Roll` 和 `Pitch` 是否接近 `0 deg`。
2. 将右侧抬高，观察 `Roll` 的正负和数值变化。
3. 将前端抬高或压低，观察 `Pitch` 的正负和数值变化。
4. 水平旋转实验箱，观察 `Yaw(Rel)` 的变化。

教学结论：

- 横滚和俯仰可以通过加速度计长期校正。
- 偏航角主要来自陀螺积分，会随时间产生漂移。
- MPU6050 没有磁力计，因此不能独立提供长期稳定的绝对航向。

### 4.2 加速度与重力方向实验

实验目的：让学生理解加速度计并不是只在“运动”时才有数值。

实验步骤：

1. 实验箱静止水平放置，观察三轴加速度。
2. 分别让 X、Y、Z 轴朝上，观察哪个轴接近 `+1g` 或 `-1g`。
3. 轻轻晃动实验箱，观察三轴加速度短时间波动。

教学结论：

- 静止时加速度计测到的是重力加速度。
- 飞控可以利用重力方向估计横滚和俯仰。
- 强烈晃动时，加速度计会混入线加速度，姿态修正可信度下降。

### 4.3 陀螺角速度实验

实验目的：让学生理解陀螺仪测的是“转得多快”，不是“当前角度”。

实验步骤：

1. 静止放置实验箱，观察三轴角速度是否接近 `0 dps`。
2. 快速绕 X 轴转动后停止，观察 `Gyro X` 只在转动时明显变化。
3. 绕 Z 轴水平旋转，观察 `Gyro Z` 和 `Yaw(Rel)` 的关系。

教学结论：

- 陀螺仪输出角速度，姿态角需要由角速度积分得到。
- 陀螺仪零偏会导致积分误差，所以需要静止校准。
- 偏航角没有重力方向可校正，因此更容易随时间漂移。

### 4.4 静止校准实验

实验目的：让学生理解为什么上电后要保持实验箱静止。

实验步骤：

1. 上电后保持实验箱静止，观察校准状态从“校准中”到“已完成”。
2. 校准过程中轻微移动实验箱，观察校准进度是否暂停或重新累计。
3. 对比校准前后静止时角速度是否更接近 `0 dps`。

教学结论：

- 当前姿态解算会在静止状态下采集陀螺零偏样本。
- 校准完成后，系统会从陀螺角速度中减去零偏。
- 校准期间不应移动实验箱，否则零偏估计会不准确。

建议后续在显示或日志中增加以下字段，方便教学观察：

- `gyro_bias_valid`：陀螺零偏是否有效。
- `calib_sample_count`：当前已累计校准样本数。
- `gyro_bias_x/y/z`：三轴陀螺零偏。
- `accel_trust`：当前加速度计修正可信度。

### 4.5 线加速度干扰实验

实验目的：让学生看到“传感器数据可信度”对飞控的重要性。

实验步骤：

1. 实验箱水平静止，记录 `Roll` 和 `Pitch`。
2. 快速平移或轻微振动实验箱，观察加速度幅值变化。
3. 观察姿态角是否出现短时波动，并解释滤波器为何不能完全相信加速度计。

教学结论：

- 加速度计在机体加速时不只包含重力。
- 姿态解算需要判断加速度幅值是否接近 `1g`。
- 当加速度明显异常时，应降低加速度计对姿态修正的权重。

### 4.6 故障与恢复演示实验

实验目的：让学生理解飞控系统为什么要关注模块状态，而不是只看传感器数值。

实验建议由教师操作：

1. 正常运行时观察 IMU 状态为 `ONLINE`。
2. 模拟 I2C 通信异常或断开模块，观察 IMU 状态变化。
3. 恢复连接后观察模块是否重新上线。
4. 查看日志中是否记录 IMU 异常和恢复事件。

教学结论：

- 飞控系统必须知道传感器数据是否可用。
- IMU 异常时，姿态解算结果不能继续被无条件相信。
- 状态、告警和恢复机制是工程系统的重要组成部分。

## 5. 建议代码讲解范围

代码讲解建议保持“够用、能对应实验现象”的深度，不建议一开始展开复杂矩阵或完整滤波理论。

### 5.1 原始数据读取

讲解重点：

- MPU6050 通过 I2C 读取寄存器。
- 一次读取加速度、温度和陀螺仪原始数据。
- 原始整数需要根据量程转换为物理单位。

示例讲解：

```c
/* 从 ACCEL_XOUT_H 开始连续读取加速度、温度和陀螺仪数据 */
status = BSP_I2C1_Mem_Read(MPU6050_ADDR,
                           MPU6050_REG_ACCEL_XOUT_H,
                           buffer,
                           MPU6050_FRAME_LEN,
                           MPU6050_I2C_TIMEOUT_MS);
```

教学解释：

- 这一步得到的还不是姿态角。
- 它只是芯片测到的三轴加速度和三轴角速度。
- 后续还要经过单位转换、坐标转换和姿态解算。

### 5.2 坐标与单位转换

讲解重点：

- 芯片坐标系不一定等于机体坐标系。
- 工程需要在 Platform Adapter 中统一坐标方向。
- 单位统一后，后续模块才能正确使用数据。

教学解释：

- 如果轴向映射错误，学生向右倾斜时可能显示为向左倾斜。
- 如果单位错误，姿态变化会变得过大、过小或不稳定。
- 坐标和单位是飞控数据链路中很容易出错但非常关键的一步。

### 5.3 姿态解算核心思想

建议用互补滤波的直观解释，而不是先讲复杂算法：

```text
短时间姿态变化：更相信陀螺仪
长时间水平参考：更相信加速度计
最终姿态角：把两者按权重融合
```

可用简化公式说明：

```c
roll = alpha * roll_from_gyro + (1.0f - alpha) * roll_from_accel;
pitch = alpha * pitch_from_gyro + (1.0f - alpha) * pitch_from_accel;
```

教学解释：

- 陀螺仪反应快，但会慢慢漂移。
- 加速度计长期能找到重力方向，但运动时容易受干扰。
- 互补滤波就是把两者优点结合起来。

### 5.4 陀螺零偏校准

讲解重点：

- 静止时理论角速度应接近 `0 dps`。
- 如果静止时仍有小角速度，这个误差就是零偏。
- 系统在静止状态下累计多帧数据，估计零偏并在后续扣除。

教学解释：

- 零偏不消除，姿态角会慢慢漂移。
- 校准过程中移动设备，会把真实运动误当成零偏。
- 所以上电或重新校准时应保持实验箱静止。

## 6. 建议新增教学能力

### 6.1 姿态教学页面

优先级：高。

建议内容：

- 显示 `Roll / Pitch / Yaw(Rel)`。
- 显示三轴角速度。
- 显示 IMU 状态、校准状态和数据延迟。
- 给出每个姿态角的简短中文解释。

教学价值：

- 学生可以直接把手上的动作和屏幕数据对应起来。
- 能理解姿态角不是抽象公式，而是飞控的实时输入。

### 6.2 校准状态可视化

优先级：高。

建议内容：

- 显示“校准中 / 已完成 / 校准失败或需静止”。
- 显示校准样本累计进度。
- 显示三轴陀螺零偏。
- 移动设备时提示“请保持静止”。

教学价值：

- 学生能理解为什么实验箱上电后不能马上晃动。
- 能看到校准对角速度稳定性的影响。

### 6.3 姿态数据变化影响提示

优先级：中。

建议内容：

- 当 `Roll` 超过一定角度时提示“横向倾斜增大”。
- 当 `Pitch` 超过一定角度时提示“俯仰姿态明显变化”。
- 当 IMU 状态异常时提示“姿态数据不可可靠使用”。

教学价值：

- 把传感器数值和飞控控制意义连接起来。
- 帮助学生理解数据异常为什么会影响低空飞行安全。

### 6.4 三种姿态解算模式对比

优先级：中低，适合进阶实验。

建议提供三种只用于教学观察的模式：

| 模式 | 说明 | 教学现象 |
|---|---|---|
| 陀螺积分模式 | 只用角速度积分 | 反应快，但会漂移。 |
| 固定互补滤波模式 | 固定 `alpha` 融合 | 比单独陀螺稳定。 |
| 动态互补滤波模式 | 根据加速度可信度调权重 | 晃动时更抗干扰。 |

注意：该功能只建议作为教学显示或实验模式，不应破坏当前工程默认姿态解算链路。

### 6.5 轴向自检实验

优先级：中。

建议内容：

- 提供“向右倾斜 / 向前倾斜 / 水平旋转”的动作提示。
- 自动判断数据变化是否符合预期。
- 给出“轴向正确 / 轴向可能接反”的结果。

教学价值：

- 学生能理解传感器安装方向和坐标系的重要性。
- 对低空飞控装调有直接帮助。

### 6.6 日志增强

优先级：中。

建议 SD-CSV 日志中保留或补充以下教学字段：

- `roll_deg`、`pitch_deg`、`yaw_rel_deg`
- `gyro_x_dps`、`gyro_y_dps`、`gyro_z_dps`
- `accel_x_g`、`accel_y_g`、`accel_z_g`
- `imu_status`
- `gyro_bias_valid`
- `accel_trust`
- `imu_fifo_depth` 或数据延迟

教学价值：

- 学生可以把实验动作和日志曲线对应起来。
- 适合课后分析姿态变化、校准效果和异常数据。

## 7. 与低空飞控教学的对应关系

MPU6050 教学不建议停留在“传感器会输出数字”的层面，应明确连接到低空飞行器控制：

- `Roll` 用于判断机体左右倾斜，影响横向平衡控制。
- `Pitch` 用于判断机体抬头或低头，影响前后运动和升降趋势。
- `Yaw(Rel)` 用于观察相对转向，但不能替代绝对航向传感器。
- 陀螺角速度用于快速感知姿态变化，是控制环响应的重要输入。
- 加速度计用于提供重力方向参考，但在振动和加速时可信度会下降。
- IMU 状态异常时，飞控不能继续无条件使用姿态结果。

建议教师在讲解时强调：飞控使用的不是单个传感器读数，而是经过状态判断、坐标转换、单位转换和滤波解算后的可信数据。

## 8. 推荐实施顺序

1. 先增加姿态教学页面，显示 `Roll / Pitch / Yaw(Rel)`、角速度、IMU 状态和简短解释。
2. 增加校准状态可视化，让学生看到静止校准的过程和结果。
3. 设计三组基础实验：姿态角认识、加速度与重力方向、陀螺角速度。
4. 增加姿态数据变化影响提示，把数据和飞控控制意义连接起来。
5. 补充 SD-CSV 教学字段，支持课后用曲线分析实验数据。
6. 后续再加入三种姿态解算模式对比和轴向自检实验。
7. 进阶阶段再讨论磁力计、六面加速度校准、温度补偿和更完整的 AHRS 算法。

## 9. 不建议优先投入的方向

以下方向有价值，但不建议作为大专低空方向入门教学的第一阶段重点：

- 一开始讲复杂矩阵推导、四元数完整数学推导。
- 在没有磁力计的情况下强调绝对航向精度。
- 把 MPU6050 教学做成纯驱动寄存器配置课程。
- 让学生直接修改底层 I2C 或 BSP 初始化链路。
- 过早引入复杂卡尔曼滤波，导致学生无法把实验现象和飞控意义对应起来。

## 10. 阶段性结论

MPU6050 模块的教学优化重点应从“工程可用”扩展到“学生可理解、可观察、可解释”。建议以姿态教学页面为核心，把 `Roll / Pitch / Yaw(Rel)`、加速度、角速度、校准状态和 IMU 健康状态集中展示，再配套动作实验和简化代码讲解。

这样可以让学生从“看到数字”进一步理解“数字代表什么、为什么会变化、变化后飞控会怎样使用”，更符合 CNS 教学实验箱和低空方向教学场景。
