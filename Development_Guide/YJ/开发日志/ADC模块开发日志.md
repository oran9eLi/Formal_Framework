# ADC 模块开发日志

## 1. 开发目标

将电池电压采集接入 NW3 工程，并让显示电压、电量更接近真实电池工作状态。最终目标是使用飞控电流计 `VOLT` 输出接入 PA5，测量电池电压并按稳定档位显示电量。

## 2. 开发过程

### 2.1 初始 ADC 接入

工程最初使用 `ADC1_IN5 / PA5` 作为电源检测输入。BSP 层负责：

- ADC1 初始化；
- 单次转换；
- 8 次平均；
- raw 到 PA5 引脚电压换算；
- 乘分压比例得到电池电压。

Sensor 层负责：

- 缓存电压快照；
- 计算电量百分比；
- 标记低电压；
- 维护错误计数。

### 2.2 硬件排查

调试中发现直接使用板上 ADC 接口时，读数并不能稳定反映电池电压。经过万用表测量确认：

- 板上 ADC 端与 PA5 导通；
- 但 PA5 没有可靠接到电池分压信号时会读到无意义或受板上电路影响的电压；
- 直接把电池高压接到 PA5 不允许，PA5 最大只能承受 3.3V。

因此改为使用飞控电流计的 `VOLT` 分压输出。

### 2.3 电流计接入

当前接线方案：

```text
电流计 GND  -> 开发板 GND
电流计 VOLT -> 开发板 ADC/PA5
CURR        -> 暂不接
5V          -> 暂不接 PA5
```

通过实测得到电流计电压输出比例约为 10.08，因此将分压系数校准为：

```c
#define BSP_ADC_DIVIDER_NUM       10080U
#define BSP_ADC_DIVIDER_DEN       1000U
```

### 2.4 电量算法修改

根据实测电池范围，电量显示规则更新为：

- 9.9V 以下为 0%；
- 9.9V 到 10.2V 为 5%；
- 10.2V 到 10.5V 为 10%；
- 12.55V 以上为 100%；
- 中间按线性比例换算；
- 电量只按 5% 档位显示；
- 新档位必须连续 10 次出现才更新。

同时保留电压滤波，避免 ADC 抖动造成显示跳变。

### 2.5 电压校准参数配置化与曲线优化

本次将 Sensor 层的二次校准参数集中到 `Sensor/Inc/sensor_power_config.h`：

- `POWER_CAL_GAIN_NUM / POWER_CAL_GAIN_DEN`：用于现场比例校准；
- `POWER_CAL_OFFSET_MV`：用于固定偏移校准；
- `POWER_LOAD_COMPENSATION_ENABLE / POWER_LOAD_COMPENSATION_MV`：用于可选负载压降补偿，默认关闭；
- `POWER_PERCENT_TABLE_xx_MV`：用于配置电量百分比曲线点。

电量曲线由原先低电量分段加中间线性换算，改为完整曲线表：

```text
9.90V=0%, 10.20V=5%, 10.50V=10%, 10.80V=20%,
11.10V=30%, 11.40V=40%, 11.70V=50%, 11.95V=60%,
12.15V=70%, 12.30V=80%, 12.45V=90%, 12.55V=100%
```

曲线点之间仍使用线性插值，并按 5% 档位显示；10 次连续确认和 200mV 滞回规则继续保留。

## 3. 调试记录

实测现象：

- 电流计单独测电压时准确；
- 同一电源同时给电流计和开发板供电时，ADC 显示比电池空载电压低约 0.2V。

结论：

- 该偏差主要来自开发板负载、线材、接头和共地压降；
- 由于分压比例约 10.08，PA5 上 20mV 的差异会放大成约 0.2V 的电池显示差异；
- 后续校准应以开发板工作时电源输入口处电压为基准，而不是空载电池电压。

## 4. 当前结果

当前 ADC 模块已完成：

- PA5 / ADC1_IN5 采集；
- 电流计 `VOLT` 校准；
- Sensor 层 gain、offset、负载补偿参数配置化；
- 电压 mV 换算；
- 表驱动电量曲线和 5% 电量档位；
- 10 次连续确认防跳变；
- Battery Topic 发布；
- Storage CSV 电压、电量字段接入；
- 单元测试覆盖电压校准和电量档位逻辑。

## 5. 后续注意

- 禁止将 10V 到 12V 电池直接接 PA5。
- 电流计 GND 与开发板 GND 必须可靠共地。
- 如果显示偏低约 0.2V 且稳定，优先视为工作状态压降。
- 如果偏差随负载大幅变化，应检查电源线、接头、电流计主电源路径和地线连接。
- `CURR` 电流信号尚未接入，后续如需电流检测，应另行确认 ADC 通道和比例。
