## 2. 需求背景

CNS 教学实验箱目前采用两块 12.6V 规格电池：

- 第一电池：主要为开发板、传感器和稳压板供电。
- 第二电池：主要为 4 个无刷电机和动力分压板供电。

前期仅实现了两块电池的电压采样和低压状态判断。随着实验箱进入底层电源管理规划阶段，需要让学生不仅能看到电压，还能理解电流、电功率和负载变化之间的关系。

因此今天新增两路电流采样：

| 对象 | 电压采样 | 电流采样 | 说明 |
|---|---|---|---|
| 第一电池 | PA5 / ADC1_IN5 | PC0 / ADC3_IN10 | 开发板与传感器供电侧 |
| 第二电池 | PA4 / ADC2_IN4 | PC1 / ADC3_IN11 | 4 个无刷电机动力侧 |

电流计为无人机电源模块，每个电流计只连接一块电池。软件侧先按模拟电压输出电流计处理，默认以 `0mV = 0A`、`100mV/A` 作为占位标定参数，后续需要根据实物模块进行标定。

## 3. 硬件与接口规划

### 3.1 电压采样

第一电池：

- 电池规格：12.6V 满电。
- ADC 引脚：PA5。
- ADC 通道：ADC1_IN5。
- 软件模块：`bsp_adc`、`sensor_power`。

第二电池：

- 电池规格：12.6V 满电。
- ADC 引脚：PA4。
- ADC 通道：ADC2_IN4。
- 软件模块：`bsp_adc2`、`sensor_power2`。

### 3.2 电流采样

第一电池电流：

- 电流计数量：1 个。
- 电流计连接对象：第一电池。
- ADC 引脚：PC0。
- ADC 通道：ADC3_IN10。
- 软件通道标识：`BSP_ADC_CURRENT_BATTERY1`。

第二电池电流：

- 电流计数量：1 个。
- 电流计连接对象：第二电池。
- ADC 引脚：PC1。
- ADC 通道：ADC3_IN11。
- 软件通道标识：`BSP_ADC_CURRENT_BATTERY2`。

### 3.3 硬件注意事项

电流计输出端必须确认接到 MCU ADC 的是模拟电压信号，并满足：

- ADC 输入电压不能超过 3.3V。
- 如果电流计 CURR 输出为 0-5V，需要外部分压后再接入 PC0 / PC1。
- 两个电流计、两块电池和开发板 ADC 参考地必须共地。
- 电池大电流路径不应经过开发板，开发板只采样电流计信号输出。
- 后续实测时应分别记录零电流输出电压和已知负载电流输出电压，用于修正 `ZERO_MV` 和 `MV_PER_A`。

### 4.2 Sensor Driver 层

修改文件：

- `Sensor/Inc/sensor_power.h`
- `Sensor/Inc/sensor_power_config.h`
- `Sensor/Src/sensor_power.c`
- `Sensor/Src/sensor_power2.c`

新增数据：

- `Power_Snapshot_t.current_ma`
- `Power_Snapshot_t.power_mw`
- `Power_Status_t.current_ma`
- `Power_Status_t.power_mw`

第一电池电流处理：

- 从 `BSP_ADC_CURRENT_BATTERY1` 读取 PC0 电流计 ADC 电压。
- 根据 `POWER_CURRENT_ZERO_MV`、`POWER_CURRENT_MV_PER_A`、`POWER_CURRENT_OFFSET_MA` 换算电流。
- 使用 `POWER_CURRENT_FILTER_OLD_WEIGHT` 和 `POWER_CURRENT_FILTER_TOTAL` 做滤波。
- 根据滤波电流和电池电压计算功率。

第二电池电流处理：

- 从 `BSP_ADC_CURRENT_BATTERY2` 读取 PC1 电流计 ADC 电压。
- 根据 `POWER2_CURRENT_ZERO_MV`、`POWER2_CURRENT_MV_PER_A`、`POWER2_CURRENT_OFFSET_MA` 换算电流。
- 使用 `POWER2_CURRENT_FILTER_OLD_WEIGHT` 和 `POWER2_CURRENT_FILTER_TOTAL` 做滤波。
- 根据滤波电流和第二电池电压计算功率。

默认标定参数：

| 参数 | 第一电池 | 第二电池 | 说明 |
|---|---:|---:|---|
| 零点电压 | 0mV | 0mV | 占位值，需实测 |
| 灵敏度 | 100mV/A | 100mV/A | 占位值，需实测 |
| 死区 | 50mA | 200mA | 防止零点附近抖动 |
| 滤波 | 3/4 旧值 + 1/4 新值 | 3/4 旧值 + 1/4 新值 | 平滑日志显示 |

- 结合代码讲解 ADC 采样、分压、电流计换算、滤波、低压确认和日志记录链路。

## 12. 今日结论

今天完成了 ADC 电源管理模块从“只看电压”到“电压 + 电流 + 功率”的一次重要扩展。两块电池当前都具备独立采样、独立换算、Business API 暴露和 SD-CSV 日志记录能力。

当前软件链路已经打通，工程构建通过。剩余关键工作不是软件链路，而是硬件实测标定和 Framework 层第二电池独立模块身份补齐。
