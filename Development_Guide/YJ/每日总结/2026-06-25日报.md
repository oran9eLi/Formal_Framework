## 2. 工程差异审查

### 2.1 MPU6050 模块

今日先对 NW3.1 与桌面 NW3 工程中的 MPU6050 相关代码进行比较。比较结果如下：

- `sensor_mpu6050.c` / `sensor_mpu6050.h` 级别的驱动代码在核心行为上没有发现实质差异。
- MPU6050 仍然负责 IMU 原始数据读取、解析、校准和驱动内部状态维护。
- 驱动层没有越过分层边界直接参与业务逻辑或日志写入。

结论：MPU6050 驱动代码本身可以认为一致。

### 2.2 姿态解算差异

随后检查姿态解算链路，确认 NW3 与 NW3.1 并不完全一致：

- NW3 当前版本偏向固定互补滤波实现。
- NW3.1 已包含更完整的姿态估计改进，例如陀螺零偏估计、加速度可信度门控、动态互补滤波系数和相关测试。

结论：MPU6050 驱动一样，但姿态解算并不一样。后续如果比较姿态表现，不能只看 `sensor_mpu6050.c`，还需要同时比较 `px4lite_attitude.c` 及其测试。

## 4. 第二电池链路审查

今日对第二电池链路进行了完整性审查。

确认链路如下：

```text
PA4 / ADC2_IN4
  -> BSP_ADC2
  -> Sensor_Power2
  -> Platform Adapter
  -> Battery2 Topic
  -> Business API
  -> Storage CSV
```

审查结论：

- PA4 / ADC2 采样链路完整。
- BSP 只负责 ADC、GPIO、clock 和原始电压换算。
- Sensor Driver 只负责第二电池电压、电量和低压事实。
- Framework topic 负责快照发布和复制。
- Business 通过 `app_data_api.h` 读取，未越层读取 BSP 或 Sensor 私有数据。
- Storage 按既有设计直接读取 Framework topic，不通过 Business API。

当前非阻塞遗留点：

- 第二电池暂未单独注册为独立模块 ID。
- 第二电池当前借用 Battery 模块采集周期和健康语义。
- 如果后续第二电池作为飞控动力安全关键输入，需要增加独立 Health / Alarm / ModuleStatus。

## 6. 第二电池动力电池曲线规划与实现

### 6.1 问题背景

第二电池不是普通开发板供电，而是给 4 个无刷电机供电。该电池负载电流大，电机启动和加速时会出现瞬时压降。如果继续使用第一电池曲线，存在两个问题：

- 低压预警太晚，原先低于 `9.90V` 才置位低压标志，不适合动力电池。
- 电量百分比曲线偏向轻载，不适合电机电池带载场景。

因此今日重新规划第二电池电量区间。

### 6.2 最终确认方案

第二电池使用独立 `POWER2_*` 动力电池曲线：

| 电量 | 电压 |
|---:|---:|
| 100% | 12.60V |
| 90% | 12.30V |
| 80% | 12.00V |
| 70% | 11.75V |
| 60% | 11.50V |
| 50% | 11.30V |
| 40% | 11.10V |
| 30% | 10.95V |
| 20% | 10.80V |
| 10% | 10.65V |
| 5% | 10.55V |
| 0% | 10.50V |

低压预警策略：

| 项目 | 阈值 |
|---|---:|
| 低压进入 | 滤波电压低于 10.80V |
| 低压解除 | 滤波电压高于 11.00V |
| 低压确认 | 连续确认 10 次 |
| 回差 | 200 mV |

### 6.3 代码实现

新增第二电池独立配置：

- `POWER2_PERCENT_TABLE_EMPTY_MV = 10500U`
- `POWER2_PERCENT_TABLE_FULL_MV = 12600U`
- `POWER2_LOW_WARNING_MV = 10800U`
- `POWER2_LOW_RECOVER_MV = 11000U`
- `POWER2_LOW_CONFIRM_COUNT = POWER_PERCENT_CONFIRM_COUNT`

修改位置：

- `Sensor/Inc/sensor_power_config.h`
- `Sensor/Src/sensor_power2.c`

`sensor_power2.c` 中新增低压防抖函数：

```c
Power2_ApplyLowVoltageConfirm()
```

其行为为：

- 未低压时，滤波电压必须连续低于 `POWER2_LOW_WARNING_MV` 才进入低压。
- 已低压时，滤波电压必须连续高于 `POWER2_LOW_RECOVER_MV` 才解除低压。
- 使用滤波电压判断，而不是瞬时采样电压，避免电机负载瞬态导致告警跳变。

### 6.4 单元测试

更新：

- `Tests/Unit/test_power2_adc_configurable_calibration.c`

覆盖内容：

- 第二电池 0% 电压为 `10500mV`。
- 第二电池 100% 电压为 `12600mV`。
- 第二电池低压进入阈值为 `10800mV`。
- 第二电池低压解除阈值为 `11000mV`。
- `low_voltage2` 在连续确认前不跳变。
- 连续确认后才置位或清除 `low_voltage2`。

## 11. 后续建议

后续建议继续推进以下工作：

- 如果第二电池作为动力安全关键输入，应增加独立 Module ID、Health 状态、Alarm 分级和恢复策略。

- 长稳测试时重点观察四个无刷电机启动、加速、持续负载下 `voltage2_v`、`battery2_pct`、`low_voltage2` 的变化，确认 10.8V / 11.0V 回差是否合适。
