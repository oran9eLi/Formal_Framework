# 屏幕模块开发文档

本文说明 Display 屏幕模块是怎么开发和实现的，重点给后续接手者看清楚：

- 我把屏幕模块分成了哪些层。
- 数据是怎么从业务层进入屏幕的。
- LVGL 页面是怎么创建和切换的。
- 显示变量、控件、触摸命令是怎么接入的。
- 后续开发时应该照着哪些代码位置扩展。

本文不记录调试问题和排查过程，只保留最终实现方式和关键代码。

## 1. 开发目标

屏幕模块的目标是把系统状态、传感器数据、告警、电机状态、定位信息、本地/远端通信状态显示到
ATK-MD0700 屏幕上。

开发时我没有让业务模块直接画屏，而是设计成下面这条链路：

```text
传感器 / 通信 / 业务任务
  -> Framework topic
  -> App 只读快照 / App Display Model
  -> Display_PrepareSnapshot()
  -> Display_SetHmiValue*
  -> Display HMI 变量缓存
  -> display_lvgl.c 创建和更新控件
  -> LVGL flush
  -> SSD1963
  -> FSMC LCD
```

这样做的好处是：业务层只管提供数据，Display 层只管显示，LCD 写入集中在 DisplayTask 一条路径里。

## 2. 模块分层实现

当前工程已启用 LVGL 后端：

```c
/* Display/Src/display.c */
#define DISPLAY_USE_LVGL_BACKEND 1U
```

整体分层如下：

```text
Bsp
  FSMC/GT911 引脚、时序、地址映射、LCD 写端口
  bsp_config.h / bsp_lcd_fsmc.*

Display 驱动层
  display_ssd1963.*  负责 SSD1963 初始化、flush、像素写入
  display_gt911.*    负责 GT911 触摸扫描

Display 协调层
  display.c / display.h
  负责 HMI 变量、App 快照装配、页面状态、刷新调度、自检恢复

Display LVGL 后端
  display_lvgl.* / lv_port_disp.* / lv_port_indev.*
  负责正式页面、控件、标题栏、本地/远端按钮、底部页签

旧点阵后端
  display_pages.* / display_gfx.* / display_text.* / display_logo.*
  当前保留作硬件调试和回退对照

Business
  business_task_template.* / business_display_placeholder.c
  负责 DisplayTask 周期调度
```

约束：

- DisplayTask 是 FSMC LCD 唯一写入者。
- Business、Framework、Sensor 不直接调用 LVGL。
- 不分配 800 x 480 x 2 的全屏帧缓冲。
- 新数据先进入 App 快照或 App Display Model，再由 Display 取走。

## 3. 页面是怎么定义的

页面枚举定义在 `Display/Inc/display.h`：

```c
typedef enum {
  DISPLAY_HMI_PAGE_LOGO = 0,
  DISPLAY_HMI_PAGE_SELF_CHECK,
  DISPLAY_HMI_PAGE_FLIGHT,
  DISPLAY_HMI_PAGE_AIRCRAFT,
  DISPLAY_HMI_PAGE_DATA,
  DISPLAY_HMI_PAGE_MOTOR,
  DISPLAY_HMI_PAGE_ALARM,
  DISPLAY_HMI_PAGE_HIDDEN,
  DISPLAY_HMI_PAGE_COUNT
} Display_HmiPage_t;
```

当前页面含义：

| 页面 | 用途 |
|---|---|
| `SELF_CHECK` | 自检页，显示模块状态和错误码 |
| `FLIGHT` | 飞行页，显示电池、环境、飞行时间、日志摘要 |
| `AIRCRAFT` | 姿态页，显示横滚、俯仰、偏航、LoRa 状态 |
| `DATA` | 定位页，显示 GNSS、经纬度、高度、速度 |
| `MOTOR` | 电机页，显示四路 PWM 和急停 |
| `ALARM` | 告警页，显示告警表 |
| `HIDDEN` | 通信连接页，用于本地/远端节点选择 |

`LOGO` 目前只保留枚举值，用于维持历史 ID 稳定，不再作为正式页面使用。

## 4. LVGL 页面是怎么创建的

页面创建入口在 `Display/Src/display_lvgl.c` 的 `Display_LvglCreatePage()`。

核心代码如下：

```c
static Display_Result_t Display_LvglCreatePage(Display_HmiPage_t page)
{
  if (page == DISPLAY_HMI_PAGE_LOGO) {
    page = DISPLAY_HMI_PAGE_SELF_CHECK;
  }
  if (page >= DISPLAY_HMI_PAGE_COUNT) {
    return DISPLAY_ERROR;
  }

  if (s_screen == 0) {
    s_screen = lv_obj_create(0);
    lv_scr_load(s_screen);
  } else {
    lv_obj_clean(s_screen);
  }

  Display_LvglClearActiveObjects();
  s_current_lvgl_page = page;

  lv_obj_set_size(s_screen, DISPLAY_LVGL_WIDTH, DISPLAY_LVGL_HEIGHT);
  lv_obj_set_style_bg_color(s_screen, lv_color_hex(0x08111A), 0);
  lv_obj_clear_flag(s_screen, LV_OBJ_FLAG_SCROLLABLE);

  Display_LvglCreateHeader(s_screen, page);

  switch (page) {
    case DISPLAY_HMI_PAGE_SELF_CHECK:
      Display_LvglCreateSelfCheckPage(s_screen);
      break;
    case DISPLAY_HMI_PAGE_FLIGHT:
      Display_LvglCreateFlightPage(s_screen);
      break;
    case DISPLAY_HMI_PAGE_AIRCRAFT:
      Display_LvglCreateAircraftPage(s_screen);
      break;
    case DISPLAY_HMI_PAGE_DATA:
      Display_LvglCreateGnssPage(s_screen);
      break;
    case DISPLAY_HMI_PAGE_MOTOR:
      Display_LvglCreateMotorPage(s_screen);
      break;
    case DISPLAY_HMI_PAGE_ALARM:
      Display_LvglCreateAlarmPage(s_screen);
      break;
    case DISPLAY_HMI_PAGE_HIDDEN:
      Display_LvglCreateHiddenPage(s_screen);
      break;
    default:
      return DISPLAY_ERROR;
  }

  if (page != DISPLAY_HMI_PAGE_HIDDEN) {
    Display_LvglCreateFooter(s_screen, page);
  }

  Display_LvglApplyCachedValues();
  return DISPLAY_OK;
}
```

实现思路：

1. 每次切页先清理当前 screen。
2. 创建通用标题栏。
3. 根据页面枚举调用具体页面创建函数。
4. 常规页面创建底部页签。
5. 隐藏页不创建底部页签。
6. 页面创建完成后，把已有 HMI 缓存值重新应用到控件。

## 5. 显示变量是怎么设计的

我把屏幕上显示的数据抽象成 HMI 变量。变量枚举在 `Display/Inc/display.h`。

示例：

```c
typedef enum {
  DISPLAY_HMI_VAR_SYSTEM_STATUS,
  DISPLAY_HMI_VAR_BATTERY_VOLTAGE,
  DISPLAY_HMI_VAR_BATTERY_CURRENT,
  DISPLAY_HMI_VAR_BATTERY_PERCENT,
  DISPLAY_HMI_VAR_GNSS_FIX,
  DISPLAY_HMI_VAR_GNSS_SAT_COUNT,
  DISPLAY_HMI_VAR_LATITUDE,
  DISPLAY_HMI_VAR_LONGITUDE,
  DISPLAY_HMI_VAR_ROLL,
  DISPLAY_HMI_VAR_PITCH,
  DISPLAY_HMI_VAR_YAW,
  DISPLAY_HMI_VAR_MESSAGE_LOG,
  DISPLAY_HMI_VAR_VIEW_NODE_ID,
  DISPLAY_HMI_VAR_COUNT
} Display_HmiVariableId_t;
```

每个变量有一条配置，结构如下：

```c
typedef struct {
  Display_HmiVariableId_t id;
  Display_HmiPage_t page;
  uint16_t var_addr;
  Display_HmiDataType_t data_type;
  Display_HmiAccess_t access;
  uint16_t refresh_ms;
  uint16_t x;
  uint16_t y;
  uint16_t width;
  uint16_t height;
  const char *name;
  const char *unit;
  const char *source;
} Display_HmiVariableConfig_t;
```

这里的 `var_addr` 是固件内部虚拟变量地址，不是 LCD 控制器寄存器地址。它主要用于调试、元数据和兼容旧 HMI 表。

## 6. 数据是怎么写入变量缓存的

外部不要直接改 LVGL 控件。数据统一通过 `Display_SetHmiValue*()` 写入。

接口定义：

```c
Display_Result_t Display_SetHmiValueU16(Display_HmiVariableId_t id, uint16_t value);
Display_Result_t Display_SetHmiValueI16(Display_HmiVariableId_t id, int16_t value);
Display_Result_t Display_SetHmiValueU32(Display_HmiVariableId_t id, uint32_t value);
Display_Result_t Display_SetHmiValueI32(Display_HmiVariableId_t id, int32_t value);
```

写入示例：

```c
(void)Display_SetHmiValueU16(DISPLAY_HMI_VAR_BATTERY_VOLTAGE, main_cv);
(void)Display_SetHmiValueU16(DISPLAY_HMI_VAR_BATTERY_PERCENT, main_pct);
(void)Display_SetHmiValueI16(DISPLAY_HMI_VAR_ROLL, roll_deg10);
(void)Display_SetHmiValueU32(DISPLAY_HMI_VAR_CLOCK_TIME, date_time->local_time_hhmmss);
```

LVGL 后端接收变量更新的入口：

```c
Display_Result_t Display_LvglSetValue(Display_HmiVariableId_t id, uint32_t value)
{
  if (id >= DISPLAY_HMI_VAR_COUNT) {
    return DISPLAY_ERROR;
  }

  s_values[id]      = value;
  s_value_valid[id] = 1U;
  Display_LvglApplyValue(id, value);
  return DISPLAY_OK;
}
```

实现思路：

1. `Display_SetHmiValue*()` 更新 Display 内部变量缓存。
2. LVGL 后端保存一份 `s_values[]`。
3. 如果对应控件已经创建，则立即更新控件。
4. 如果控件还没创建，等页面创建后 `Display_LvglApplyCachedValues()` 再补上。

## 7. 快照装配是怎么实现的

屏幕显示数据集中在 `Display_PrepareSnapshot()` 中装配。

核心结构：

```c
Display_Result_t Display_PrepareSnapshot(uint32_t now_ms)
{
  App_NavigationSnapshot_t navigation;
  App_SystemSnapshot_t system;
  App_EnvironmentSnapshot_t environment;
  App_AlarmSnapshot_t alarm;
  App_DateTimeSnapshot_t date_time;
  App_MotorSnapshot_t motor;

  if (Display_EnsureInit() != DISPLAY_OK) {
    return DISPLAY_NOT_READY;
  }

  App_MessageLogUpdate(now_ms);

  (void)Display_SetHmiValueU32(DISPLAY_HMI_VAR_UPTIME_MS, now_ms);
  (void)Display_SetHmiValueU32(DISPLAY_HMI_VAR_FLIGHT_TIME_S, now_ms / 1000U);

  if (App_GetDisplayNavigation(&navigation, now_ms) == PX4LITE_OK) {
    Display_LoadNavigationSnapshot(&navigation);
  } else {
    Display_ClearNavigationSnapshot();
  }

  if (App_GetDisplayDateTime(&date_time, now_ms) == PX4LITE_OK) {
    Display_LoadDateTimeSnapshot(&date_time);
  } else {
    Display_ClearDateTimeSnapshot();
  }

  if (App_GetDisplaySystem(&system, now_ms) == PX4LITE_OK) {
    Display_LoadSystemSnapshot(&system);
  } else {
    (void)Display_LoadModuleStatusFallback();
  }

  if (App_GetDisplayAlarm(&alarm, now_ms) == PX4LITE_OK) {
    Display_LoadAlarmSnapshot(&alarm, motor_fault, main_fault);
  }

  if (App_GetDisplayEnvironment(&environment, now_ms) == PX4LITE_OK) {
    Display_LoadEnvironmentSnapshot(&environment);
  } else {
    Display_ClearEnvironmentFields();
    Display_ClearBatteryFields();
  }

  if (App_GetDisplayMotor(&motor, now_ms) == PX4LITE_OK) {
    Display_LoadMotorSnapshot(&motor);
  } else {
    Display_ClearMotorFields();
  }

  Display_LoadLoraStats();
  Display_ApplyOfflineDataPolicy();

  (void)Display_SetHmiValueU32(DISPLAY_HMI_VAR_MESSAGE_LOG,
                               Display_PagesGetLogVersion());

  return DISPLAY_OK;
}
```

实现思路：

- Navigation 负责姿态、GNSS、位置、速度。
- DateTime 负责时间和日期。
- System 负责模块状态、自检、最高故障码。
- Environment 负责温湿压、电池、电流。
- Alarm 负责告警表。
- Motor 负责四路 PWM。
- LoRa 统计独立刷新。

每个 `Display_Load*Snapshot()` 只做一件事：把 App 快照字段转换成 HMI 变量。

## 8. 本地/远端显示是怎么实现的

屏幕右上角显示当前查看对象：

```c
display_mode = App_GetRemoteDisplayMode();

{
  uint8_t view_id = 0U;
  uint8_t selected_node = 0U;

  if (display_mode == PX4LITE_REMOTE_MODE_REMOTE) {
    (void)App_GetSelectedRemoteNode(&selected_node);
    if (selected_node != 0U) {
      view_id = selected_node;
    }
  }

  if (view_id == 0U) {
    view_id = App_GetLocalNodeId();
  }

  (void)Display_SetHmiValueU16(DISPLAY_HMI_VAR_VIEW_NODE_ID, view_id);
}
```

消息日志和告警表不在 Display 里分别生成本地/远端两套逻辑，而是走业务层统一模型：

```c
alarm_result = App_GetDisplayAlarm(&alarm, now_ms);
if (alarm_result == PX4LITE_OK) {
  Display_LoadAlarmSnapshot(&alarm, motor_fault, main_fault);
}

if (App_GetDisplayMessageLog(&log, now_ms) == PX4LITE_OK) {
  for (li = 0U; li < log.count; ++li) {
    uint16_t seq = log.entries[li].sequence;
    if ((seq != 0U) && (seq > s_log_bridged_seq)) {
      Display_PagesPushLogMessage((Display_LogMsg_t)log.entries[li].message_id,
                                  log.entries[li].time_hhmmss);
      s_log_bridged_seq = seq;
    }
  }
}
```

这样本地模式和远端模式都从 `App_GetDisplay*()` 取数据，Display 只负责显示。

## 9. 任务调度是怎么实现的

DisplayTask 位于 `Business/Src/business_task_template.c`。

主要流程：

```c
for (;;) {
  uint32_t now_ms = Business_PlatformGetMs();

  result = Business_DisplayPollTouch(now_ms);
  result = Business_DisplayPollKey(now_ms);

  if (Business_TimeReached(now_ms, next_refresh_ms) != 0U) {
    result = Business_DisplayPrepareSnapshot(now_ms);
    if (result == BUSINESS_SERVICE_OK) {
      refresh_pending = 1U;
    }
    next_refresh_ms = now_ms + BUSINESS_DISPLAY_REFRESH_PERIOD_MS;
  }

  if (Business_DisplayNeedsImmediateRefresh() != 0U) {
    refresh_pending = 1U;
  }

  if (refresh_pending != 0U) {
    result = Business_DisplayRefreshStep(now_ms, BUSINESS_DISPLAY_REFRESH_BUDGET_US);
    if (result == BUSINESS_SERVICE_OK) {
      refresh_pending = 0U;
    }
  }

  Business_StatusHeartbeat(BUSINESS_COMPONENT_DISPLAY);
  vTaskDelayUntil(&last_wake, pdMS_TO_TICKS(BUSINESS_DISPLAY_SERVICE_PERIOD_MS));
}
```

当前配置在 `Business/Inc/business_template_config.h`：

```c
#define BUSINESS_DISPLAY_SERVICE_PERIOD_MS    10U
#define BUSINESS_DISPLAY_REFRESH_PERIOD_MS    200U
#define BUSINESS_DISPLAY_REFRESH_BUDGET_US    2000U
#define BUSINESS_PRIORITY_DISPLAY             (tskIDLE_PRIORITY + 1U)
#define BUSINESS_DISPLAY_TASK_STACK_WORDS     1280U
```

实现思路：

1. 每 10ms 唤醒一次。
2. 先服务触摸。
3. 到 200ms 节拍时准备一版显示快照。
4. 切页或 LVGL 有待刷新时立即刷新。
5. 刷新完成后清 `refresh_pending`。
6. 周期性上报 DisplayTask 心跳。

## 10. LVGL 刷新是怎么接到 SSD1963 的

`Display_RefreshStep()` 当前直接走 LVGL 后端：

```c
Display_Result_t Display_RefreshStep(uint32_t now_ms, uint32_t budget_us)
{
  if (Display_EnsureInit() != DISPLAY_OK) {
    return DISPLAY_NOT_READY;
  }
  return Display_LvglRefreshStep(now_ms, budget_us);
}
```

LVGL 刷新核心：

```c
Display_Result_t Display_LvglRefreshStep(uint32_t now_ms, uint32_t budget_us)
{
  uint32_t elapsed_ms;

  (void)budget_us;
  if (s_lvgl_display_ready == 0U) {
    return DISPLAY_NOT_READY;
  }

  if (s_page_change_requested != 0U) {
    s_page_change_requested = 0U;
    if ((s_requested_page != s_current_lvgl_page) ||
        (s_page_rebuild_requested != 0U)) {
      s_page_rebuild_requested = 0U;
      (void)Display_SetHmiPage(s_requested_page);
    }
  }

  elapsed_ms = now_ms - s_last_tick_ms;
  if (elapsed_ms != 0U) {
    lv_tick_inc(elapsed_ms);
    s_last_tick_ms = now_ms;
  }

  lv_timer_handler();
  return DISPLAY_OK;
}
```

真正写屏发生在 LVGL display port 的 flush 回调中，最终调用 SSD1963 的像素 flush 接口。

## 11. 触摸和按钮是怎么开发的

GT911 触摸通过 `lv_port_indev.c` 接给 LVGL。

在页面里新增按钮时，按 LVGL event callback 开发。

示例结构：

```c
lv_obj_t *btn = lv_btn_create(parent);
lv_obj_set_pos(btn, x, y);
lv_obj_set_size(btn, w, h);
lv_obj_add_event_cb(btn, Display_LvglXxxEventCb, LV_EVENT_CLICKED, 0);
```

callback 里只做 Display 层允许的事：

- 切换页面。
- 写入 HMI 变量。
- 触发已有业务命令入口。
- 设置 Display 内部请求标志。

不要在绘图函数里直接改业务状态。

已有参考：

- `Display_LvglMotorSliderEventCb()`：电机滑条。
- `Display_LvglEstopEventCb()`：急停。
- `Display_LvglLocalRemoteEventCb()`：本地/远端切换。
- `Display_LvglRemoteNodeEventCb()`：远端节点选择。

## 12. 新增一个显示字段怎么做

以新增一个普通数值为例，步骤如下：

1. 在 `Display_HmiVariableId_t` 里加变量 ID。

```c
DISPLAY_HMI_VAR_XXX_VALUE,
```

2. 在 `s_hmi_variables[]` 里加变量配置。

```c
{DISPLAY_HMI_VAR_XXX_VALUE,
 DISPLAY_HMI_PAGE_FLIGHT,
 0x0123,
 DISPLAY_HMI_TYPE_U16,
 DISPLAY_HMI_ACCESS_RO,
 500,
 0, 0, 0, 0,
 "xxx_value",
 "unit",
 "App_CopyXxx"},
```

3. 在 `Display_PrepareSnapshot()` 或 `Display_Load*Snapshot()` 中写值。

```c
(void)Display_SetHmiValueU16(DISPLAY_HMI_VAR_XXX_VALUE, value);
```

4. 在 `Display_LvglFormatValue()` 中增加格式化。

```c
case DISPLAY_HMI_VAR_XXX_VALUE:
  (void)snprintf(text, DISPLAY_LVGL_VALUE_TEXT_LEN, "%lu", (unsigned long)value);
  break;
```

5. 在页面创建函数里创建一行值。

```c
Display_LvglCreateValueRow(card,
                           DISPLAY_HMI_VAR_XXX_VALUE,
                           "标签",
                           22,
                           88,
                           122);
```

6. 如果标签是中文，确认字库里有这些字。

## 13. 新增一个页面怎么做

1. 在 `Display_HmiPage_t` 中新增页面枚举。
2. 在 `display_lvgl.c` 新增：

```c
static void Display_LvglCreateXxxPage(lv_obj_t *parent)
{
  lv_obj_t *card;

  Display_LvglCreateSystemColumn(parent);
  card = Display_LvglCreateCard(parent, 264, DISPLAY_LVGL_BODY_Y, 268,
                                DISPLAY_LVGL_BODY_H, "页面标题");

  Display_LvglCreateValueRow(card, DISPLAY_HMI_VAR_XXX_VALUE,
                             "字段", 22, 48, 122);
}
```

3. 在 `Display_LvglPageTitle()` 中增加页面标题。
4. 在 `Display_LvglCreatePage()` 的 switch 中调用该页面函数。
5. 如果参与底部导航，在 `s_tabs[]` 中增加页签。
6. 如果是隐藏页或特殊入口，不加到底部页签，单独写入口按钮。

## 14. 中文字体是怎么处理的

当前中文不是完整字库，而是 `display_lvgl_font_zh.c` 里的子集字库。

开发时：

- 新增中文标签前先确认字库是否已有该字。
- 没有就补 16 x 16 字模。
- C 源码中的中文字符串继续使用 UTF-8 字节转义。
- 不直接引入完整 CJK 字库，避免 Flash/RAM 占用过大。

## 15. 自检和恢复是怎么实现的

LVGL 初始化：

```c
Display_Result_t Display_LvglInit(uint32_t now_ms)
{
  if (s_lvgl_core_ready == 0U) {
    lv_init();
    s_lvgl_core_ready = 1U;
  }

  if (LvPortDisp_Init() == 0U) {
    s_lvgl_display_ready = 0U;
    return DISPLAY_ERROR;
  }

  s_lvgl_display_ready = 1U;
  (void)LvPortIndev_Init();

  if (Display_LvglCreatePage(DISPLAY_HMI_PAGE_SELF_CHECK) != DISPLAY_OK) {
    return DISPLAY_ERROR;
  }

  s_last_tick_ms = now_ms;
  return DISPLAY_OK;
}
```

自检：

```c
Display_Result_t Display_LvglSelfCheck(uint16_t *error_code)
{
  if (error_code != 0) {
    *error_code = 0U;
  }

  if (s_lvgl_display_ready == 0U) {
    if (error_code != 0) {
      *error_code = 1U;
    }
    return DISPLAY_NOT_READY;
  }

  return DISPLAY_OK;
}
```

恢复：

```c
void Display_LvglRequestRecover(void)
{
  s_lvgl_display_ready = 0U;
}
```

恢复不在中断里直接重 init，而是通过 DisplayTask 的路径重新初始化。

## 16. 开发约束

后续继续开发屏幕模块时保持这些规则：

- 不让业务模块直接调用 LVGL。
- 不让其他任务直接写 FSMC LCD。
- 不在任务栈里放大数组。
- 不使用全屏 framebuffer。
- 不在触摸 callback 里做耗时 I/O。
- 新数据先进 App 快照或 App Display Model。
- 新中文先补字库。
- 修改后补 `Change_History/YYYY-MM-DD_序号_主题.md`。

## 17. 最小验证

每次改屏幕模块后，至少验证：

- Keil ARMCC5 Rebuild 通过。
- 首屏能显示。
- 底部页签能切换。
- 本地/远端按钮能进入和返回。
- 新字段有数据显示。
- 中文没有缺字。
- 触摸事件只触发一次。
- DisplayTask 栈剩余正常。
- LVGL heap 没有 assert。
