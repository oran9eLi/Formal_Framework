# v1.0 课堂实验台操作说明

适用范围：传感器观察、LoRa 通信和无桨电机实验。当前说明对应 `release/v1.0` 的 M3 软件候选；正式上课前须完成 M4 实板验收。

## 1. 课前准备

1. **拆除全部桨叶**，固定机架，确保裸电机周围没有线材和小物件。
2. 检查主控电源、电机电源、屏幕、MPU6050、BME280、GNSS、LoRa 和 SD 卡接线。
3. 上电后先看“上电自检”页。红色项目表示故障或未就绪，黄色表示启动或降级，绿色表示正常。
4. 进入实验前确认页面右上角显示本机编号。查看远端时，页面控件为只读；只有“本机急停”仍明确作用于当前这台实验台。

## 2. 传感器与姿态实验

### 观察姿态

1. 打开“姿态”页，缓慢改变机架横滚和俯仰，观察数值与地平仪同步变化。
2. “相对偏航”表示相对开机/参考位置的角度，不代表真北。静止一段时间后可能出现缓慢漂移。

### 校准零偏

1. 将实验台放到稳定桌面，停止触碰。
2. 点击“校准零偏”。页面依次显示“请求已接受”“请放稳设备”“采集中 xx%”。
3. 看到“零偏校准成功”后再移动设备。若显示“无姿态数据”或“设备未放稳”，排查传感器或重新放稳后再试。
4. 校准期间不要用手扶着机架；轻微持续移动也可能导致等待或失败。

### 设置与恢复显示零位

1. 把机架摆到希望作为课堂参考的位置，点击“设为零位”。当前姿态成为本机显示参考。
2. 点击“恢复基准”可取消相对零位，回到测得姿态。
3. 相对零位只改变本机显示，不改变控制、遥测和日志中的原始测量；重启后清除。

## 3. 无桨电机实验

### 认识页面数据

- `设 xx%`：学生设置的基础目标。
- `出 xx%`：控制器当前实际发出的输出命令；姿态辅助时可与设定不同。
- `xxxxus`：最终写给 ESC 的 PWM 脉宽。
- 模式按钮：点击在“直控”和“姿态辅助”之间切换。系统上电默认直控。
- 运行阶段：显示停止、ESC 准备中、手动运行、同步升速、缓降停机或电源闭锁。

这里的“实际输出”是控制器命令，不是转速传感器测得的 RPM。

### 手动与辅助对比

1. 保持直控，拖动一路滑轨，比较“设、出、us”的变化。
2. 点击模式按钮选择“姿态辅助”，在低目标下轻微改变机架姿态，观察“出”是否相对“设”出现修正。
3. 再切回直控，确认修正消失。模式只由学生点击改变，同步升速和缓降不会代替学生选择。

### 同步升速、缓降和急停

1. 点击“同步升速”，四路目标按曲线同步增加；姿态或环境传感器未就绪、动力闭锁时不会开始，原因显示在消息日志。
2. 点击“缓降停机”，四路输出按曲线降到零。缓降期间非零手动目标会被拒绝并写入消息日志。
3. 紧急情况按“本机急停”。急停直接撤收本机输出；确认安全后重新拖动滑轨才可重新给定目标。

## 4. LoRa 通信实验

1. 页面顶部持续显示本机 LoRa 发送计数、接收计数和丢包率。
2. 点击“本地/远端”进入“通信连接”页，选择 `DCDW-xxx` 节点。
3. 节点行中的 `RX` 和 `Loss` 每秒原位更新；数值变化不会反复重建整页。节点上线、下线或状态变化时页面会更新节点集合。
4. 选择节点后回到原页面查看远端数据。远端电机滑轨、升速、缓降、模式和姿态操作不可点击。
5. 远端协议目前不传输学生基础目标、电机控制模式和过程阶段；页面的“设”显示 `--`，模式和阶段显示“远端未上报/远端状态”。
6. 点击“本地/远端”返回本机；远端查看超时也会自动回到本机数据。

## 5. 课堂验收记录

每组至少记录：实验台编号、固件提交号、传感器自检结果、校准结果、直控/辅助观察、四路 PWM 范围、急停结果、远端节点编号、RX/Loss 变化和发现的问题。没有实板记录的项目不能标为 v1.0 通过。
