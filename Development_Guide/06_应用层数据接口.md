# 应用层数据接口

## 允许调用

Display、LoRa、5G、Logger 等业务模块只允许包含：

```c
#include "app_data_api.h"
```

应用层不得直接包含 `sensor_gnss.h`、`bsp_gnss.h`，也不得读取
Framework 内部 topic 存储。

## 导航读取

```c
App_NavigationSnapshot_t navigation;
Px4Lite_Result_t result;
uint32_t now_ms;

now_ms = Px4Lite_PlatformGetMs();
result = App_CopyNavigation(&navigation, now_ms);

if ((result == PX4LITE_OK) &&
    ((navigation.valid_mask &
      PX4LITE_NAV_VALID_POSITION) != 0U))
{
    /* Use latitude, longitude and altitude. */
}
```

返回值：

- `PX4LITE_OK`：完整且未超龄。
- `PX4LITE_NOT_READY`：尚未发布过导航数据。
- `PX4LITE_STALE`：有历史数据，但数据已超龄。
- `PX4LITE_BUSY`：一致性复制期间状态正在变化，可下周期重试。

## 系统读取

```c
App_SystemSnapshot_t system;
Px4Lite_Result_t result;
uint32_t now_ms;

now_ms = Px4Lite_PlatformGetMs();
result = App_CopySystem(&system, now_ms);

if (result == PX4LITE_OK)
{
    if (system.system_ready != 0U)
    {
        /* Required modules finished startup and no blocking fault exists. */
    }
}
```

`App_CopySystem()` 只有在 Health 摘要和模块状态版本一致时才返回成功，
防止读取到一半旧、一半新的组合状态。

## 时间戳

- `sample_time_ms`：设备产生数据或驱动收到完整数据的时间。
- `publish_time_ms`：Framework 完成处理并发布的时间。
- 新鲜度使用 `sample_time_ms` 判断。
- 处理延迟可由 `publish_time_ms - sample_time_ms` 计算。

## valid 与 valid_mask

- `header.valid` 表示这是一份结构完整、可识别的快照。
- `valid_mask` 表示具体哪些业务字段可使用。
- GNSS 未定位时仍可发布完整快照，但位置有效位必须为 0。
- 未计算 NED 速度前，不得设置 `PX4LITE_NAV_VALID_VELOCITY`。
