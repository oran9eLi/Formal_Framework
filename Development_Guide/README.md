# Development Guide

本目录是 Formal Framework 的统一开发手册入口。长期有效规则只维护在当前编号文件中；历史问题处理、一次性背景和旧迁移记录放在 `Change_History/` 或 `YJ/`，不再作为当前开发口径。

## 当前手册顺序

1. `01_统一开发手册.md`：项目基线、规则优先级、分层原则、任务模型、文档同步要求。
2. `02_架构边界与数据流.md`：目录职责、数据读取边界、snapshot、状态边界、恢复边界。
3. `03_模块接入手册.md`：统一接入入口，覆盖新外设分类、必改文件、初始化链路、通信/显示/5G-A/Remote ID/LoRa 多从机规则和评审清单。
4. `04_调试验证与发布门禁.md`：Debug 开关、构建验证、必测项目、发布门禁和专项说明。
5. `05_完成度与后续清单.md`：当前完成度唯一事实来源、剩余阶段、每次移植记录要求。

## 强制同步规则

代码框架、目录职责、任务模型、接口边界、配置入口、模块状态、外设接入方式或发布验证要求发生变化时，必须同步修改本手册。只改代码不改手册，视为开发闭环未完成。

模块完成度只以 `05_完成度与后续清单.md` 为准。不得因为文件、任务、函数声明或空实现存在，就把模块视为完成。

## 保留目录

| 目录 | 用途 |
|---|---|
| `Change_History/` | 历史变更记录，保留当时文件名和当时事实 |
| `Example_Template/` | 模块和数据完整性模板 |
| `Business_Layer_Template/` | Business 层模板 |
| `YJ/` | 旧工程迁移资料归档，只作参考 |
