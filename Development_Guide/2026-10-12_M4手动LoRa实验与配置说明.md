# M4 手动 LoRa 实验与配置说明

日期：2026-10-12。适用于 codex/v1-m4 开发候选；实施与证据见 [M4 验证记录](../Release/V1.0_M4_验证记录.md)，进度以 [执行台账](../Release/V1.0_执行台账.md)为准。

## 1. 实板准备

两台箱子使用同一候选固件。先登记实际 E22 型号、接线及模块软件版本；本实现按 E22-400T30D 的寄存器协议配置。以下为本轮固定课堂预设，尚待实板验收：

| 参数 | 要求 |
|---|---|
| 正常模式 UART | 9600 bit/s，8N1 |
| 空中速率 | 9.6 kbit/s |
| E22 射频地址 / NETID | ADDH=0、ADDL=0、NETID=0；与 MAVLink Node ID 分开 |
| 串口分包 | 240 B |
| 传输 | 透明；关闭附加 RSSI、环境 RSSI、软件切模式、中继和 LBT |
| 发射功率 | 30 dBm；仅适用本轮 30D 型号预设 |
| 通信密码 | 教师用厂商工具统一设为 0；密码为只写字段，固件不能读回验证 |
| Channel | 同组两台一致；屏幕候选 23 / 26 / 29 / 32 |

固件读取 0x00..0x06：REG0=0x64；REG1 的 0xE7 掩码位为 0，保留位不比较；REG3 高四位为 0，低位 WOR 参数在正常模式不参与本轮实验。读取确认后才允许基础帧和实验数据发送。

厂商默认空速为 2.4 kbit/s，可能与本轮要求不同。出现 **Profile mismatch** 时，教师通过厂商配置工具手动核对上表，保存后重启箱子；屏幕不会自动改写空速、功率等参数。出现 Unknown/Timeout/I/O error 时，检查模块、电源、UART、M0/M1/AUX 接线，再重新上电核验。

依据：[亿佰特 E22-400T30D 产品入口](https://www.ebyte.com/product/934.html)及[官方 E22-T 系列手册](https://www.ebyte.com/downpdf/934.html)。实际子版本与协议兼容性仍需登记。

## 2. 操作入口

进入 Comm，循环按钮依次切换 **Experiment → Config → Remote**。三个视图共用返回和最近 3 条 Event Log；完整历史仍在集中历史页。

### Experiment

1. 选择 Data：GNSS / Attitude / Power / Environment。
2. 选择 Interval：1 / 2 / 5 / 10 s，默认 Attitude、2 s。
3. **Send** 提交一次当前数据组；**Start** 开始连续发送；**Stop** 取消未提交的数据帧。
4. Queued(lab) 表示本次上电实验帧被驱动接受；UART(all) 来自 UART DMA 完成回调，含基础/实验/配置命令；Module idle(all) 为正常帧发送后的 AUX 空闲事实，含基础/实验帧。这三项不能一一对应。RX(session)/CRC/Drop/Loss est. 随硬件会话重置：分别为合法 MAVLink 帧、CRC拒绝、完整帧队列丢弃、序号估算损失，均不证明每一实验组已被对方收到。

Stop 后仍保留 HEARTBEAT（2 s）、长期产品身份（5 s）、SYS_STATUS（5 s）。配置独占期间暂停全部 LoRa 发送。已启动的 DMA 帧不能撤回；无历史队列或追赶补发。电池/环境等多帧组复制一次后分步发送。

参数修改、配置事务和模块故障会停止实验；恢复、复位与重启不自动 Start。切页只改变显示。数据不足显示 No data；参数/预算不允许时显示 Rate limit；模块未知、配置忙或预设不符时拒绝发送。

### Config

| 操作 | 结果与生效时机 |
|---|---|
| Node ID 滑块，Save Node | 1..250；Current 是本次运行地址，Saved 是保存地址；Saved / Reboot required 表示下次重启生效 |
| Channel 循环选择，Apply CH | 只写 E22 的 CH 寄存器，保存应答后再独立读回；Actual CH 为实际读值，编辑值不是当前值 |
| Restore | 分别追加 UID 默认地址记录、将 CH 恢复为 23；Node/CH 分项显示，可能一项成功一项失败 |

保存 Node ID 要求电机目标与输出已归零、没有自动序列、最新电机供电事实有效。当前实现要求电机供电在 10.1..13.5 V，样本年龄/连续测量间隔不超过 200 ms，连续推进的有效采样跨度至少 500 ms，电压保持在起始稳定值 ±300 mV 内；重复读取同一缓存不会延长窗口，每次 Flash 编程前复核。Power gate 表示门禁拒绝，不代表已经保存成功。保存期间维护锁拒绝新非零输出/起飞，保护和急停继续工作，结束不恢复旧输出。

长期产品身份 DCDWCNS1…由硬件 UID 派生，不随 Node ID 修改。重启后 LoRa、RPi、RemoteID 使用同一当前短地址。上电从 Flash 恢复 Node ID，从 E22 读取 Channel；Data/Interval/对端选择和连续实验会话不持久化。

### Remote

1. Next 浏览最多 8 条轻量发现记录，Select 手动选择一个对端。
2. 选择切换清除旧完整快照，等待所选节点的新帧和有效长期身份。
3. 观察 Fix/卫星、位置/高度/北东速度、姿态/角速度、两路电压/电流/电量、温压/湿度；缺测和过期显示 N/A / stale。相对 Yaw 不代表真北。
4. 各域 age 是本机接收后的年龄，HB/data 分开；seq loss 是 MAVLink 序号估算。双方时钟未同步，不把 age 解释为传输时延。
5. Freeze 只冻结观察值，其年龄继续增长；后台收发、日志、保护和配置继续工作。身份失效/冲突时撤销旧负载。

身份广播每 5 s，身份可信期 15 s；心跳过期门限 20 s，数据字段过期门限 30 s。每域独立判龄，心跳不能给旧姿态、定位或电源数据续期。

## 3. 多组课堂实验

同组使用同一 Channel，各箱 Node ID 不同。相同 Node ID 的不同产品身份显示 **ID CONFLICT**，禁止混入活动快照。学生为其中一台选择新 Node ID，Save 后重启，重新 Select。

同信道负载过高时，学生可将各组调整到不同候选 Channel、降低发送频率或轮流发送，再比较 RX/age/seq loss。候选信道不代表已验证完全隔离。没有收到身份广播时显示 ID unknown，隐蔽节点/身份丢失可能使冲突检测不完整；CRC 或丢帧不能直接证明同频干扰。

## 4. Flash 保留区与烧录

应用 IROM 上限为 0xE0000，Node ID 区为 sector 11：0x080E0000..0x080FFFFF，128 KiB，64 B/记录，共 2048 槽。格式包含版本、序号、本机 UID、设置值、CRC 和最后提交字；上电跳过未提交、半写或不同 UID 记录，使用最新有效记录。

运行时只向空白槽追加，不擦扇区；同一设置重复保存不占新槽。空间满显示 Full，并保留旧配置。

烧录前核对下载器采用 **Erase Sectors（仅擦写固件使用扇区）**。**Erase Full Chip / Mass Erase 会清空地址记录**，之后恢复 UID 默认值；恢复同一地址可重新 Save。不要将其他镜像数据写入保留区。空间满的维护擦除应在电机安全停止、单独维护流程下执行，首版屏幕不提供擦除入口。

分步写入不等于没有暂停取指；Flash 单字耗时、Comm 最大周期、供电变化时撤收波形均为实板必验项。当前候选还未完成双机、四机、资源和长稳验收。
