# 高度显示优化接入说明

## 目标

把原来直接显示 GNSS/GPS 高度的逻辑，改成：

- 没有 GPS 初始高度时，不显示绝对高度。
- GPS 第一次有效后，记录当前 GPS 高度作为高度基准。
- 同时记录 BME280 当前气压作为气压基准。
- 后续短时间内用 BME280 气压变化修正高度显示。
- GPS 长时间无数据时，不继续气压外推，直接保持最后一次有效高度。
- 任何异常状态下都不归零。

## 显示规则

| 状态 | 显示方式 |
|---|---|
| 从未拿到有效 GPS 高度 | 显示 `--` 或 `等待定位` |
| GPS 首次有效，BME280 气压有效 | 完成初始化，显示 GPS 高度 |
| 初始化完成，GPS 正常 | 显示气压融合高度，并用 GPS 慢速修正基准 |
| 初始化完成，GPS 短暂丢失 | 继续用 BME280 气压变化维持高度 |
| GPS 丢失超过 60 秒 | 冻结最后一次有效高度，不归零 |
| BME280 气压异常 | 冻结最后一次有效高度 |

## 接入位置

建议新增两个文件：

- `height_fusion.h`
- `height_fusion.c`

然后在现有业务刷新或显示刷新前调用 `HeightFusion_Update()`。

推荐调用位置：

- 如果工程有业务数据汇总层，放在业务数据更新处。
- 如果工程只有显示刷新层，放在高度显示字段写入前。
- 不建议从屏幕显示字符串反向解析气压，应该直接使用 BME280 解析后的数值。

## 输入数据

每次调用需要提供：

```c
HeightFusionInput input;

input.gps_valid = gps_has_valid_altitude;
input.gps_altitude_m = gps_altitude_m;
input.pressure_valid = bme280_pressure_valid;
input.pressure_pa = bme280_pressure_pa;
input.now_ms = system_tick_ms;
```

注意单位：

- 如果 BME280 当前输出是 `Pa`，直接传入。
- 如果 BME280 当前输出是 `hPa`，需要乘以 `100.0f` 后传入。

例如：

```c
input.pressure_pa = bme280_pressure_hpa * 100.0f;
```

## 输出使用

```c
HeightFusionOutput output;

output = HeightFusion_Update(&height_ctx, &input);

if (output.display_valid)
{
    display_altitude_m = output.display_altitude_m;
}
else
{
    /* 显示 -- 或等待定位 */
}
```

不要在 `display_valid == false` 时把高度写成 `0`。

## 当前参数

示例模块里默认参数如下：

| 参数 | 当前值 | 作用 |
|---|---:|---|
| 气压有效范围 | `30000~110000 Pa` | 过滤明显异常气压 |
| GPS 丢失保持时间 | `60000 ms` | 超过后冻结最后高度 |
| 高度低通系数 | `0.15` | 抑制显示抖动 |
| 显示死区 | `0.5 m` | 小变化不刷新显示 |
| GPS 慢速校准系数 | `0.01` | GPS 正常时慢慢修正高度基准 |
| GPS 最大校准误差 | `30 m` | 避免 GPS 大跳变污染基准 |

## 高度计算公式

气压相对高度使用标准近似公式：

```c
delta_h = 44330.0f * (1.0f - powf(pressure / pressure_ref, 0.1903f));
display_h = altitude_ref + delta_h;
```

其中：

- `pressure_ref` 是首次 GPS 有效时记录的 BME280 气压。
- `altitude_ref` 是首次 GPS 有效时记录的 GPS 高度。
- `pressure` 是当前 BME280 气压。

## 预期效果

修改后高度显示会变成：

- 开机未定位时不乱显示。
- 定位成功后才显示绝对高度。
- 设备不动时高度不会一直跳。
- GPS 短暂断开时高度还能保持稳定。
- GPS 长时间断开时高度停在最后一次有效值，不继续漂移，也不归零。

## 后续可优化点

如果工程里已经有速度、卫星数、HDOP 或静止检测，可以继续增强：

- GPS 速度接近 0 时，加大显示死区。
- HDOP 较差时，不参与 GPS 慢速校准。
- 卫星数不足时，只保持高度，不更新基准。
- 设备静止时冻结显示高度，只在明显升降时刷新。
