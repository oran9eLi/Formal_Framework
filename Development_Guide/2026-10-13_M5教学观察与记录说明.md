## 原始报文与发送事实

- 捕获环与生产队列/FIFO分离。MAVLink与NMEA共用互斥区，最多4帧/4句、16键；Raw单帧完整到280 B，NMEA到128 B。
- Start新建session并清旧统计；Clear或改入口换session并暂停；旧token不能读新类型。离开捕获页排队Pause，业务收发继续。切页期间单槽忙时保留目标入口并重试。
- Count为RX完整有效帧、TX接口已接受帧；TX失败仍可选Raw，Attempt/Timeout/Error独立统计，零接受键Avg/Age为N/A。
- 汇总按(source,sysid,compid,msgid)；Avg Hz=(count-1)/(last-first)，Age独立显示。环覆盖不是生产丢帧，Summary drop与Capture drop另列；超长NMEA计Capture drop。
- Select只复制该键最近仍在环内的记录；不可用会提示。选帧字节稳定，TX槽还存在时只更新阶段，覆盖后标注slot overwritten。
- LoRa Queued=Driver接受，UART done=DMA TC，Module idle=AUX空闲；RPi UART done=本机完整阻塞发送。各阶段均不证明对端接收。
- RX只捕获生产解析器判定完整有效的MAVLink帧，业务过滤前取副本。签名字节存在与签名认证分开；当前不配置密钥，不宣称认证。未知合法消息保留Raw并显示Unsupported。
- 13项Decoded按仓库方言实际wire offset读字段，MAVLink2缺省尾字节按协议为零；N/A哨兵和非有限浮点明确标出，不执行消息中的命令。

Decoded的GPS DOP为DOPx100、GPS yaw为cdeg，unknown/not provided/unsupported按消息字段定义。H1请求声明11+N、响应15+N，N=1..48，响应显示实际baud。

H1/B1契约保持0x8003、version1：type1→2回显；type3→4仅115200→57600临时切换。type4完整发送成功后才改速，复位回115200，Flash不保存速率。Serial本机阶段绑定最近接受nonce；拒绝/重复/忙计数为累计，本机UART成功不冒称Server成功。

## Observe

初始Stopped。Group选择IMU、Attitude、Baro、Power、GNSS、Motor、Drift；Field A/B在组内选择现有测量，Interval为200/500/1000 ms。组、字段、间隔和Set ref要求Stopped；被拒的动作不会暗改运行会话。

| 操作 | 结果 |
|---|---|
| Start | 新session、清旧曲线/统计，开始采样 |
| Stop | 停止新采样，保留结果 |
| Reset（Stopped） | 清数据、Freeze和漂移参考 |
| Freeze（Running） | 固定已显示坐标，统计继续 |
| Resume | 从当前环恢复绘图 |
| Set ref（Drift，Stopped） | 只取新鲜有效GNSS，换会话，之后手动Start |

两路64点，每路独立有效位；不读取IMU FIFO，不把融合头时间当IMU/GNSS新测量。重复缓存和无效/过期槽均留下断点，不计Count；每个真实有效样本均有点标记，慢速源不因孤立点被隐藏；Age来自最后接受的源测量时间，点横轴是采集任务真实轮询时间。500 ms在现有200 ms调度上交替600/400 ms，不补“准时”点。

两路曲线纵轴分别按原单位自动范围，屏上列单位和Min/Max/Mean；不以不同单位的线形高度直接比较物理量。角度显示局部unwrapped；缺口后新段，段内Min/Max/Mean重建，会话有效Count另列，控制/原始/CSV值保持原口径。

Drift为参考点附近N/E平面近似，限制1000 m、经度跨界归一化；显示N/E/距离及有效点数，失效N/A、超范围Out of range。参考仅用于实验，不写Navigation。切页继续既有观察，重新进入不Start；重启不恢复统计/参考。

## Record

上电Stopped，间隔1/2/5/10秒。Start由storage任务核对SD就绪后执行；Observe与Record各自独立。事件/故障CSV仍按既有后台服务运行。

- Accepted：本会话采样/格式化尝试条数；Queued：成功入数据队列条数。
- Written：同session数据完整写入条数；Synced：成功fsync覆盖的Written条数。
- Outstanding：本会话待处理数据；Queue drop / Write drop为本会话丢失，与事件总计分开。
- Stop后Stopping，停止新采样；本会话待写条目处理完并成功sync、无丢失才Saved。共享事件队列无需全空。
- 队满/格式化失败使会话有丢失，Stop后Partial；写入/同步失败或掉卡为Error，显示SD阶段和真实FatFs码。恢复不续录。
- Error会话剩余队列条目在恢复可处理后丢弃，不补写；处理完后才能开始下一会话，旧数据不会计进新会话。
- 保留CSV宽表schema2和日期文件，文件追加；session为内存队列归属标记。电脑核对时用记录页Start/Finish Uptime定位行范围，屏内不提供回放/文件管理。

## 资源与课堂配置

GNSS/IMU/Baro三个周期打印宏设0，启动/异常保留。常驻资源采集独立于Debug task，关闭打印后仍可用。旧LoRa分消息零值统计已移除，Debug使用当前会话Queued、实际UART TC和AUX idle、RX/CRC/drop。

40 KiB FreeRTOS与40 KiB LVGL堆不增大；DMA保持主SRAM。显示布局/数值分拍，LVGL单缓冲partial在同步条带间续刷；每条带已完成再让出预算，没有跨拍借用栈上draw context或延迟flush_ready。2 ms为完整服务目标，单条带或格式化可以超限，必须看实际whole/render/flush最大值和overrun。

仍需实测：主堆峰值<75%，LVGL峰值<85%且最大连续空闲≥4 KiB，每任务余栈>配置25%且≥100 word，完整显示2 ms、触摸100 ms、切页300 ms；切页200次/最重组合/诊断开关对照。静态map合格不能替代这些证据。

电脑无线验收准备见[LoRa工具说明](../Tools/LoRa测试工具说明.md)。教学箱传感器、GNSS可用定位环境、SD卡、RPi/USB-TTL和第二E22分别覆盖对应验收；电机动态与保护测试仍需实际电调/电机条件。
