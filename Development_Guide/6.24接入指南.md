# 6.24接入指南

本文档是 2026-06-24 边界收口后的外设接入入口指南。后续新增 LoRa 收发、通信外设、传感器、显示项或状态类模块时，必须以本文为入口，并同步遵守 `01_统一开发手册.md`、`02_架构边界与数据流.md`、`03_模块接入手册.md` 和 `05_完成度与后续清单.md`。

## 1. 总原则

- 保持单向依赖：Core -> Business -> Framework -> Platform Adapter -> Driver -> BSP -> HAL。
- `main.c` 只做组合根，不承载协议解析、业务策略或外设细节。
- Framework 普通文件不得直接包含 BSP 头文件；`Framework/Src/px4lite_platform_f407.c` 是 Framework 层唯一 BSP/Driver 适配入口。
- Business 和 Display 只能通过 `app_data_api.h` 读取应用视图或状态，不得读取 Framework topic、BSP DMA buffer 或 Driver 私有变量。
- 新增外设必须补齐初始化链路：HAL config、Keil source list、`MX_xxx_Init` 风格入口、MSP GPIO/clock/DMA/NVIC、interrupt handler 和 FreeRTOS 所属任务。

## 2. 目录归属

| 类型 | 目录 | 说明 |
|---|---|---|
| 普通传感器 | `Sensor/Inc` / `Sensor/Src` | 芯片协议、解析、校准和传感器事实状态 |
| 通信 Driver | `Driver/Comm/Inc` / `Driver/Comm/Src` | LoRa、5G-A、CAN、UART modem 等通信类驱动 |
| BSP | `Bsp/Inc` / `Bsp/Src` | 引脚、总线、DMA、中断和原始收发 |
| Framework 适配 | `Framework/Src/px4lite_platform_f407.c` | Driver/BSP 到 Framework 类型转换 |
| Business API | `Business/Inc/app_data_api.h` / `Business/Src/app_data_api.c` | 应用层统一读取入口 |
| Display | `Display/Inc` / `Display/Src` | 页面模型、渲染和触摸处理，不直接依赖 Framework 枚举 |

LoRa E22 的正式位置为 `Driver/Comm/Inc/lora_e22.h` 和 `Driver/Comm/Src/lora_e22.c`。后续通信类 Driver 不再放入 `Sensor/`。

## 3. 栈约束

- 周期任务不得在栈上创建完整系统快照、完整告警表、全量显示视图或 LoRa 大 payload。
- 聚合视图使用文件级静态 scratch、summary 接口、固定块池或固定队列。
- `biz_display` 使用 `App_CopyDisplaySnapshot()` 输出的静态显示视图，不在任务栈上拼完整界面数据。
- `comm` 不拼全量大包；MAVLink/LoRa 外发必须按 Telemetry Catalog 分项读取和编码。
- `health` 和 `debug` 读取告警 summary 或单条 record，不复制完整告警表到任务栈。
- 新增任务必须记录周期、优先级、栈预算、最长执行时间和 DebugTaskMonitor 栈水位。

## 4. LoRa 收发接入要求

1. BSP 只负责 UART/DMA/IRQ、AUX/M0/M1 引脚和原始 tx/rx。
2. `Driver/Comm` 负责 LoRa E22 协议状态、异步发送状态、最近 RX 帧事实和恢复请求。
3. `comm` 任务是 LoRa RX/TX 的任务所有者，不为普通通信收发再拆新任务。
4. `Lora_E22_Send()` 保持异步 copy 语义；返回 OK 只代表帧进入发送流程，真正完成以 UART DMA TC 回调为准。
5. MAVLink 必须逐字段编码，禁止直接发送 C struct 内存。
6. RX 先保留协议事实和最近帧接口；主从字段、时隙、重传和 ACK 策略后续单独定义，不提前写成已完成能力。

## 5. Display 接入要求

- Display 页面层不得包含 Framework 故障头文件或模块枚举。
- 模块名、故障原因、状态灯、告警列表、离线清屏策略统一通过 `app_data_api.h` 获取。
- 新增显示值必须先进入 Framework topic 或 App 快照，再由 Display 和 LoRa 使用同源数据。
- 触摸输入只调用 Business/App 命令入口，不直接写 Framework 或 Driver 内部状态。

## 6. 评审门禁

- Keil 工程必须同步 include path 和 source list。
- 固件源码、Keil 工程或外设配置修改后必须执行 Keil Rebuild All。
- 发布目标为 `formal_framework.axf - 0 Error(s), 0 Warning(s)`。
- 当前 2026-06-24 最终收口已验证通过，记录见 `Change_History/2026-06-24_34_LoRa与Display最终边界收口.md`。
