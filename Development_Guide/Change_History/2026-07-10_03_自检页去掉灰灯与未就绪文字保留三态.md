# 2026-07-10_03 自检页去掉灰灯与"未就绪"文字，状态只保留红/黄/绿三态

## 修改原因和风险

- **原因**:自检页每个模块行为 `[彩色灯] + [名称] + [状态文字]`,灯色四态、文字四态:
  - 值2 绿 / `正常`
  - 值1 黄 / `警告`
  - 值0 **灰** / `未就绪`
  - 值3 红 / `故障`
  其中 value 0(未就绪/未初始化)的**灰灯**与**"未就绪"文字**为冗余,按需求删除。**状态文字这一列保留**(正常/警告/故障),只是不再出现灰色和"未就绪"。
- **方案**:把 value 0 并入红色/故障——灯只剩红黄绿三态,文字只剩正常/警告/故障三种。状态灯与状态文字都保留,仅去掉第四态。
- **风险/影响**:
  - value 0(未初始化/被禁用)现显示为**红灯 + "故障"**,与离线/故障(值3)一致:上电初期未上线的模块会先红后转绿,属预期。
  - 判据来源(Framework 模块状态 → `Display_MapStateValue`/`MapCommStateValue`)不变;只改显示层的颜色与文字映射,不影响任何状态逻辑。

## 涉及文件

- `Display/Src/display_lvgl.c`:
  - `Display_LvglStatusColor`:删除 value 0 的灰色(`LV_PALETTE_GREY`)分支,并入红色。状态灯只余绿/黄/红。
  - `Display_LvglStatusText`:删除 value 0 的"未就绪"分支,并入"故障"。状态文字只余 正常/警告/故障。
  - `Display_LvglCreateSelfCheckPage`:状态文字标签(`Display_LvglCreateValueLabel`)**保留不变**(此前一版误删,已恢复)。

## 行为变化

- 自检页每个模块仍显示 `灯 + 名称 + 状态文字`。
- 状态灯:**绿=在线,黄=启动/降级,红=离线/故障/未初始化**(无灰)。
- 状态文字:**正常 / 警告 / 故障**(无"未就绪"),与灯色一一对应。
- 右侧"自检汇总"告警表、消息日志面板不在本次范围,保持不变。

  3. 全程无灰色灯、无"未就绪"文字。
