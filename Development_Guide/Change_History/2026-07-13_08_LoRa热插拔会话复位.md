# 2026-07-13 LoRa 热插拔会话复位

## 变更范围

- `Sensor/Src/lora_e22.c`
- `Framework/Inc/px4lite_remote_telemetry.h`
- `Framework/Src/px4lite_remote_telemetry.c`
- `Framework/Src/px4lite_modules.c`

## 变更说明

- LoRa 拔出后，驱动会执行一次会话复位：
  - 停止当前 LoRa TX DMA 发送流程。
  - 清空 LoRa RX 队列和 MAVLink 解析器状态。
  - 清零 `rx_frame_count`、`tx_frame_count`、丢包估算、CRC/解析/发送错误和最后收发时间。
  - 清空待发送帧和发送状态机，避免拔出前残留帧在重新插入后继续发送。
- LoRa 断开时，Framework 会同步清空远端遥测缓存：
  - 清空远端节点表。
  - 清空远端序号统计。
  - 清空已选远端节点，恢复默认节点选择。
- LoRa 插回且 AUX ready 后，`comm` 周期会重新触发 BSP 和 E22 初始化。
- 插回后收发统计从 0 重新计算，屏幕上发送/接收计数不再沿用拔出前的旧值。

## 行为口径

- 拔掉 E22：LoRa 状态变为离线，发送/接收计数显示为 0，远端节点和远端数据清空。
- 插上 E22：LoRa 重新初始化，状态恢复在线后重新收发，发送/接收计数从 0 开始增长。
- 是否收到对端 LoRa 数据不影响本机 LoRa 在位灯，只有本机 E22 硬件不可用才判离线。
