# 2026-07-08_22_环境电池改用官方MAVLink通道

## 背景

依据 RPi 侧《建议：部分自定义 NAMED_VALUE_INT 字段改走官方 MAVLink 通道》(2026-07-08)。抓包发现固件新增的 4 个 `NAMED_VALUE_INT`(`BAROTEMP`/`BAROPRES`/`BAT1CUR`/`BAT2CUR`)里,3 个与已有官方 MAVLink 字段是同一物理量的重复表达。本次按建议把它们收敛到官方消息。

> **注意**:本篇的建议① 恰好**回退**了 `2026-07-08_16`(温度/气压"以湿度为准"拆成 NAMED_VALUE)。经确认采纳 RPi 侧建议,改回官方 `SCALED_PRESSURE`。

## 改动

### ① 温度/气压 → 官方 `SCALED_PRESSURE`(msgID 29)
- TX:删 `MavTx_SendBaroTemperature`/`MavTx_SendBaroPressure` 两个 NAMED_VALUE 编码器,合回 `MavTx_SendScaledPressure`(一帧带 `press_abs`(hPa)+`temperature`(cdegC),`press_diff`=0)。两 catalog 各把 `BAROTEMP`+`BAROPRES` 合成一项 `PRESSURE`(msgID SCALED_PRESSURE, scope STANDARD/ALWAYS)。
- RX:删 `BAROTEMP`/`BAROPRES` name 分支,恢复 `MavRx_DecodePressure`(SCALED_PRESSURE → pressure_pa + temperature_c)+`case MAVLINK_MSG_ID_SCALED_PRESSURE`。
- 删 statics `s_next_baro_temp_ms`/`s_baro_temp_count`;config `ENABLE_SCALED_PRESSURE` 注释回退。

### ② 删除冗余 `BAT1CUR`
- `BATTERY_STATUS.current_battery` 已覆盖电池1电流(抓包 `current_battery×10 == BAT1CUR`)。
- TX:删 `MavTx_SendBattery1Current` + 两 catalog 项 + statics(`s_battery1_current_count`/`s_next_battery1_current_ms`/`s_last_battery1_current_sequence`)。
- RX:删 `BAT1CUR` name 分支(`remote->current_ma` 已由 `MavRx_DecodeBattery` 从 BATTERY_STATUS 填)。

### ③ 电池2 → 官方 `BATTERY_STATUS(id=1)`
- MAVLink 用 `BATTERY_STATUS.id` 区分多块电池,取代 `BAT2STAT`/`BAT2CUR` 两个自定义帧。
- TX:删 `MavTx_SendBattery2Status`/`MavTx_SendBattery2Current`,新增 `MavTx_SendBattery2`(BATTERY_STATUS `id=1`,`voltages[0]`=电压 mV、`current_battery`=电流 cA、`battery_remaining`=百分比、`charge_state`=低压)。两 catalog 各把两项合成一项 `BATTERY2`。保留 per-target 去重 `s_last_battery2_sequence[2]`;删 `s_battery2_current_count`/`s_next_battery2_current_ms`/`s_last_battery2_current_sequence`。
- RX:`MavRx_DecodeBattery` 按 `packet.id` 分流——`id=1`→电池2(voltage2_mv/current2_ma/battery2_percent/low_voltage2),其余→电池1;删 `BAT2STAT`/`BAT2CUR` name 分支。

## 效果

- 环境:一帧标准 `SCALED_PRESSURE` 带温度+气压(还多一个 `press_diff` 坑位),比两个自定义帧更标准、更省。
- 电池:电池1/2 都走标准 `BATTERY_STATUS`(id=0/1),QGC 等地面站可直接识别;删掉 3 个冗余/自定义 NAMED_VALUE。
- 两块板同程序一起重编译即自洽;RPi 侧按其文档,M4 先按当前格式接入,固件切官方通道后 RPi 再删自定义分支、改读官方字段。

## 影响面 / 注意

- 这三条都改了 LoRa/屏幕 RX 契约,但两板同程序,一起烧录即一致。
- `BAT2CUR` 是真正新增数据(电池2电流),现随 `BATTERY_STATUS(id=1).current_battery` 一并携带,信息不丢。
- 建议① 回退了 2026-07-08_16;字库 差/浮/固 那档事(定位状态)与本篇无关。

## 改动文件

- `Framework/Src/px4lite_mavlink_tx.c`:SCALED_PRESSURE 编码器复原;删 BAT1CUR;Battery2 改 BATTERY_STATUS(id=1);两 catalog 收敛;statics/init 清理。
- `Framework/Src/px4lite_mavlink_rx.c`:恢复 SCALED_PRESSURE 解码+case;Battery 按 id 分流;删 BAT1CUR/BAT2STAT/BAT2CUR/BAROTEMP/BAROPRES 分支。
- `Framework/Inc/px4lite_config.h`:ENABLE_SCALED_PRESSURE 注释回退。
