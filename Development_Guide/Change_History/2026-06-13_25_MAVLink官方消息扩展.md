# 2026-06-13 25 MAVLink 官方消息扩展

## 背景

本轮目标是把当前正式数据链路里已经生成的结果,按 MAVLink common
官方消息发送给地面站。通信层不手写 MAVLink 字节帧,也不引入自定义 dialect;
所有遥测帧继续由官方 `mavlink_msg_*_encode_chan()` 编码,再交给 LoRa 发送。

## 数据映射

- `HEARTBEAT`: 飞控/教学箱在线心跳。
- `ATTITUDE`: 姿态角和角速度,来自 Navigation 快照。
- `GPS_RAW_INT`: GNSS 有定位时发送经纬度、高度、星数和 fix 状态。
- `NAMED_VALUE_INT("GNSS_SAT")`: GNSS 卫星细节补充,仅作为调试型官方消息。
- `SYS_STATUS`: 模块健康摘要,并带上电池电压、电流和电量百分比。
- `BATTERY_STATUS`: 电源电压、剩余百分比、低压状态。
- `SCALED_PRESSURE`: 气压和温度。
- `STATUSTEXT`: 当前最高活动告警,例如 `PX4LITE ALARM LORA 0x0301`。

## 代码变更

- `px4lite_mavlink_tx.c/h` 增加 `BATTERY_STATUS`、`SCALED_PRESSURE`、
  `STATUSTEXT` 调度槽和发送统计。
- `SYS_STATUS` 补充电池字段,便于地面站基础状态页显示。
- `px4lite_config.h` 增加各类 MAVLink 标准消息开关和周期。
- `Px4Lite_GetCommDebugInfo()` 回填新增 MAVLink 发送计数。
- LoRa Debug 输出增加
  `mav(hb/gps/gnss/att/sys/bat/baro/txt)` 计数,用于确认每类消息是否真的发出。

## 边界

- Debug 串口仍然只观察正式链路的结果,不替代 MAVLink 发送链路采集数据。
- 屏幕暂不细调;后续屏幕仍从 `App_Copy*` / Topic 快照读取同一份结果。
- 地面站能否稳定识别还取决于 LoRa 空口接线、波特率、透明传输模式和地面端串口配置。
