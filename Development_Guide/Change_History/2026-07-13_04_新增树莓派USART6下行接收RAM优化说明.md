# 新增树莓派 USART6 下行接收 RAM 优化说明

## 变更时间

2026-07-13

## 变更内容

新增 `Development_Guide/树莓派USART6下行接收RAM优化说明.md`，记录树莓派 USART6 下行接收链路引发 Keil `L6406E` RAM 不足的原因和优化方案。

文档覆盖：

- `L6406E No space in execution regions` 的原因说明。
- 当前 Keil scatter 只使用 128KB SRAM1 的背景。
- USART6 RX 环形缓冲由 512 byte 缩小到 128 byte 的依据。
- RPi MAVLink 8 帧静态队列改为单帧待处理缓存的原因。
- 对现有本机滑条、树莓派下发、ACK、LoRa 远端显示等功能的影响边界。
- ARMCC 单文件编译检查结果和后续 Keil Rebuild All 复核要求。

## 说明

该文档用于后续维护和联调排查。固件行为以源码为准；正式烧录前仍需执行 Keil Rebuild All 并确认 `0 Error(s), 0 Warning(s)`。
