# 2026-06-23 变更记录：LoRa 远程显示第二阶段

## 变更内容

- `Framework/Inc/px4lite_config.h` 增加手动目标 `PX4LITE_REMOTE_TARGET_SYSID_DEFAULT`、远端设备表容量和远程显示扩展发送周期配置；本阶段仍按手动 `sysid` 分配，STM32 Unique ID 派生先保留不做。
- `Framework/Src/px4lite_remote_telemetry.c` 增加远端设备观测表、设备状态口径、字段级更新时间、字段 stale 位和字段级过期判断；字段短暂过期时保留最后远端值，不再直接清零。
- `Framework/Src/px4lite_mavlink_rx.c` 解析 `TIME_LOC`、`DATE_LOC`、`HUMIDITY`、`MOTOR12`、`MOTOR34`，并在非目标设备心跳到达时只更新设备表、不写远端快照。
- `Framework/Src/px4lite_mavlink_tx.c` 增加远程显示扩展轮转槽，使用标准 `NAMED_VALUE_INT` 逐字段发送远端时间、日期、湿度和四路电机占空比；电机 PWM 变化时优先发送并短时重复，降低远端滑块同步延迟。
- `Display/Src/display.c` 在 REMOTE 模式下显示远端时间、湿度和电机占空比；远端字段未收到时保持无效，已收到但过期时由 `stale_mask` 标记并保留最后远端值。
- `Display/Src/display.c` 与 `Business/Src/app_data_api.c` 增加双层保护：REMOTE 模式下电机滑块触摸和 Business 控制 API 均拒绝写本机 Control。
- `Tests/Unit/test_mavlink_rx_remote_telemetry.c` 补充设备表、扩展字段和字段级 stale 旧值保留测试。
- `Tests/Unit/test_mavlink_tx_motor_priority.c` 覆盖电机 PWM 变化后优先发送 `MOTOR12` 的调度行为。
- 更新 `Development_Guide/17_LoRa远程显示与可靠链路方案.md`，记录第二阶段已完成项和后续保留项。

## 边界说明

- `LOCAL` 模式仍可保留本机电机滑块控制行为，具体执行以 Control 模块和本机安全门禁为准。
- `REMOTE` 模式只看远端电机状态，不改远端电机状态。
- 第二阶段文档和 UI 文案不得把收到 `HEARTBEAT` 称为“连接成功”；收到目标有效遥测后才进入 `ACTIVE` 显示。
- 如果多台远端设备使用相同 MAVLink `sysid`，仅靠 `HEARTBEAT` 无法区分，必须依赖后续绑定、Remote ID、信道或协议层身份增强。
- 远端设备表 UI、屏幕上的人工选择控件、完整模块状态、完整告警表和 Unique ID 派生 `sysid` 不在本次实现范围。
