# 2026-06-24_39 电池电量重排、电机低压停机与充电提示

## 一、需求

3S 锂电，9.0V 为下限。电压分档与行为：

电机电池(ADC2)分档（**没插电池时 ADC2 无数据=断开**，插上才有读数）：

| 电压 | 状态 | 行为 |
|------|------|------|
| ≥10.5V | 正常 | 电机可运行 |
| 9.9~10.5V | 低电 | 电机可运行，**消息提示需充电** |
| 9.0~9.9V | 供电不足 | **电机不能启动**（停机/锁 PWM），消息+告警“电机供电不足” |
| 5.0~9.0V | 没电 | 已插电池但电量耗尽，电机停机/锁 PWM，消息“电机电池没电”+告警 |
| <5.0V | 断开 | 未插电池，电压/电量显示 0，消息“电机断开”+告警 |

主控电池(ADC1)：<5V 未接入显示 0；5~10.5V 提示“主控需充电”。

- 电池百分比按 9.0~12.6V 重排（主控 ADC1、电机 ADC2 同款）。
- 电机电池插上后持续运行；<9.9V 电机自动停机且滑动 PWM 滑块无反应；恢复 ≥9.9V 自动解锁。
- 主控电池 <10.5V 同样消息提示需充电。

## 二、改动

### 1. 电量百分比（线性、5% 步进）

[sensor_power.c](../../Sensor/Src/sensor_power.c) / [sensor_power2.c](../../Sensor/Src/sensor_power2.c)：`*_CalcPercent` 改为 9.0V=0%、12.6V=100% 的**线性映射**（5% 步进，保留 200mV 滞回 + 10 次确认防跳变），反函数 `*_PercentCenterMv` 同步。常量精简为 `*_EMPTY_MV=9000 / *_FULL_MV=12600`，`low_voltage` 阈值 <9.0V。

### 2. 显示门限（[display.c](../../Display/Src/display.c)）

```
DISPLAY_MOTOR_BAT_CONNECT_MV = 5000   在位/断开门限：<5V 未插电池(断开)，电压电量显示 0
DISPLAY_MOTOR_BAT_DEAD_MV    = 9000   没电门限：已插电池但 <9V
DISPLAY_MOTOR_BAT_RUN_MV     = 9900   电机可启动门限：<9.9V 停机+锁 PWM
DISPLAY_MOTOR_BAT_OK_MV      = 10500  低于提示充电
DISPLAY_MAIN_BAT_PRESENT_MV  = 5000   主控在位/显示 0
DISPLAY_MAIN_BAT_CHARGE_MV   = 10500  主控低于提示充电
```

电机自检灯：<9.9V 红、9.9~10.5V 黄、≥10.5V 绿。
注：电机“未接入显示 0”门限由此前的 9V 收紧为 **5V**（区分“没插电池=断开”与“插了但没电”），覆盖记录 38 中该项。

### 3. 电机低压停机 + 锁 PWM

- `Display_LoadEnvironmentSnapshot`（每次快照、与页面无关）：电机电池 **<9.9V** → 置 `s_motor_bat_cutoff` 并 `Display_ForceMotorsOff()` 强制四路油门清零；≥9.9V 解锁。
- `Display_SetMotorThrottleCommand`：cutoff 期间忽略滑块输入（滑动无反应）。
- <9.0V 时电机电压/电量显示 0（“没电”）。

### 4. 消息 + 告警

新增字模 没/充/需/要（[display_text.c](../../Display/Src/display_text.c) `s_mlg_table`）与日志短语：

| 消息 | 文本 | 触发 |
|------|------|------|
| `DISPLAY_LOGMSG_MOTOR_DISCONNECT` | 电机断开 | 电机 <5.0V（未插电池）|
| `DISPLAY_LOGMSG_MOTOR_DEAD` | 电机电池没电 | 电机 5.0~9.0V |
| `DISPLAY_LOGMSG_MOTOR_LOWPOWER` | 电机供电不足 | 电机 9.0~9.9V |
| `DISPLAY_LOGMSG_MOTOR_CHARGE` | 电机电池需充电 | 电机 9.9~10.5V |
| `DISPLAY_LOGMSG_MAIN_CHARGE` | 主控电池需充电 | 主控 5.0~10.5V |

`Display_MotorLogMsg` 改为五档；新增 `Display_MainBatteryLogMsg` 与去抖 `db_main`，按变化追加日志。“主控”的“控”字用与现有主控标签一致的字模（`s_mlg_kong_aircraft`），避免与“电机控制”里的控字模混用导致显示异常。

**告警页同步提示**：新增故障码 `PX4LITE_FAULT_MOTOR_DEAD/MOTOR_CHARGE/POWER_CHARGE`（[px4lite_faults.h](../../Framework/Inc/px4lite_faults.h)）。`Display_EvalMotorFault` 四档（<5 断开 / 5~9 没电 / 9~9.9 供电不足 / 9.9~10.5 需充电），新增 `Display_EvalMainFault`（主控 5~10.5V 需充电）；`Display_LoadAlarmSnapshot` 把电机与主控告警一并注入告警表与自检错误码表。告警表原因栏对这三种电池告警改用消息日志字模拼绘（`Display_PagesAlarmReasonLogMsg` + `Display_TextDrawLogMessage`），模块栏电机=电机字模、主控=电源字模。

### 5. 阈值滞回（防噪声横跳）

电压有约 0.1V 浮动，直接按阈值分类会在边界反复横跳（告警/灯/停机/消息抖动）。新增带 **200mV 滞回**的档位状态机：`Display_BatBandHyst` + `Display_UpdateBatteryBands`，每次快照按 `voltage2_mv`/`voltage_mv` 更新 `s_motor_band`(0断开/1没电/2供电不足/3需充电/4正常) 与 `s_main_band`(0未接入/1需充电/2正常)。进入某档后需电压反向越过阈值 200mV 才换档（即每个阈值形成约 ±0.2V 滞回带），>0.1V 噪声。**所有判定**（电压/电量显示 0、电机停机+锁 PWM、自检灯、电机/主控消息、电机/主控告警）统一读档位，不再各自比较电压。

## 四、未做 / 待确认

## 五、验证

- 电机电池缓降：≥10.5V 绿；9.9~10.5V 黄+“电机需充电”；9.0~9.9V 红+“电机供电不足”+告警+电机停机/滑块锁定；<9.0V 电压电量 0+“电机电池没电”；回升 ≥9.9V 自动恢复可控。
- 主控电池 <10.5V 出现“主控需充电”；<5V 显示 0。
- 电量百分比随电压在 9.0~12.6V 间以 5% 平滑变化。
