# 2026-07-13_07 LoRa 通信与远端显示同步修复

## 变更摘要

- LoRa 发送调度允许在半双工 `BUSY` 状态下进入调度器，由发送器内部继续判断 DMA 是否空闲，修复电机、消息日志、告警扩展帧排不上发送的问题。
- 树莓派 USART6 下行解析与 LoRa 空口解析分离，RPi 只处理控制类下行帧，不覆盖 LoRa 远端遥测。
- LoRa 告警发送保留 `ALRMHI/ALRMMSK` 摘要，同时补发 `TUNNEL 0x8001` 完整告警表。
- 远端显示快照按 `alarm_active_mask` 展开完整告警列表，不再只显示最高告警。
- 电机页改用 `App_GetDisplayMotor()`，远端模式下显示远端电机值。
