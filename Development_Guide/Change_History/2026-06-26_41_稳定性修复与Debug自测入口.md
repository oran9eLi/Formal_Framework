# 2026-06-26 稳定性修复与 Debug 自测入口

## 1. 背景

本次收口针对 IMU snapshot 竞态、BSP 初始化失败定位、调试 UART 配置一致性、LVGL 刷新预算和后续逐项硬件验证入口。目标是在不改变生产数据路径的前提下，让后续 Debug 能按模块逐个验证。

## 2. 代码变更

1. `Sensor/Src/sensor_mpu6050.c` 的 snapshot 写入、清空、复制和状态读取统一使用 `BSP_Critical_Enter()` / `BSP_Critical_Exit()`，避免 estimator 读取到半截结构体。
2. `Bsp/Src/bsp.c` 记录 `enabled/attempted/failed` 初始化位图，`BSP_Init()` 不再让后一个成功覆盖前一个失败。
3. `Bsp/Src/bsp_uart.c` 按 `bsp_config.h` 的 UART 宏配置 HAL 句柄，并提供只读配置快照。
4. `Debug/Src/debug_selftest.c` 新增默认关闭的分项自测入口，支持 IMU snapshot、BSP init、LVGL budget、远端节点视图和 GT911 诊断打印。
5. `Debug/Src/debug_service.c` 在 DebugTask 中按 `DEBUG_SELFTEST_REPORT_PERIOD_MS` 调度自测入口；未打开自测开关时不产生额外运行负载。
6. `Display` facade 暴露 LVGL 刷新预算统计，供 Debug 自测只读打印。

## 3. 边界要求

1. Debug 自测是跨层诊断特例，只能在 `Debug/` 中读取 BSP、Driver 或 Display 后端的只读诊断接口。
2. Business 和 Display 正式页面仍必须通过 `app_data_api.h` 读取业务数据，不得直接读取 Driver、BSP、DMA buffer 或 Framework topic。
3. 自测项必须默认关闭；现场验证时先打开 `DEBUG_SELFTEST_ENABLE`，再一次只打开一个 `DEBUG_SELFTEST_*` 单项。
4. 自测代码不得执行外设重新初始化、协议发送、SD 写入或 UI 渲染。
