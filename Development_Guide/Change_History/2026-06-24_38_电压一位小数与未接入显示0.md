# 2026-06-24_38 电压一位小数与未接入显示 0

## 一、需求

主控电压(ADC1)与电机电压(ADC2)：
1. 只显示**一位小数**（如 11.8V）。
2. **接入后才显示数据，未接入显示 0**（电压、电量均归 0）。

## 二、改动

### 1. 一位小数

[display_pages.c](../../Display/Src/display_pages.c) `Display_PagesDrawField` 中电压分支：`Display_PagesFmtUnsigned(..., 2U, 100U)` → `1U, 100U`，即由两位小数改为一位（值仍为 0.01V 单位，whole=值/100、frac=值%100，按一位小数取整输出）。主控/电机两路共用该分支，一并生效。

### 2. 未接入显示 0

[display.c](../../Display/Src/display.c) `Display_LoadEnvironmentSnapshot`：按在位门限判定，未接入时电压与电量都写 0，接入才写真实值。

| 通道 | 在位门限 | 说明 |
|------|---------|------|
| 主控(ADC1) | `DISPLAY_MAIN_BAT_PRESENT_MV` = 5000mV | 与 sensor_power 的 `POWER_PRESENT_MV` 一致 |
| 电机(ADC2) | `DISPLAY_MOTOR_BAT_PRESENT_MV` = 9000mV | 沿用既有“电机断开”门限（<9V 即视为断开） |

低于门限：`BATTERY_VOLTAGE`/`BATTERY_PERCENT`、`MOTOR_BAT_VOLTAGE`/`MOTOR_BAT_PERCENT` 全写 0。

## 三、验证建议

- 接入主控/电机电池：电压显示一位小数（如 11.8V），电量正常。
- 拔掉对应电池：该路电压显示 0.0V、电量 0。
- 电机电池在 9.0~9.9V（接入但低电）应显示真实电压而非 0（仍判为接入）。

## 四、未验证

本机无编译环境，未编译验证。电机“未接入”沿用既有 <9V 门限，与电机断开/告警语义一致；如需把“低电但接入”也显示真实值的更低门限，调整 `DISPLAY_MOTOR_BAT_PRESENT_MV` 的取舍即可。
