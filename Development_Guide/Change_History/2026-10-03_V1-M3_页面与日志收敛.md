# V1-M3 页面与日志收敛

日期：2026-10-03。范围与状态分别见 [M3 实施计划](../../Release/V1.0_M3_实施计划.md)和[执行台账](../../Release/V1.0_执行台账.md)。

## 页面与数据边界

- 六个中文主入口保留，本机导航、环境、电源、控制和告警始终读取本机 App 快照。旧 `App_SetRemoteViewEnabled(1)` 返回拒绝；选择对端不修改生产发送开关。
- 移除品牌区及工程中的 Logo 资源引用；非自检页取消重复模块灯。自检显示实际模块状态，电机区域表示 PWM/控制模块，不推断电机机械连接。
- `Diagnostics` 合并模块状态、故障码、状态持续时间、错误/恢复计数与 LCD/触摸运行状态。`Event history` 集中本机事件。`Comm` 提供本机收发统计和远端心跳发现列表；M4 继续完成手动通信和远端实验数据页。
- 六主页面及 Comm 底部显示最近 3 条短英文事件；Diagnostics 和历史页使用完整内容区。无跑马灯，二级页可返回原主入口。
- Freeze 仅暂停观察数据更新，时间、告警、事件、控制和保护继续运行；Resume 后重新显示当前数据。
- LVGL 页面对象启动创建、切页复用，文字使用静态缓冲；保留 40 KiB LVGL 堆。库内部绘制临时分配、峰值/碎片和实际刷新耗时仍需资源验收，不能仅以对象复用宣称无运行时分配或达到 2 ms 硬预算。

## 事件职责

```text
Control / Attitude 实际状态转移 ──┐
                                ├─ Framework 本机事件环 ─ App 只读快照 ─ Display
Business 200 ms 状态观察 ─────────┘                     └ RPi 旧日志表
```

- 本机状态观察从显示更新移到 `Business_AcquisitionTask`。启动仅初始化观察器；显示恢复及通信重新初始化不清空事件。
- 模块状态、定位状态、电源和告警分别记录。普通状态候选连续稳定 1500 ms 后确认，时间保留候选首次观察的 Uptime；控制保护与操作结果直接记录，不等待去抖。
- 启动检查集合限定 GNSS、IMU、Baro、LoRa、SD，禁用项排除。不使用“全部自检通过”替代整机验收。
- GNSS no fix 与 RX timeout 分开；动力电压描述不代表电机机械健康；RID 检出、UART 提交、上游网络报告分别表达。
- RID 编码/提交错误计数改为本次上电累计，热恢复保留；避免统计清零制造虚假错误或掩盖恢复后的新错误。RPi `RIDSTAT` 仍发送该累计计数低 16 位，字节布局不变。
- 操作由 Control/Attitude 所属状态机记录接受、拒绝、开始、完成、中止和急停。同步升速、缓降和最小输出使用对应操作名称，PWM 写入成功不等同于电机实际停止。
- 活动告警与历史事件分开；读取失败为 unavailable/N/A，不能显示“无告警”。

## 容量与兼容

| 项目 | 固定边界 |
|---|---|
| 本机事件环 | 32 条，容量满覆盖最旧；读取不生成事件 |
| 普通页面 | 最近 3 条，短静态英文与真实严重度 |
| 历史 | 分页、严重度筛选、清视图；清视图不擦除生产事件 |
| 本机消费 | 完整快照及 version；不按普通 sequence 大小判新旧 |
| 序号 | 1—65535 循环、跳过 0；旧增量接口按环中位置查找游标 |
| RPi `0x8002` | 保持最新 9 条、75 B payload 与原字段布局 |
| 旧远端缓存 | 独立 9 条，不随本机环扩容；完整 LoRa 历史退出归 M4 |

消息 ID 0—37 保持编号，新增英文目录从尾部追加至 174。RPi 应用需要同步 `Framework/Inc/px4lite_log_message_ids.h` / `Framework/Src/px4lite_local_msglog.c` 的消息目录；仅保持包布局不代表旧应用能够解释新增 ID。旧 RPi 日志包没有会话字段，重启/断连后的对端会话处理及回绕覆盖还需验证；本轮不能关闭 L15 的全部跨端验收。

本次构建身份、实际结果与未验收项见 [M3 验证记录](../../Release/V1.0_M3_验证记录.md)。
