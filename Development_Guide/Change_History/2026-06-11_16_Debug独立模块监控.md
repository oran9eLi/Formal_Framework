# Debug 独立模块监控改造

日期：2026-06-11

## 改造内容

- 删除旧的 `DEBUG_ENABLE`、`DEBUG_PERIODIC_ENABLE` 等嵌套开关。
- 堆栈、GNSS、GNSS BSP、业务日志及后续模块使用并列独立宏。
- 新增低优先级 `DebugTask`，统一调度周期诊断。
- 从 `HealthTask` 移除 GNSS 和任务栈周期打印。
- 任务监控注册容量由 8 个提高到 16 个。
- GNSS 正式驱动不再包含 Debug 头文件。

## 默认配置

- 启动日志：开启。
- 所有已注册任务的 Stack/Heap 监控：开启。
- GNSS 周期数据：关闭。
- GNSS BSP 中断/DMA 诊断：关闭。
- 其他预留模块：关闭。

## 使用方式

进行单个外设测试时，同时开启：

```c
DEBUG_STACK_MONITOR_ENABLE
DEBUG_<MODULE>_MONITOR_ENABLE
```

只进行整机任务资源测试时，仅开启：

```c
DEBUG_STACK_MONITOR_ENABLE
```

## 台架验证

默认“只开启堆栈监控”配置已在 STM32F407ZGT6 实机运行：

```text
heap_free=21400
heap_peak_used=19560
sensor      peak=240W min_free=144W/576B
estimator   peak=54W  min_free=330W/1320B
health      peak=167W min_free=217W/868B
biz_system  peak=56W  min_free=264W/1056B
biz_acq     peak=78W  min_free=306W/1224B
biz_display peak=29W  min_free=355W/1420B
debug       peak=146W min_free=238W/952B
```

验证结论：

- 所有已注册任务均被统一报告。
- 周期重复报告稳定，Heap 最小值未继续下降。
- `HealthTask` 移除格式化输出后，栈峰值由 195W 降至 167W。
- 新增 `DebugTask` 栈余量为 952B，保留 384W 配置以支持模块联合调试。
- “Stack + GNSS”组合也已通过 ARMCC5 全量编译。
