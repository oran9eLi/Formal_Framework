# V1-M2 数据、收发与恢复修复

日期：2026-09-28。适用源码：`develop / bbf917f` 加已有 M1 和本轮 M2 工作区修改。

本记录说明实际软件行为变更。构建、回归和产物身份见 [M2 验证记录](../../Release/V1.0_M2_验证记录.md)，任务状态以 [执行台账](../../Release/V1.0_执行台账.md) 为准。实板和长稳尚未执行。

## 1. 数据契约

- GNSS 分开记录链路活动与位置、速度、UTC、高度四个测量域。GSA/GSV 不为旧定位、速度或 UTC 续期；合法毫秒零值仍是采样时刻。
- Navigation 增加 UTC 有效位与实际 IMU 姿态更新时间。Estimator 在新样本到来或有效位变化时发布；短 FIFO 间隙可使用尚新鲜的姿态，超时撤销有效位。
- Remote 保留八槽，导航四域、温压/湿度、电池 1/2 分别检查年龄；电池电压、电流、电量分别记录有效性，协议未知值不能更新旧字段为有效。
- App 环境快照增加八个细有效位。复用 Power/Battery 结构保留字节记录 `current_valid`，有效零电流与采集失败不同，电流失败不清有效电压。
- 屏幕通过 App 细有效位更新，过期或未知显示 `--`；失效的 LVGL 主标签及别名同步清除有效状态，恢复时即使数值相同也会重绘。姿态画布隐藏/恢复复用已有对象。
- 电池档位及显示侧告警只消费对应有效电压，模块整体状态不再二次清空独立电池字段。无可信 UTC 时不以运行时间或编译日期填充时钟字段。
- CSV 定位年龄使用位置时刻，姿态年龄和样本列使用真实 IMU 时刻，均检查对应有效位。CSV 格式版本未变。

## 2. 通信与并发

- LoRa 和 RPi 复位 MAVLink 库实际持有的解析上下文，覆盖半帧超时、重新初始化、UART 恢复及波特率切换。
- 接收 CRC 拒绝、解析拒绝、完整帧队列丢弃、DMA 覆盖与序号缺口各按自身语义计数；不再对每字节错误输出做累计差值。
- GNSS 环形 DMA 的位置读取与软件队列更新处于同一保存/恢复 PRIMASK 保护区；ISR 仍不解析协议。
- 远端槽位的身份查找、复制及提交在各自完整临界区中完成，防止查找后被第九节点置换造成串号；淘汰年龄支持计时回绕。
- GNSS 恢复请求由 Health 设置请求标志，采集任务消费并执行；浮点换算位于快照临界区外。

## 3. 测量与恢复

- 横滚互补滤波按最短角差修正并归一化，避免跨 ±180° 绕远。
- 常规电流 ADC 读取保持模拟输入，浮空预充完整受默认关闭的诊断开关控制；高优先级采集路径不再打印电流诊断，低优先级 Debug 读取快照。
- BME280 的测量触发许可与状态机推进分开：仍按既定周期启动，每个 sensor 周期推进等待与读取，使用实际触发时刻标记样本。
- SD 各文件阶段失败统一清理并降级，保留首个错误、错误阶段和累计写丢弃；退避从清理完成时刻计算，旧调用时刻不会因无符号下溢立即重挂载。
- GT911 复位、等待、探测与配置改为显示任务推进的非阻塞状态机，输入设备仅启动注册一次。触摸失败返回释放状态，定时重试；LCD 主体与触摸可用性独立，触摸缺席报告降级。

## 4. RemoteID

- LOCATION 时间采用有效 UTC 的小时内秒，未知填 `65535`；午夜零秒可用。
- SYSTEM 时间采用 2019-01-01 纪元；无可信时间暂缓该消息。
- 水平速度由北东分量计算，航迹由北东速度方向计算；静止或未知航迹按协议填写，不使用姿态 yaw。
- 本机没有可信垂直速度来源，垂直速度填未知 `6300`；未新增垂直融合。

## 5. 后续边界

本轮沿用既有任务、静态分配和页面布局；未实施品牌区移除、二级导航、LoRa 手动地址/信道或远端单页。旧 `App_CopyRemoteDisplaySnapshot` 无当前生产调用点，其粗粒度兼容输出应在 M3 接入或清理时处理，不能用于新的逐字段显示。

实际 LCD 显示、物理收发、采样精度、恢复时序、运行堆栈水位及长稳仍需在统一功能固件上验证。
