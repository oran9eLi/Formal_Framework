# 2026-06-25 远端接收显示闭环

## 背景

两块板先互相通信验证数据一致性，需要把对端 LoRa/MAVLink 数据闭环到现有显示页面，同时保留后续主机/从机、Remote ID、5G-A 和更多外设扩展入口。

## 代码变更

1. `Framework/Inc/px4lite_types.h`
   - 新增 `Px4Lite_RemoteTelemetry_t` 和 `PX4LITE_REMOTE_VALID_*` 有效位。
   - 远端快照覆盖当前外发目录能还原的模块状态、导航、姿态、环境、电源、告警和来源信息。

2. `Framework/Inc/px4lite_mavlink_rx.h` / `Framework/Src/px4lite_mavlink_rx.c`
   - 新增 Framework MAVLink RX 解码模块。
   - LoRa Driver 只提供 MAVLink 帧事实，RX 模块按 message id 逐字段解码，不在 Driver/Display 中解释业务字段。
   - 当前支持 HEARTBEAT、GPS_RAW_INT、GLOBAL_POSITION_INT、ATTITUDE、SYS_STATUS、BATTERY_STATUS、SCALED_PRESSURE、NAMED_VALUE_INT(`GNSS_SAT`/`MODSTAT0`/`MODSTAT1`) 和 STATUSTEXT。

3. `Framework/Src/px4lite_modules.c`
   - 在 comm work 中挂入 `Px4Lite_MavlinkRxRun()`，RX 先于 TX 调度。

4. `Business/Inc/app_data_api.h` / `Business/Src/app_data_api.c`
   - 新增 `APP_REMOTE_MAX_AGE_MS` 和 `App_CopyRemoteDisplaySnapshot()`。
   - 远端遥测统一映射到 `App_DisplaySnapshot_t`，Display 页面不直接读 LoRa RX 帧。

5. `Display/Inc/display.h` / `Display/Src/display.c`
   - 新增 `Display_DataSource_t`、`Display_SetDataSource()`、`Display_GetDataSource()` 和 `Display_ToggleDataSource()`。
   - 默认显示本机数据；切换后同一页面消费对端 App 显示视图。

6. `Business/Src/business_platform_adapter.c` / `Business/Src/business_display_placeholder.c`
   - KEY0 作为本机/对端显示数据源切换键。
   - 平台适配只读取 KEY0 原始状态；Business 显示服务做去抖和按下边沿；KEY1 急停职责不变。

7. `MDK-ARM/formal_framework.uvprojx`
   - 加入 `px4lite_mavlink_rx.c`。

8. `Framework/Inc/px4lite_config.h`
   - LoRa 本机串口和 E22 空中速率均按 9600 bps 记录。
   - 默认单端可用发送预算按 40% 配置为 3840 bps，保留半双工避让和 E22 开销余量。
   - 两板同程序互发阶段默认使用保守 MAVLink 周期，后续主从时隙确定后再统一调高。
   - 新增 `PX4LITE_NODE_ROLE`、`PX4LITE_NODE_ID` 和 `PX4LITE_REMOTE_NODE_MAX`，MAVLink `system_id` 由 `node_id + 1` 派生。

9. `Framework/Src/px4lite_mavlink_rx.c`
   - 远端快照由单槽扩展为远端节点槽位表。
   - 按接收帧 `system_id` 写入对应远端槽位，默认主机选择从机 1，从机选择主机。

## 边界结论

- LoRa Driver：只做合法 MAVLink 帧事实和 TX/RX 状态机。
- Framework MAVLink RX：唯一远端 MAVLink 业务字段解码点。
- 远端槽位：按 `node_id/system_id` 管理，后续多从机只切换选中槽位。
- Business App API：唯一远端显示视图出口。
- Display：只按当前数据源读取 App 显示视图，不解释 LoRa/MAVLink。
- KEY0：显示数据源切换；KEY1：电机急停。
