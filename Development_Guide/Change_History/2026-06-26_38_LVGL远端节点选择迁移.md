# 2026-06-26 LVGL 远端节点选择迁移

## 变更

1. Display 运行入口迁入 LVGL：初始化、自检、恢复、刷新、页面切换和触摸输入由 `display_lvgl.c` 与 LVGL port 接管。
2. 保留现有 App 数据视图闭环：`Display_PrepareSnapshot()` 继续从 `App_CopyDisplaySnapshot()` / `App_CopyRemoteDisplaySnapshot()` 生成统一 HMI 变量，渲染层只消费变量缓存。
3. KEY0 退出产品交互路径；本机/对端切换由 LVGL 屏幕事件触发。
4. LVGL 通信页通过 `App_CopyRemoteNodeStatuses()` 显示远端心跳节点；点击节点后调用 `App_SelectRemoteNode()`，开启 120 s 主数据查看租约并切换到远端 App 数据视图。
5. Keil 工程加入 LVGL include path、Display LVGL port 源文件和 LVGL source group。

## 边界

- LVGL 属于 Display 实现细节，Business / Framework 不直接包含 LVGL 头文件。
- LVGL 页面只调用 `display.h` 与 `app_data_api.h`，不直接访问 LoRa Driver、BSP DMA buffer 或 Framework topic。
- 远端节点选择只改变 Framework 远端槽位选择与 MAVLink 主数据租约，不改变 MAVLink 原生消息定义。
