# 2026-06-24 变更记录 30：LoRa 状态与数据闭环

## 1. 变更范围

- 收紧 LoRa 模块状态语义：只有最近收到对端合法 MAVLink 帧才判定 ONLINE。
- 本机 LoRa 初始化失败或明确本机模块不可用才进入红色故障；对端超时进入 DEGRADED，用于黄色显示。
- LoRa TX 完成由 UART DMA TC 和 E22 AUX 空闲共同确认，TX 统计不再证明对端在线。
- 新增最近一帧 MAVLink RX 协议事实接口，供两板互测和后续主从解码使用。
- 新增 `MODSTAT0` / `MODSTAT1` 标准 `NAMED_VALUE_INT` 模块状态外发帧。

## 2. 边界约束

- 显示界面展示的外设状态和值，是 LoRa/MAVLink 外发的数据视图。
- 通信不得从 Display 反读，也不得维护独立影子数据；必须来自 Framework topic、Health 状态或 App API 同源快照。
- RX 接口只暴露接收时间、sysid、compid、seq、msgid、payload 长度和 payload 副本，不在 LoRa 驱动中解释业务字段。
- 后续主从节点、时隙、分段重传和远端外设字段另行定义，不写入当前 LoRa 驱动。
