# 已落地功能与验证状态汇总

整理日期：2026-11-06。用途：把本轮已经进入当前源码并保留的电源、电机改动集中说明，便于开发交接；本文件不建立独立验收台账。当前任务状态和证据编号以[执行台账](../../Release/V1.0_执行台账.md)为准。

用户本轮将电压电流等列为已落地功能，要求整理留档；本文记录这些实现继续保留。此前数值偏差项尚无新的标定读数或关闭证据，另列待确认，避免与功能保留意见混为一项。

“已落地”在本文中表示功能已实现并保留在当前生产代码。“软件验证通过”表示所列主机回归和Keil检查通过；实板准确性、保护波形及长稳结论单独记录，不因功能存在或编译通过而自动关闭。

## 一、已保留的电压、电流功能

| 项目 | 当前实际行为 |
|---|---|
| 第一组电压1/电流1 | 默认停用PA5/PC0外部采样，不采集、不发布，不为禁用组产生缺测故障 |
| 第二组电压2/电流2 | 保留PA4电压、PC1电流，作为主回路唯一测量源 |
| 内部参考 | ADC1内部VREFINT保留，第二组继续使用VDDA修正 |
| 显示 | 统一Voltage / Current / Power，读取第二组，不再分主控和电机两组 |
| 功率 | 使用同组有效电压和电流计算；缺测或过期显示N/A，合法0A仍显示为0 |
| 上位机 | MAVLink保留第二组BATTERY_STATUS id=1，停发禁用第一组id=0，不伪造有效电量百分比 |
| 记录 | CSV schema2保持49列及原顺序，禁用组按缺测处理，未知电量百分比留空 |
| 供电类型 | 目前不自动区分电池/外接电源，这是用户此前选择暂不处理的范围 |

验证依据：V1-E34的20组针对性回归、四种开关组合Keil全量0错误0警告；V1-E44 P25候选的24组回归继续覆盖了上述采集、显示、上报和CSV路径。配置及详细文件清单见[单路供电开发日志](2026-11-04_单路主回路供电监测与统一显示.md)。

**仍待确认的部分：电流计实际读数和标定。** 之前记录的电压/电流显示偏差及采样信号电平问题由用户选择暂留，本轮没有提供新的标定值或实测验收。因此“单路功能和统一显示已实现”不等于“实际电压电流已经校准准确”；相应问题继续保留在台账。

## 二、已保留的电机控制改动

| 项目 | 当前实际行为 |
|---|---|
| 人工锁 | 开机默认锁定，显式解锁才允许提交控制目标 |
| 页面 | 右侧原有按钮保留，增加第四个Lock/Unlock切换按钮，显示实际锁状态 |
| 解锁 | 清旧目标，确认最小PWM输出并等待2500ms电调预备；解锁本身不提交非零油门 |
| 上锁和异常 | 上锁、急停、控制超时或PWM失败撤回控制权限；输出失败不伪造已确认零输出 |
| ±1%入口 | Details页改用正确的单路控制入口，保留0..100%目标范围 |
| 电压门禁 | PX4LITE_CONTROL_POWER_GATE_ENABLE当前为0，按用户要求临时旁路电压准入限制 |
| 原保护代码 | 9900/10100/13500mV阈值和原门禁算法保留，设开关为1可恢复；人工锁、急停、超时等继续工作 |

验证依据：V1-E35的26组针对性回归、门禁0/1两配置Keil全量0错误0警告；V1-E44中人工锁、页面、控制、命令及fatal撤收回归继续通过。详细实现见[电机开发日志](2026-11-04_电机手动锁与临时停用电压门禁.md)。本汇总没有新增实机电机输出、保护波形或长稳验收结论。
