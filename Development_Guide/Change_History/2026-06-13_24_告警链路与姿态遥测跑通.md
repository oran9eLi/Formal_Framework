# 2026-06-13 24 告警链路与姿态遥测跑通

## 背景

本轮目标是先跑通除屏幕页面细调之外的数据链路:

```text
Sensor/BSP -> Sensor Driver -> Framework Topic/FIFO -> App_Copy*
    -> Display / MAVLink-LoRa / Alarm / Logger
```

Debug 串口只观察正式链路已经生成的可视化数据,原始字节和寄存器类排障继续
放在独立 RAW 宏下。

## 代码变更

- 新增 `px4lite_alarm.c/h`,由 Health 周期刷新活动告警表。
- 新增 `App_CopyAlarm()`,屏幕、Debug、Logger 后续均通过 App 层只读告警快照。
- `App_CopySystem()` 优先使用 Alarm Manager 摘要。
- Navigation 快照增加 `roll/pitch/yaw rate`,单位为 `dps*100`,用于后续 PID
  和 MAVLink 姿态遥测。
- MAVLink TX 新增 `ATTITUDE` 消息槽,默认 50ms 周期,从 Navigation 快照读取
  姿态角和角速度。
- Debug 新增 BARO、POWER、ALARM 可视化输出,LoRa 输出增加 ATTITUDE 发送计数。
- `formal_framework.uvprojx` 增加 `px4lite_alarm.c`。

## 调度边界

- 未新增 AlarmTask;Alarm Manager 挂在 `health` 任务 100ms 周期内运行。
- `sensor` 仍负责采集和发布,`estimator` 负责姿态/导航转换,`comm` 负责
  MAVLink-LoRa 发送,`debug` 只读快照并打印。
- 屏幕后续接入姿态和告警时只读 `App_CopyNavigation()`、`App_CopyAlarm()` 和
  `App_CopySystem()`,不得直接扫描 Health 内部状态或读取 MPU6050 驱动。
