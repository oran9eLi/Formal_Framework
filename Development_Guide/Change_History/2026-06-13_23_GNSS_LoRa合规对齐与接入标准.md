# GNSS / LoRa 合规对齐与模块接入标准

把已跑通的 **GNSS(接收类)** 与 **LoRa(通信类)** 立为统一样板:先排查 LoRa 对
[01_强制开发规范.md](../01_强制开发规范.md) 的不合规项并向 GNSS 对齐,再固化为接入标准。
LoRa 是 [2026-06-12_22](2026-06-12_22_重构Phase0_返回值与时间源统一.md) 之后才加入的源码,
跳过了当时的句柄封装(P1)与时间源统一(#9)约定,本轮补齐。

> 本轮已完成 Keil/ARMCC5 构建确认,仍需补 §14 异常注入(含 LoRa 断链重连)与 24h 运行。

## A1 LoRa UART 句柄私有化(对齐 P1 / §13.2)

- `bsp_lora.c`:全局可写句柄 `UART_HandleTypeDef BSP_LORA_UART_HANDLE;` → `static s_lora_uart`,
  新增访问器 `BSP_LoRa_GetUartHandle()`(同 `bsp_gnss.c` 的 `s_gnss_uart` 款式)。
- `bsp_lora.h`:`#include "stm32f4xx_hal.h"` + 声明访问器。
- `stm32f4xx_it.c`:删除 `extern UART_HandleTypeDef BSP_LORA_UART_HANDLE;`,
  `USART3_IRQHandler` 改用 `BSP_LoRa_GetUartHandle()`(与 `USART2_IRQHandler` 一致)。

## A2 LoRa 驱动去 HAL,时间源统一(对齐 #9 / §2 / §13.1)

- `lora_e22.c`:不再直接 `#include "stm32f4xx_hal.h"`(改 `stm32f4xx.h` 取 CMSIS 内联 + `bsp_time.h`);
  `HAL_GetTick()`(Init 等待、Send 暂存时间戳)全部改为 `BSP_Time_GetTickMs()`。
- `sensor_gnss.c`:去掉冗余的 `#include "stm32f4xx_hal.h"`(仅用 CMSIS 内联,`stm32f4xx.h` 已够),
  使其成为"Sensor 层不直接 include HAL"的干净样板。
- 结果:`Sensor/` 目录下零 `HAL_GetTick` 调用、零直接 HAL include。

## A3 通信类 OFFLINE 移交 Health(对齐 §13.5 单写者)

- `px4lite_modules.c` `CommWorkRun`:不再自行写 OFFLINE,仅记录 `last_rx_ms`/`last_valid_ms`(=max rx/tx)/
  错误/丢包,并按服务结果与活动升 DEGRADED / ONLINE;删除 `fault` 局部与内联离线分支。
- `px4lite_modules.c` `HealthRun`:新增 `#if PX4LITE_ENABLE_LORA` 超时分支,
  按 `last_valid_ms` 与 `PX4LITE_LORA_OFFLINE_MS` 判 OFFLINE(同 GNSS 模式,含启动宽限)。
- 行为差异:离线由 comm(10ms)改为 Health(100ms)判定,语义一致;ONLINE 仅在有收发活动时升。

## B2 / B3 发送缓冲区所有权与发送语义文档化

- `lora_e22.c` `s_tx_pending`、`px4lite_mavlink_tx.c` `s_frame`:声明处补"comm 任务单一所有者"标注(§13.2)。
- `lora_e22.h` `Lora_E22_Send`、`px4lite_platform.h` `Px4Lite_LoRaSend`:注明**异步复制语义**——
  返回 OK = 已复制并暂存,非空口已发;实际发完以 `tx_frame_count`/`last_tx_ms` 为准(§9.2)。

## P2 §4 模板落地与优化(本轮追加)

- **P2(GNSS)**:`Sensor_GNSS_Service(out)` → `Sensor_GNSS_Service(now_ms)` + `Sensor_GNSS_CopySnapshot` + `Sensor_GNSS_GetStatus`(新增 `Gnss_Status_t`);时间戳由入参 `now_ms` 贯穿 `Gnss_FeedAndParse`,去掉驱动内 `BSP_Time_GetTickMs()` 与 `bsp_time.h`;`px4lite_platform_f407.c` 改为 Service + CopySnapshot 两步。
- **P2(IMU/BARO/BATTERY)**:`Sensor_MPU6050_Service`、`Sensor_BME280_Service`、`Sensor_Power_Service` 对齐为 `Service(now_ms)` + `CopySnapshot` + 紧凑 `GetStatus`;平台适配层由旧 `Service(out)` 改为先推进采集,再复制缓存快照;Debug IMU 改用 `Sensor_MPU6050_CopySnapshot` 读取完整测量。
- **优化**:GNSS/IMU 的 I/O 错误计数改用现成 `Px4Lite_RecordSensorIoError` helper(消除与 BARO/BATTERY 的写法重复);新增 `PX4LITE_LORA_STARTUP_GRACE_MS` 用于 Health LoRa 分支(替代复用 OFFLINE_MS);`BSP_GNSS_Init` 检查 `HAL_UART_Init`/`HAL_DMA_Init` 返回值(对齐 `BSP_LoRa_Init` 健壮性)。
- **规则**:`01_强制开发规范.md` §13.5「同一公开状态单写者」改为「按转移类别单一归属」——数据路径写 ONLINE/DEGRADED、Health 独占 OFFLINE/FAILED/恢复,消除与框架实现的字面矛盾。
