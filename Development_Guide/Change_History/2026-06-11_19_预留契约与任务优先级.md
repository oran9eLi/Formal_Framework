# 预留契约与任务优先级更新

日期：2026-06-11

## 代码更新

- Framework、Business、Debug 的任务优先级全部改为配置宏。
- SensorTask 从 `idle+3` 提升到 `idle+4`。
- Business Acquisition 从 `idle+3` 调整到 `idle+2`。
- 新增 `Px4Lite_RecoveryMonitorRun()`，固定接入 Health 调用点。
- GNSS 恢复阈值、延时和最大重试次数进入配置。
- 自动恢复默认关闭，不改变当前正式行为。
- 新增 `PX4LITE_ENABLE_LOG_POOL`，默认关闭。
- Log Pool 头文件明确标记为预留契约，关闭时不得调用且不分配资源。

## 验证

默认恢复关闭配置：

```text
0 Error / 0 Warning
Code=34420 RO=776 RW=236 ZI=47332
```

临时开启 GNSS 恢复宏的条件编译验证：

```text
Code=34676 RO=776 RW=240 ZI=47328
```

验证后已恢复 `PX4LITE_GNSS_RECOVERY_ENABLE = 0U`。
