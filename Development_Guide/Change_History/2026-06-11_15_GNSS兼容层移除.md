# GNSS 兼容层移除记录

日期：2026-06-11

## 1. 决策

GNSS 后续只使用 Formal Framework 新接口，不再兼容原通用传感器函数表和
通道样本模型。

本记录取代此前“暂时保留 GNSS 旧接口”的过渡安排。

## 2. 删除内容

- `Sensor_Driver_t` 和 `g_gnss_driver`。
- `Sensor_Sample_t`、`Sensor_Status_t` 和 GNSS 通道编号。
- `sensor_driver.h`、`sensor_data.h`、`sensor_device_id.h`、
  `app_error.h`。
- `Gnss_Read()`、`Gnss_GetStatus()`、`Sensor_GNSS_GetSnapshot()` 等旧入口。

## 3. 保留接口

```c
Gnss_Result_t Sensor_GNSS_Init(void);
Gnss_Result_t Sensor_GNSS_Service(Gnss_Snapshot_t *out);
```

正式调用链：

```text
USART2 DMA/IDLE
  -> BSP GNSS
  -> Sensor_GNSS_Service()
  -> Gnss_Snapshot_t
  -> Px4Lite Platform Adapter
  -> Framework Measurement Topic
  -> Navigation Domain / Business API
```

## 4. 后续规则

1. 新传感器优先定义设备专属强类型快照。
2. Platform Adapter 是驱动类型转换为 Framework 类型的唯一位置。
3. 任务、显示、通信和日志不得直接读取驱动私有数据。
4. 不得重新引入“通道编号 + 通用整数值”作为正式数据模型。
5. 高频连续数据使用 FIFO，低频完整状态使用一致性快照。
