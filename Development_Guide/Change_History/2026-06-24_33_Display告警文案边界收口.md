# 2026-06-24 33 Display 告警文案边界收口

## 背景

Display 页面层需要绘制自检和告警列表，但直接包含 `px4lite_faults.h` 会让页面布局代码感知 Framework 故障枚举，后续新增模块或故障码时容易把显示文案逻辑散落在页面文件中。

## 变更内容

- `Business/Inc/app_data_api.h` 新增 `App_GetModuleDisplayName()` 和 `App_GetFaultReasonText()`。
- `Business/Src/app_data_api.c` 统一维护模块显示名、故障域回退名和故障原因文本。
- `Display/Src/display_pages.c` 移除 `px4lite_faults.h` 依赖，告警表文案改为通过 App API 获取。
- 更新 `02_架构边界与数据流.md`、`03_模块接入手册.md` 和 `05_完成度与后续清单.md`，明确 Display 页面层不直接包含 Framework 故障头文件。

## 边界说明

`app_data_api.c` 仍是 Business 数据入口特例文件，允许调用 Framework 状态、告警和故障定义。Display 页面层只消费应用层提供的文案结果，不直接解析 Framework 故障枚举。
