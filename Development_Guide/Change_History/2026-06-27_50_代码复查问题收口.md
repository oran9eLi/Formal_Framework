# 代码复查问题收口

## 背景

针对 LoRa/MAVLink RX 栈占用、HEARTBEAT 字段、Display 字体参数、GT911 初始化结果、Debug 自测和压力显示边界做一次集中复查。目标是在不扩大任务数量、不默认扩大栈的前提下，把低风险问题收口，后续继续用栈水线决定是否需要小幅增加 `comm` 栈。

## 变更

- `Px4Lite_MavlinkRxRun()` 不再在 `comm` 任务栈上放 `Px4Lite_CommRxFrame_t`、`mavlink_message_t` 和 `Px4Lite_RemoteTelemetry_t` 大对象，改为 `comm` 单写者静态 scratch。
- `Px4Lite_CopyRemoteNodeStatuses()` 不再复制完整远端遥测快照到局部栈；临界区只复制轻量字段，过期和状态计算放在临界区外。
- `HEARTBEAT` 解码 `type`、`autopilot`、`base_mode`、`system_status` 和 `mavlink_version`，并通过 Framework/App 远端节点轻量视图透传。
- stream/poll 的 `COMMAND_ACK` 只刷新在线时间和 ACK 统计，不伪造 HEARTBEAT 节点类型。
- `Display_LvglCreateValueLabel()` 正式使用调用方传入的字体，空指针时才回退中文字体。
- `LvPortIndev_Init()` 保存并返回 GT911 初始化结果；Display 初始化仍允许无触摸时页面继续启动，GT911 细节通过 debug/selftest 查看。
- `Display_FloatPaToU32()` 使用真实气压显示范围饱和，避免使用 U32 极限导致 float 边界精度不可靠。
- 新增 `DEBUG_SELFTEST_GNSS_ENABLE` 和 `DEBUG_SELFTEST_LORA_ENABLE`，通过 App/Framework 只读快照和统计接口打印 GNSS/LoRa 自测信息。

## 栈与任务

- 未新增 FreeRTOS 任务。
- 未扩大 `PX4LITE_STACK_COMM`，当前仍为 384 words。
- RX 主路径移除约一组完整远端遥测快照和 MAVLink 消息的栈占用；Debug selftest 远端节点数组改为静态 scratch，避免打开自测时压 DebugTask 栈。
- 栈水线监控仍由 `DebugTaskMonitor` 和 `uxTaskGetStackHighWaterMark()` 提供；后续实测 `comm` 最小剩余栈不足时，再将 `PX4LITE_STACK_COMM` 小幅调整到 512 words。
