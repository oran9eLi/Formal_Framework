# 2026-06-25 LoRa 收发统计与丢包率

## 背景

两块板互相查看数据时，需要在 Display 上看到 LoRa 发送数量、接收数量和链路丢包率，作为后续主从、多从机、分段发送和半双工调度的基础观测量。

## 代码变更

1. `Driver/Comm/Inc/lora_e22.h` / `Driver/Comm/Src/lora_e22.c`
   - 新增 MAVLink `seq` 跳号统计。
   - 按 `system_id` 独立记录上一帧序号，避免多从机帧交错导致误算丢包。
   - 序号跳变超过半圈时按断链后重同步处理，避免热插拔或长时间无接收后累加异常大额丢帧。
   - 输出 `rx_sequence_expected_count`、`rx_sequence_lost_count` 和 `rx_loss_rate_x10`。

2. `Framework/Inc/px4lite_types.h` / `Framework/Src/px4lite_platform_f407.c`
   - 将 LoRa Driver 通信统计透传到 `Px4Lite_CommDebugInfo_t`。
   - LoRa 模块 `drop_count` 同步计入序号跳号估算丢帧。

3. `Business/Inc/app_data_api.h` / `Business/Src/app_data_api.c`
   - `App_DisplaySnapshot_t` 新增 LoRa 丢帧数、ACK 计数预留和丢包率字段。
   - 本机显示视图从 `App_GetCommStats()` 取本机总链路事实。
   - 远端显示视图使用本机 TX 总数，并使用当前选中远端槽位的 RX 计数和丢包率。

4. `Display/Src/display.c`
   - LoRa 统计加载同步刷新 TX 计数、RX 计数、ACK 计数和丢包率。
   - 初始化占位丢包率从 0.5% 改为 0，避免开机显示假丢包。

## 口径

- TX 计数：本机 UART DMA 发送完成且 E22 AUX 回到空闲后的累计帧数。
- RX 计数：本机成功解析的合法 MAVLink 帧累计数。
- 丢包率：接收侧按 MAVLink `seq` 跳号估算，单位 0.1%。
- 对端视图：RX 计数和丢包率对应当前选中远端节点，后续主机切换从机页面时沿用同一槽位口径。
- ACK 计数：当前未定义真实 ACK/重传协议，固定为 0。
