# 2026-07-18_02 USART6 以 5G 在线门控遥测与下行控制

## 需求

USART6 状态机：
- STM32 恒定 1Hz 发心跳（保活，永远发）。
- 树莓派收到心跳 → 回 RPICELL 5G 状态。
- 5G 在线 → STM32 开始发遥测数据；5G 断开 → 只留心跳，停发数据。
- 连上 5G 后，下行控制链路才生效。**急停 31090 也随门控**（用户明确选择，已知情断网时急停不可用的安全风险）。

## 与既往变更的关系

本次**反转** 2026-07-17_09（当时把 RPICELL 与遥测门控解耦）。但不是完全回退：心跳保持始终发送（旧的 `s_rpi_uplink_enabled` 会连心跳一起停），且门控信号改用 5G 模块公开状态而非私有标志。

## 实现

### 单一真相源：`Px4Lite_Is5GOnline()`

`px4lite_modules.c` / `.h` 新增。以 `PX4LITE_MODULE_5G` 公开状态为准：RPICELL bit0 置 ONLINE/OFFLINE（`px4lite_mavlink_rx.c:720/722`），Health task 超时(`PX4LITE_5G_HEARTBEAT_TIMEOUT_MS`=3000ms)清 OFFLINE。临界区读取，`PX4LITE_ENABLE_5G==0` 时恒返回在线（不门控）。遥测门控与命令门控共用此判据，避免双份状态。

### 遥测门控（`px4lite_mavlink_tx.c` / `Px4Lite_MavlinkTxRunRpi`）

- 每趟开始查一次 `five_g_online`。
- 第一趟(RPi 独立遥测)：心跳项(`message_id == MAVLINK_MSG_ID_HEARTBEAT`)恒发；其余项 5G 离线时 `continue` 跳过。
- 第二趟(RPi 专属数据 LORASTAT/RIDSTAT/告警表/日志表)：全属"数据"，5G 离线时整趟不发。
- ACK 在两趟之前发送，**不受门控**（应答是命令回执，非遥测数据）。

心跳用 round-robin 内固定索引，5G 离线时整趟只有它能过闸，1Hz 节奏不受影响。开机 `s_status` 清零 → 5G=UNINITIALIZED → 离线，故上电即"只发心跳"，待首帧 RPICELL 报在线才放数据，构成握手起点。

### 下行控制门控（`px4lite_command.c` / `Px4Lite_CommandHandleMavlinkLong`）

目标校验通过后，若 `link == PX4LITE_MAVLINK_LINK_RPI` 且 5G 离线 → 以 `MAV_RESULT_TEMPORARILY_REJECTED` 应答并返回，不进入命令分发。**含急停 31090**。

- 仅门控 RPi(USART6)链路命令；LoRa 链路命令不受影响（地面站 LoRa 控制不应依赖 RPi 的 5G）。
- 选择 ACK 拒绝而非静默丢弃：树莓派能区分"被拒(5G 未通)"与"应答丢失"，符合本项目"命令必有回执"的一贯原则。该拒绝 ACK 走 USART6，在遥测门控之前发送。

## 行为总览

| 场景 | 心跳 | 遥测数据 | RPi 下行命令 |
|---|---|---|---|
| 开机未收 RPICELL | 1Hz 发 | 停 | 拒(TEMP_REJECTED) |
| 5G 在线(RPICELL bit0=1) | 1Hz 发 | 全量发(各流≤1Hz) | 正常执行并回 ACK |
| 5G 离线(bit0=0) | 1Hz 发 | 停 | 拒(TEMP_REJECTED) |
| RPICELL 断流>3s | 1Hz 发 | 停(Health 判 OFFLINE) | 拒(TEMP_REJECTED) |

LoRa 空口遥测与 LoRa 链路命令均不受本次门控影响。

## 安全说明

用户明确选择"急停 31090 也随门控"。因此 **5G 断网期间，经 USART6 的急停命令会被拒绝执行**。若现场需要断网急停，应通过 LoRa 链路下发急停（不受门控），或后续把 31090 改为门控豁免。此风险在实现前已提示并由用户确认。

## 心跳帧格式（USART6，供树莓派对接）

MAVLink v2，固定 21 字节。payload 固定 `00 00 00 00 12 08 00 04 03`：
type=18(ONBOARD_CONTROLLER)、autopilot=8(INVALID)、base_mode=0、system_status=4(ACTIVE)、mavlink_version=3、custom_mode=0。
帧头：STX=0xFD, LEN=9, incompat/compat=0, seq=滚动, sysid=UID派生(1..250,动态), compid=0xC1(193), msgid=0。CRC-16/MCRF4XX(crc_extra=50)小端。识别端点用 msgid=0 + type=18 + compid=193，sysid 动态学。
