# 补齐树莓派 USART6 下行接收链路

## 变更时间

2026-07-13

## 变更范围

- BSP UART：USART6/RPi 保持阻塞 TX，同时新增 RX 中断单字节接收和环形缓冲。
- Core MSP/IRQ：启用 USART6 NVIC，并新增 `USART6_IRQHandler()` 转发到 BSP。
- Platform Adapter：从 BSP 原始字节缓冲读取 RPi 数据流，解析 MAVLink 帧并转换为 `Px4Lite_CommRxFrame_t`。
- Comm task：每个通信周期先服务 RPi RX，并在 `Px4Lite_CopyCommRxFrame()` 中优先取 RPi 帧，无 RPi 帧时回退 LoRa 帧。
- MAVLink TX：component id 为 `193` 的下行命令 ACK 从 RPi 专属 USART6 出口返回，避免被 LoRa 发送循环消费。

## 行为说明

树莓派现在可以通过 USART6 PC7(RX) 向 STM32 下发 MAVLink `COMMAND_LONG`：

- `31011`：设置四路电机油门百分比，目标会锁存保持。
- `31090`：电机急停。

下行命令进入原有 `px4lite_mavlink_rx.c -> px4lite_command.c -> px4lite_control.c` 链路，不直接绕过 Control/BSP 边界。电机页仍固定显示本机 Control 输出，远端数据接收和远端查看显示逻辑不变。
