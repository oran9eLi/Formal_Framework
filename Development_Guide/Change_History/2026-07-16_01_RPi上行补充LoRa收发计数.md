# 2026-07-16 01 RPi 上行补充 LoRa 收发计数

## 背景

复核树莓派 USART6 上行链路时确认：

- 日期时间已通过 `NAMED_VALUE_INT("GNSSUTC")` 上发。复核后将数据源改为统一时间服务：GNSS 有定位并完成校时时来自 GNSS；GNSS 未定位或不可用时，如 RTC 有效则由 RTC 兜底。帧格式保持 `value=yymmdd`、`time_boot_ms=UTC 当日秒数`。
- 四路 PWM 脉宽已通过标准 `SERVO_OUTPUT_RAW` 上发，`servo1_raw` 到 `servo4_raw` 单位为 us。
- LoRa 链路状态已通过 `NAMED_VALUE_INT("LORASTAT")` 上发，但原位布局只包含丢包率、节点号、模块在位和链路状态，没有包含 `tx_frame_count` / `rx_frame_count`。

## 改动

在 `Framework/Src/px4lite_mavlink_tx.c` 的 RPi 专属目录新增两个 `NAMED_VALUE_INT`：

| name | value | time_boot_ms | 周期 |
|---|---:|---:|---:|
| `LORATX` | `Px4Lite_CommDebugInfo_t.tx_frame_count` | `last_tx_ms` | 1000 ms |
| `LORARX` | `Px4Lite_CommDebugInfo_t.rx_frame_count` | `last_rx_ms` | 1000 ms |

`LORASTAT` 原格式保持不变，避免破坏树莓派现有解析分支。

同时调整 `GNSSUTC` 的编码来源：

| name | value | time_boot_ms | 来源 |
|---|---:|---:|---|
| `GNSSUTC` | UTC 日期 `yymmdd` | UTC 当日秒数 | `Px4Lite_CopyTime()` 统一时间快照，GNSS 校时优先，RTC 兜底 |

## RPi 侧对齐

树莓派解析端在 `NAMED_VALUE_INT` 分支按 `name` 增加：

```cpp
if (name == "LORATX") {
  store.UpdateLoraTxCount(static_cast<std::uint32_t>(value.value), value.time_boot_ms);
  return true;
}
if (name == "LORARX") {
  store.UpdateLoraRxCount(static_cast<std::uint32_t>(value.value), value.time_boot_ms);
  return true;
}
```
