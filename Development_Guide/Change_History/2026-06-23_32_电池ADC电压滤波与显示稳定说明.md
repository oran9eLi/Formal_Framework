# 电池 ADC 电压滤波与显示稳定说明

## 背景

主控电池 ADC1 和电机电池 ADC2 的屏幕电压曾出现约 0.2V 的跳变。两路电池同时存在该现象，原因主要不是电池本体突变，而是 ADC 采样噪声经过约 10.08 倍分压系数还原后被放大到电池端电压。

原链路中，BSP 层只做 8 次 ADC 平均，Sensor 层虽然有一阶低通滤波，但滤波值只用于电量百分比计算；发布给 Framework、Business、Display 的 `voltage_mv` 仍来自原始采样电压，因此屏幕会直接跟随 ADC 抖动刷新。

## 修改目标

降低两路电池在屏幕上的电压跳变，同时保留接入检测、热插拔检测和低电压事实判断的响应速度。

## 数据链路

修改后的数据流如下：

```text
ADC 原始采样
  -> BSP 8 次平均
  -> 还原为电池端原始电压 voltage_mv
  -> 原始电压用于接入检测/热插拔/低电压标志
  -> Sensor 一阶低通滤波 filtered_voltage_mv
  -> filtered_voltage_mv 用于发布电压和电量百分比
  -> Framework battery/battery2 topic
  -> Business environment snapshot
  -> Display 电压显示与电机供电判断
```

## 滤波参数

两路电池使用相同的一阶低通：

```c
filtered = (old_filtered * 3 + new_sample + 2) / 4;
```

参数位置：

- `Sensor/Src/sensor_power.c`
- `Sensor/Src/sensor_power2.c`

该滤波约等于保留 75% 历史值、引入 25% 新采样值。优点是实现简单、计算量低、能明显压制 0.1V 到 0.2V 级别显示抖动。

## 保留原始电压的判断

以下判断仍使用原始采样电压，避免滤波导致插拔和低电响应变慢：

- 电池是否从未接入跳变为接入
- 滤波器热插拔重置
- `low_voltage` 低电压事实标志

发布给上层和屏幕的电压改为滤波后的 `filtered_voltage_mv`。

## 电机电池门限

当前电机电池 ADC2 的显示与告警门限为：

- `< 9.0V`：电机电池断开，红灯
- `9.0V ~ 9.9V`：电机供电不足，黄灯，并报“电机供电不足”
- `>= 9.9V`：电机供电正常，绿灯

由于显示层现在读取的是滤波后的电压，门限附近的灯色和告警也会更稳定。

## 验证建议

1. 使用稳压电源分别接入 ADC1 和 ADC2。
2. 固定输出电压在 11V 到 12V 区间，观察屏幕电压是否仍出现 0.2V 级跳变。
3. 缓慢扫过 9.0V 和 9.9V，确认电机电池红/黄/绿状态切换符合门限。
4. 热插拔电池，确认插入后首个有效采样仍能快速显示当前电压。

## 后续可选优化

如果现场仍有明显跳动，可以继续增加 BSP 平均次数，例如从 8 次提高到 16 次或 32 次；也可以在显示层增加刷新死区，例如电压变化小于 0.05V 时不刷新。前者改善数据源，后者改善视觉稳定性。
