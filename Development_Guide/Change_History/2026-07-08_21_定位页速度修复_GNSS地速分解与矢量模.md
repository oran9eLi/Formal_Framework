# 2026-07-08_21_定位页速度修复_GNSS地速分解与矢量模

## 背景与问题(定位页速度行恒为 0)

定位页"速度行"取值链:
`Display_LoadNavigationSnapshot`(display.c)→ 导航快照 `velocity_north_cms/east_cms` → 导航 topic 速度分量。

但导航 topic 构建 [px4lite_modules.c] 里 `memset(&navigation,0,…)` 之后,只填了位置/高度/hdop/卫星/fix/姿态,**从未给 `velocity_north_cms/east_cms` 赋值**(全项目搜过,本地无任何赋值,仅远端 RX 从 GLOBAL_POSITION_INT 填过)。于是:

- 本地定位页速度行 = `max(|vN|,|vE|)` = `max(0,0)` = **恒为 0**;
- 这些恒 0 的速度分量还喂给了 `GLOBAL_POSITION_INT.vx/vy` 和 RemoteID 水平速度 → **对端速度、RemoteID 广播速度也恒为 0**。

而 GNSS 其实**有地速**:`ground_speed_cms`(驱动从 GGA/VTG 解出),甚至已塞进 `GPS_RAW.vel` 发出。只是它从没被转成导航 topic 的 NED 速度分量。

第二个问题:显示用 `max(|vN|,|vE|)` 近似地速,**不是矢量模**,斜向运动会偏小(45° 时约少 29%)。

## 修改

### ① 本地导航:GNSS 地速按航向分解成 NED 分量(`Framework/Src/px4lite_modules.c`)
导航构建里,`fix_type != 0` 时新增:
```c
float course_rad = (float)gnss.heading_deg100 * (PI / 18000.0f); /* deg*100 → rad */
float speed_cms  = (float)gnss.ground_speed_cms;
navigation.velocity_north_cms = (int32_t)(speed_cms * cosf(course_rad)); /* vN = 地速·cos(航向) */
navigation.velocity_east_cms  = (int32_t)(speed_cms * sinf(course_rad)); /* vE = 地速·sin(航向) */
navigation.velocity_down_cms  = 0;                                        /* GNSS 无垂直速度 */
navigation.valid_mask |= PX4LITE_NAV_VALID_VELOCITY;
```
- 航向为 COG(地面航向,顺时针自北),NED 约定 vN=cos、vE=sin。
- 新增 `#include <math.h>`(FPU 可用,`px4lite_attitude.c` 已用 sqrtf/atan2f)。
- 一处修好,**定位页速度、GLOBAL_POSITION_INT vx/vy、RemoteID 水平速度**都有了正确来源。

### ② 显示:地速改用矢量模 √(vN²+vE²)(`Display/Src/display.c`)
- 删除只取分量较大者的 `Display_AbsCmsToU16`,改为 `Display_GroundSpeedCms(vN,vE) = √(vN²+vE²)`(`sqrtf`,饱和到 65535,新增 `#include <math.h>`)。
- 本地/远端(远端 vN/vE 来自 GLOBAL_POSITION_INT)统一按矢量模算。

### ③ 顺带:速度行单位显示 cm/s → m/s(`Display/Src/display_lvgl.c`)
`DISPLAY_HMI_VAR_GNSS_SPEED` 原来落到 default 分支直接打印原始 cm/s 数字。速度非 0 后这会误导,新增专用 case:转 m/s 保留一位小数,如 `5.2m/s`。

## 效果

定位页速度行显示真实地速(m/s,一位小数);对端/ RemoteID 的速度也不再恒 0。矢量模保证斜向运动速度正确。

## 注意/取舍

- GNSS 只有 2D 地速+航向,`velocity_down_cms` 无来源,保持 0(垂直速度不显示)。
- 静止时 COG 可能无意义,但此时地速≈0 → vN/vE≈0,无副作用。
- 后续若接入 IMU/GNSS 融合的 3D 速度估计,可替换本处分解逻辑。

## 改动文件

- `Framework/Src/px4lite_modules.c`:导航构建按 GNSS 地速+航向填 velocity NED 分量;加 `<math.h>`。
- `Display/Src/display.c`:`Display_AbsCmsToU16` → `Display_GroundSpeedCms`(矢量模);加 `<math.h>`。
- `Display/Src/display_lvgl.c`:`GNSS_SPEED` 专用渲染,cm/s → m/s 一位小数。
