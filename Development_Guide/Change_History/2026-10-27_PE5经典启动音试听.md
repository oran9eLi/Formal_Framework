# PE5经典启动音试听候选

日期：2026-10-27。分支：`codex/buzzer-startup-audition`；基线`103a8cc`，包含Serial通用监视候选。状态：软件实现、独立源码审查及Keil全量构建完成，实板听感与电气验证待进行；不是V1.0稳定版放行。

## 使用范围与预期

用户直接授权先接手边无源模块试听经典启动音。只接入PE5蜂鸣器，现有页面、通信协议、实验、电机逻辑保持；RGB和正式操作反馈不在本候选。主程序最早先将PE5固定低电平，sensor完成已有模块启动后初始化TIM9，再等待1000ms播放一次；从sensor初始化时刻计算，而非保证上电第1秒发声。

旋律取自[PX4 STARTUP定义](https://github.com/PX4/PX4-Autopilot/blob/main/src/lib/tunes/tune_definition.desc)，频率换算依据[PX4解析器](https://github.com/PX4/PX4-Autopilot/blob/main/src/lib/tunes/tunes.cpp)，没有移植运行时MML解析器或浮点幂运算。

| 项目 | 实现 |
|---|---|
| 音符 | A、D、C反复三组，随后D/C交替八音，共17音 |
| 频率 | 1760、2349、2093Hz；采用PX4自身octave/note换算口径 |
| 标称节奏 | T240，前9槽各125000us，后8槽各62500us，总窗口1625000us |
| 发声比例 | 标称Normal 7/8，其余静音；硬件PWM约50%占空比 |
| 实际边界 | 由现有sensor任务约10ms推进，受调度和既有I/O延迟影响；后8槽的7.812ms间隙可能跳过，不宣称逐边界精确复刻 |
| 结束 | 请求0Hz，CCR=0并产生更新事件立即提交，PE5持续低电平，不循环播放 |
| 再听 | 复位重启；没有增加页面按钮、远程播放命令或自动故障声 |
| 延迟执行 | 直接定位当前时间槽，跳过过期音符；超出窗口即静音，不追补或重播 |

## 接线前确认

手边模块丝印HW-508 v0.2.0，用户描述带驱动；客服补充：停止时S脚拉高或拉低均可，只要不再输入脉冲，通常空闲拉低。因此本候选采用空闲低电平。此信息只确认停音方式，不能单凭丝印认定内部驱动、VCC针序、电压或3.3V输入兼容性。

| 信号 | 连接条件 |
|---|---|
| PE5 | 只接已确认兼容3.3V逻辑、带足够驱动能力的模块S/SIG输入；不可据此直接驱动未知电磁线圈 |
| GND | 模块与F407共地 |
| 模块供电 | 按实际模块规格和针序确认；不能把三针中间脚默认接5V |
| 复位静音 | CPU执行前及复位保持期间GPIO不是固件可控，需确认模块输入下拉或使用适当外置下拉；新扩展板已有10kΩ栅极下拉 |

若模块未标清针序或板上器件，先提供正反面清晰照片或卖家电路图，再确认具体接线。无反馈输入，软件成功不代表模块在位或真实发声。

## 分层和完整接入

- BSP：bsp_buzzer.c/.h独占PE5/AF3/TIM9_CH1，提供MX_TIM9_Init、Init/DeInit、SetFrequency和EmergencyStop。原始频率接受200～5000Hz，0为静音。实际APB2=84MHz、定时器倍频为168MHz、PSC=167，计数1MHz；周期就近取整，PWM占空比约50%。
- MSP：HAL_TIM_PWM_MspInit/DeInit独立配置GPIOE/TIM9时钟和引脚；不受电机PWM开关约束。使用纯硬件PWM，无DMA、定时中断或NVIC入口需求；现有HAL_TIM已启用，Keil source list已加入两个.c。
- Platform：只有px4lite_platform_f407.c包含蜂鸣器BSP头；包装初始化/频率输出结果。
- Framework：固定34B只读频率表、sensor单一写者，以平台真实微秒计算窗口。无新任务、动态内存、逐波形中断或阻塞等待；TIM3/TIM4电机和TIM6时基保持。
- 状态：Px4Lite_StartupToneCopyStatus复制WAITING/PLAYING/DONE/ERROR、音符索引、软件频率和错误计数；不新增Business/UI消费者，不作器件在线检测。错误后终止本次播放，可通过复位重新初始化；未接入自动恢复/告警策略。
- 撤收：main最早调用无需HAL/tick的原始低电平撤收；正常静音立即提交CCR=0；初始化失败同样撤收并清理；Core_FatalQuiesce关闭中断后直接撤收，保持既有电机撤收。
- 使能：BSP_ENABLE_BUZZER与PX4LITE_ENABLE_STARTUP_TONE在本试听分支默认1，可在后续目标配置关闭。当前只验证默认试听配置，没有声称其他组合构建通过。
