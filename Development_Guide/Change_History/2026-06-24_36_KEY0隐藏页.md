# 2026-06-24_36 KEY0 隐藏页 / LoRa 连接选择页

## 一、需求

新增一页隐藏页，由板载 **KEY0** 弹出/返回；该页用作 **LoRa 连接选择页**：左侧占屏 3/4 的列表显示在线节点，点行选中、点按钮连接，支持滚动翻页；右侧 1/4 为当前选择详情框和连接/断开按钮。

## 二、页面与导航

| 项 | 方案 |
|----|------|
| 页面枚举 | `Display_HmiPage_t` 在 `ALARM` 后、`COUNT` 前新增 `DISPLAY_HMI_PAGE_HIDDEN` |
| 触发 | KEY0 按下边沿切换：非隐藏页按下→记忆当前页并弹出；隐藏页按下→返回原页面（带 2 拍去抖，约 20ms） |
| 弹出延迟 | 复用“切页立即刷新”通路，按下到弹出 ≈0~10ms |
| 导航隔离 | 隐藏页不参与翻页：`Display_PagesGetNextPage` 与页码圆点遍历上界改为 `DISPLAY_HMI_PAGE_HIDDEN`；隐藏页不画底部翻页栏 |

## 三、LoRa 连接页

布局（800×480，标题栏保留）：

- **左侧列表框**（x=8,w=580，占约 3/4）：每页 7 行，列为 状态点 + 节点名 + ID + 在线状态（**只显示在线节点**，离线由调用方过滤）。选中行浅蓝高亮 + 左侧蓝条。右侧滚动列含 ▲/▼ 翻页按钮和滚动条滑块；标题行显示“在线 N”和“P 当前/总页”。
- **右侧详情框**（x=596,w=196）：标题“当前选择”，显示选中节点的 节点名、ID、状态（待连接/已连接）、上次通信时间。
- **连接按钮**：未连接→绿色“连接”；已连接到选中节点→红色“断开”。

交互：触摸点列表行选中、点按钮连接/断开；连接后按钮变“断开”、状态变绿“已连接”。

**范围**：本次只做界面 + 数据接口。LoRa 真实节点发现/连接握手协议（通信层）不在本次范围——E22 当前无邻居表概念。界面用占位接口驱动，后端以后接到接口上。

### 数据接口（仿 `Display_PagesSetSelfCheckFaults`）

| 接口 | 说明 |
|------|------|
| `Display_LoraNode_t {node_id, label, last_comm_hhmmss}` | 在线节点条目 |
| `Display_PagesSetLoraNodes(nodes, count)` | 业务/通信层推入在线节点列表（只在线，最多 16） |
| `Display_PagesSetLoraConnected(connected, node_id)` | 回写真实连接状态 |
| `Display_PagesSetLoraConnectHandler(handler)` | 注册连接/断开命令回调 `(node_id, connect)` |
| `Display_PagesGetLoraVersion` / `Display_PagesLoraContentDirty` | 版本号驱动重绘 |

连接状态由显示层本地维护（按钮立即反映），并调用回调通知后端；后端可用 `Display_PagesSetLoraConnected` 回写权威状态。占位演示数据在 `DEBUG_ENABLE` 下由 `Display_LoadMockValues` 注入 9 个节点（触发翻页）。

### 中文字模

新增 12 个 16×16 单字字模（节点连接当前选择待已上次）到 `s_mlg_table`，并加“节点/连接/断开/当前选择/待连接/已连接/上次通信”拼词函数；“断开/通信/在线/状态”复用已有字模与整词标签。字模由硬件方按现有格式（阴码/逐行/高位在前）提供。
