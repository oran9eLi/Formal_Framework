# 2026-06-26 多从机选择显示闭环

## 1. 背景

当前产品雏形要求主机能从通信页选择某个从机并显示该从机数据；从机只能查看主机数据，且无操作 120 s 后自动回到本机视图。Remote ID 和 5G 当前不进入业务数据闭环，只保留后续身份和模块状态接入口。

## 2. 本次闭环

1. `App_DisplaySnapshot_t` 增加当前显示对象 `view_node_id/view_system_id/view_remote_id_valid`，Display 统一从 App 数据视图读取身份字段。
2. 本机视图显示本机 `PX4LITE_NODE_ID`；远端视图按选中远端 `system_id - 1` 显示临时 node id，后续 Remote ID 只替换身份显示来源。
3. `App_SelectRemoteNode()` 增加角色过滤：主机不能选择 node 0，从机只能选择 node 0。
4. `App_CopyRemoteNodeStatuses()` 先复制 Framework 远端槽位，再按角色过滤并映射为 `App_RemoteNodeView_t` 给 LVGL 通信页，避免页面层直接理解主从策略或 Framework 远端节点枚举。
5. LVGL 通信页节点列表增加状态灯和选中高亮；新鲜心跳显示绿色，过期心跳显示黄色。
6. 远端显示视图同步使用选中槽位的 RX 计数和丢包率，同时保留本机 TX 计数。
7. 从机远端查看超时统一为 120 s；主机选中从机后不做自动退回。
8. 远端视图下禁止通过电机滑块修改本机电机输出；急停入口保持可用。

## 3. 边界要求

1. 主从/多从扩展只新增 node id 和远端槽位，不复制 LoRa Driver、MAVLink RX 或 Display 页面解析代码。
2. LVGL 页面只调用 `display.h` 和 `app_data_api.h`，不得直接读取 Framework topic、LoRa RX 帧、BSP DMA buffer 或 Driver 私有状态。
3. Remote ID 后续作为身份显示字段接入，不改变 `PX4LITE_NODE_ID`、MAVLink `system_id = node_id + 1` 或远端槽位选择规则。
4. 5G-A 当前按连接管理和 AT 控制面接入，不从本板承载业务数据流；若后续需要外发状态，先进入模块状态和 Health。
