# 2026-07-14 X 模式三轴电机混控修正

## 1. 问题

原姿态辅助代码采用“1 前左、2 前右、3 后右、4 后左”编号，与指定 X 模式示意图中的“3 后左、4 后右”不一致；原旋转方向约定也与示意图不同，并且仅实现横滚、俯仰修正，没有偏航修正。

## 2. 统一约定

| 电机 | 机位 | 俯视旋转方向 |
|---|---|---|
| M1 | 前左 | 顺时针 CW |
| M2 | 前右 | 逆时针 CCW |
| M3 | 后左 | 逆时针 CCW |
| M4 | 后右 | 顺时针 CW |

三轴混控符号按 `[M1, M2, M3, M4]` 排列：

| 轴 | 混控符号 |
|---|---|
| Roll | `{+1, -1, +1, -1}` |
| Pitch | `{-1, -1, +1, +1}` |
| Yaw | `{-1, +1, +1, -1}` |

姿态正方向采用：右侧下沉为正 Roll、抬头为正 Pitch、机体上方俯视顺时针为正 Yaw。Control 使用“目标角减测量角”计算误差，因此上述符号会产生与当前偏差相反的恢复力矩。

## 3. 实现

- 姿态辅助仍以滑动条或树莓派下行写入的每路油门作为基础值，只修正已有非零基础油门的通道；0% 通道保持停机。
- Roll、Pitch、Yaw 分别计算定点 PD 修正并叠加到基础油门，最终统一限制到 0~100%。
- Yaw 误差折返到 -180~180°，避免跨越 ±180° 边界时按长路径纠偏。
- `COMMAND_LONG 31012` 使用 `param1` 设置模式，`param2`、`param3`、`param4` 分别设置 Roll、Pitch、Yaw 目标；旧发送端保持 `param4=0` 时仍可兼容。
- 急停、ESC 预解锁、任务超时保护、姿态新鲜度检查和 PWM 输出链路保持不变。

## 4. 物理边界

1000~2000 us PWM 只控制普通单向 ESC 的油门，不能在软件中直接改变电机转向。M1/M4 顺时针、M2/M3 逆时针必须通过电调设置或交换对应电机任意两根三相线实现，并在拆除桨叶后验证。

当前偏航角由陀螺仪积分得到，没有磁力计提供绝对航向约束，长时间运行会漂移；Yaw 混控用于相对航向稳定，不表示已经具备绝对航向保持能力。
