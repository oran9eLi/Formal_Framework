# 2026-09-23 阶段一 H1 UART6 箱子端最小回显

## 变更目的

在不触及 Pi/Server、不改 UART 参数和不执行飞控命令的前提下，为 F407 增加与业务 `TUNNEL 0x8001/0x8002` 区分的 `0x8003` 最小受控回显。本轮以 2026-09-23 H1 候选稿作本地实现依据，**不宣称三端冻结或真机验收**。

## 改动

- 新增 `px4lite_rpi_h1_echo.h/.c`：只收版本 1、类型 1、1—48 字节且精确长度的请求；复制 8 字节 nonce 和文本，类型改 2，在尾部附当前已应用 UART6 波特率。目标必须精确命中本机 system id 和组件 193；来源 id 不固定为旧草案的 193。
- UART6 `TUNNEL` 接收分发与发送调度改接 H1；核对外层 MAVLink 实际携带字节数，不接受解码补零制造的文本。单槽待发响应在发送成功后释放。
- CommTask 不再调用旧 `ApplyPendingBaud()`；旧草案文件及测试保留，但从当前 Keil 工程移出，旧协议开关关闭。BSP 初始化值、波特率 setter、Flash、飞控控制代码均未修改。
- 新增 H1 主机单测及本技术文档，在进度台账注明旧草案不再是当前固件路径。

## 验证与限制

MSVC `/utf-8 /W4 /WX` 主机单测及 AddressSanitizer 运行已通过；旧草案单测在历史开关局部启用后也通过。当前接入的 RX/TX/Comm 源文件已做主机语法检查，屏蔽的仅为第三方 MAVLink 和既有无关代码告警。Keil MDK-ARM 5.36 / ARMCC5 全量重建包含 H1 源文件，结果为 0 错误、0 警告；map 中主 SRAM 剩余 12080 字节。实板 UART6 抓帧和运行记录尚未归档；实验箱实烧版本、接线及 B0 未核验，源码默认 `115200` 和测试用 `57600` 均不得写成现场配置。旧草案文档只保留在开发机未提交工作区，不进入本次版本，也不再作为 H1 协议依据。
