# 2026-06-30 远程遥测业务日志页面框架与测试收口

## 改动

- 新增 `px4lite_remote_telemetry`，统一持有远端节点遥测槽位、选中节点和本机/远端查看模式；`px4lite_mavlink_rx.c` 只负责解码入槽，避免远端状态所有权散落在 RX 文件中。
- `Px4Lite_MavlinkSetRemoteView()` 同步远端节点选择和远端模式；REMOTE 电机目标加入变化触发的短帧急发，REMOTE 日志加入 60 s 全量回放和增量发送，均使用静态 scratch，不占用任务栈。
- 新增 `app_message_log` 业务层日志入口，`biz_system` 周期生成启动、状态变化、电源和告警日志；Display 日志只保留界面环形缓存，不再重复写 Framework 本地消息日志。
- 新增轻量 `display_pages` / `display_text` 适配层，用于 LoRa 节点选择和页面文本枚举边界；当前产品界面仍以 LVGL 为主，不恢复 LL 旧手绘页面栈。
- `Tests/Unit/` 补齐到 16 个单元测试源文件；保留 F1 已适配的电源 ADC 校准测试，不直接覆盖为 LL 版本。
- Keil 工程 source list 已加入 `px4lite_remote_telemetry.c`、`app_message_log.c`、`display_pages.c` 和 `display_text.c`。

## 边界

- 没有新增 FreeRTOS 任务，没有扩大 `PX4LITE_STACK_COMM` 或其他任务栈。
- 远端遥测槽位、消息日志、REMOTE TX scratch 和 Display page 状态均为静态有界存储；周期任务不在栈上放完整系统快照、完整日志表或 LoRa 大 payload。
- Business 继续通过 `app_data_api.h` 和业务适配接口读取数据；Display 页面适配层不包含 BSP/Sensor 头文件。
- `mavlink_tx.c` 和 `modules.c` 按 F1 当前架构手动合并 LL 优势逻辑，未直接整文件替换。
