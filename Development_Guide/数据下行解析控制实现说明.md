# 数据下行解析控制实现说明

## 1. 目标

本次实现的是树莓派到 STM32 的命令下行解析控制。树莓派负责把外部 JSON 命令转换成 MAVLink `COMMAND_LONG`，STM32 只解析 MAVLink，不解析 JSON。

实现后的链路为：

```text
树莓派 MAVLink COMMAND_LONG
  -> Framework/Src/px4lite_mavlink_rx.c 解码
  -> Framework/Src/px4lite_command.c 分发命令
  -> Framework/Src/px4lite_control.c 执行电机控制
  -> Business/Inc/app_data_api.h 读取本机电机快照
  -> Display/Src/display.c 刷新电机页进度条
  -> Px4Lite_MavlinkQueueCommandAck() 回复 COMMAND_ACK
```

USART6/RPi 直连下行已补齐接入：
```text
USART6 PC7(RX) 中断收字节
  -> Bsp/Src/bsp_uart.c 环形缓冲
  -> Framework/Src/px4lite_platform_f407.c MAVLink 组帧
  -> Framework/Src/px4lite_modules.c 优先取 RPi 接收帧
  -> 原有 px4lite_mavlink_rx.c / px4lite_command.c / px4lite_control.c 链路
```

## 2. 现有电机控制方式

当前工程已经有完整的四电机 PWM 控制链路：

```text
Px4Lite_ControlSetMotorThrottlePercent(motor_index, throttle_percent)
  -> 锁存 0~100% 目标油门
  -> Px4Lite_ControlRun() 每 20ms 统一刷新
  -> 0~100% 映射为 1000~2000us ESC 脉宽
  -> Px4Lite_MotorWritePulseUs()
  -> BSP_PWM_SetPulseUs()
  -> TIM3/TIM4 输出
```

因此命令解析层不能直接写 `BSP_PWM_SetPulseUs()`，必须调用 `Px4Lite_ControlSetMotorThrottlePercent()`。这样可以保留原来的 ESC 预解锁、限幅、Control 任务级失效保护和急停锁存逻辑。

相关现有配置：

```c
#define PX4LITE_CONTROL_PERIOD_MS          20U
#define PX4LITE_MOTOR_COUNT                4U
#define PX4LITE_CONTROL_ESC_MIN_PULSE_US   1000U
#define PX4LITE_CONTROL_ESC_MAX_PULSE_US   2000U
#define PX4LITE_CONTROL_FAILSAFE_TIMEOUT_MS 200U
```

`PX4LITE_CONTROL_FAILSAFE_TIMEOUT_MS` 只用于判断 Control 任务自身是否长时间未运行。树莓派或屏幕滑条设置的油门目标不会因为 200ms 未重复下发而自动失效；最近一次有效目标会一直保持，直到被新的本地滑条命令、树莓派下行命令、急停、低压保护或恢复复位覆盖。

## 3. 新增命令

新增两个 MAVLink `COMMAND_LONG` 命令：

```c
#define PX4LITE_CMD_SET_MOTOR_THROTTLE_PERCENT 31011U
#define PX4LITE_CMD_MOTOR_EMERGENCY_STOP       31090U
```

### 3.1 设置四电机油门百分比

命令 ID：

```text
31011
```

参数定义：

```text
param1 = 电机1油门百分比，范围 0~100
param2 = 电机2油门百分比，范围 0~100
param3 = 电机3油门百分比，范围 0~100
param4 = 电机4油门百分比，范围 0~100
```

STM32 收到后会把四个参数转换成 `uint8_t` 百分比，并分别调用：

```c
Px4Lite_ControlSetMotorThrottlePercent(0, throttle[0]);
Px4Lite_ControlSetMotorThrottlePercent(1, throttle[1]);
Px4Lite_ControlSetMotorThrottlePercent(2, throttle[2]);
Px4Lite_ControlSetMotorThrottlePercent(3, throttle[3]);
```

该命令是锁存式控制。比如树莓派下发 `param1~param4 = 50.0` 后，四路电机目标油门会保持为 `50%`，不会要求树莓派持续重复下发；后续如果本机屏幕滑条改成 `30%`，则本机滑条成为最新控制目标；如果树莓派再下发 `60%`，则树莓派命令再次覆盖本机目标。

### 3.2 急停

命令 ID：

```text
31090
```

参数不使用。收到后调用新增接口：

```c
Px4Lite_ControlEmergencyStop(now_ms);
```

该接口会：

```text
1. 锁存急停状态
2. 清零四路目标油门
3. 将 ESC 状态退回未解锁
4. 立即调用 Px4Lite_MotorDisarmAll()
5. 将四路输出写到 ESC 最小脉宽
```

急停锁存后，后续非 0 油门会被 `Px4Lite_ControlSetMotorThrottlePercent()` 拒绝，并通过 `COMMAND_ACK` 返回临时拒绝。

## 4. 文件修改说明

### 4.1 `Framework/Inc/px4lite_control.h`

新增 Control 急停接口声明：

```c
Px4Lite_Result_t Px4Lite_ControlEmergencyStop(uint32_t now_ms);
```

### 4.2 `Framework/Src/px4lite_control.c`

新增实现：

```c
Px4Lite_Result_t Px4Lite_ControlEmergencyStop(uint32_t now_ms)
{
  Px4Lite_Result_t result;

  s_estop_latched  = 1U;
  s_esc_armed      = 0U;
  s_arm_start_ms   = now_ms;
  s_last_run_ms    = now_ms;
  s_last_run_valid = 1U;
  Px4Lite_ControlClearTargets();

  result = Px4Lite_MotorDisarmAll();
  Px4Lite_SetExternalModuleState(PX4LITE_MODULE_CONTROL, PX4LITE_STATE_DEGRADED, (result == PX4LITE_OK) ? PX4LITE_FAULT_NONE : PX4LITE_FAULT_SYSTEM_SELF_CHECK, now_ms);
  return result;
}
```

### 4.3 `Framework/Src/px4lite_command.c`

新增：

```c
#include "px4lite_control.h"
```

新增命令 ID：

```c
#define PX4LITE_CMD_SET_MOTOR_THROTTLE_PERCENT 31011U
#define PX4LITE_CMD_MOTOR_EMERGENCY_STOP       31090U
```

修改 `Px4Lite_CommandHandleMavlinkLong()`，从默认全部返回 `MAV_RESULT_UNSUPPORTED`，改为按命令分发：

```text
31011 -> 解析 param1~param4 -> 设置四路电机油门百分比
31090 -> 执行急停
其他  -> MAV_RESULT_UNSUPPORTED
```

### 4.4 `Display/Src/display.c`

电机控制页用于确认本机执行器状态，因此该页面不跟随远端查看模式选择电机数据源，而是固定读取本机 Control topic：

```c
if (s_current_page == DISPLAY_HMI_PAGE_MOTOR) {
  motor_result = App_CopyMotor(&motor, now_ms);
} else {
  motor_result = App_GetDisplayMotor(&motor, now_ms);
}
```

下行命令 31011 设置四路油门后，Control 层发布的 `duty_percent[0..3]` 会通过 `DISPLAY_HMI_VAR_MOTOR_PWM_1~4` 刷新到 LVGL 电机页滑条/进度条。这样树莓派下行控制电机时，本机屏幕可以同步看到 0~100% 的目标油门反馈。

该改动只作用于本机电机控制页。其他页面仍通过 `App_GetDisplayMotor()` 按现有本机/远端显示模式读取数据，不改变远端数据接收和远端查看显示逻辑。

## 5. ACK 回复规则

每条属于本机的命令都会通过：

```c
Px4Lite_MavlinkQueueCommandAck(command, ack_result, source_system, source_component);
```

回复树莓派。

结果含义：

```text
MAV_RESULT_ACCEPTED              命令已接受
MAV_RESULT_DENIED                参数非法，例如百分比超出 0~100
MAV_RESULT_TEMPORARILY_REJECTED  当前急停锁存或 Control 忙
MAV_RESULT_FAILED                底层执行失败
MAV_RESULT_UNSUPPORTED           未知 command id
```

## 6. 树莓派下发示例

设置四个电机为 `10%`：

```text
command = 31011
param1 = 10.0
param2 = 10.0
param3 = 10.0
param4 = 10.0
```

急停：

```text
command = 31090
param1 = 0
param2 = 0
param3 = 0
param4 = 0
```

## 7. 安全边界

1. MAVLink RX 层只解码，不直接改电机状态。
2. Command 层负责目标校验、命令分发和 ACK 回复。
3. Control 层仍然是电机输出唯一业务 owner。
4. BSP 层只负责原始 PWM 脉宽输出。
5. 任何电机命令都必须经过 `Px4Lite_ControlSetMotorThrottlePercent()` 或 `Px4Lite_ControlEmergencyStop()`。
6. 最近一次有效油门目标会锁存保持；树莓派下行和本机滑条按“最后一次有效命令生效”覆盖。
7. 地面测试时建议卸桨，并先从 `5%~10%` 小油门开始验证。

```text

3. 电机油门下行仍通过 Px4Lite_ControlSetMotorThrottlePercent()，不绕过 Control/BSP 边界。

5. 电机页进度条固定显示本机 Control 输出，确认下行命令是否已实际控制本机电机。
6. 远端数据接收和远端查看显示逻辑保持原样，不被本机电机页进度条策略影响。
7. USART6/RPi RX 已接入通信任务，树莓派可直接通过 USART6 下发 31011/31090；component id 为 193 的命令 ACK 会从 USART6 返回树莓派。
```
