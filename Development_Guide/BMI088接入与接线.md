# BMI088接入与接线

日期：2026-11-10。面向固件维护者和接线人员，说明本工程替换MPU6050时的配置、接线及实板检查。用户最新确认BMI088已经接通，通信记为用户首轮通过；具体模式/双ID记录、轴向、精度及长稳尚未完整归档，下表不是全部实板验收通过结论。构建、候选与验收状态以执行台账为准。

## 1. 接口兼容的范围

BMI088的加速度计和陀螺仪须分别识别、配置和读取。芯片支持I²C和SPI，但模块的PS、CS及地址选择接法会限制可用模式；软件不能让未引出或未连接的接口自动可用。陀螺接口由PS决定；加速度上电默认I²C，CSB1的上升沿可切换SPI并保持到下次上电复位。[Bosch数据手册第3、6、7章](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bmi088-ds001.pdf)

本工程按配置选择一种BMI088总线，默认I²C；保留MPU6050可配置路径。双接口兼容指两套总线访问适配共用测量出口，不表示任意接线都能盲探测、自动切换。切换模式后完整断电再上电，不仅复位单片机。

## 2. 配置入口

在`Framework/Inc/px4lite_config.h`选择本轮约定的驱动和总线，具体候选以该文件与构建记录一致的内容为准：

| 配置项 | 取值与默认 |
|---|---|
| `PX4LITE_IMU_DRIVER_MPU6050` | 0，保留原驱动选择值 |
| `PX4LITE_IMU_DRIVER_BMI088` | 1，BMI088选择值 |
| `PX4LITE_IMU_DRIVER` | 默认`PX4LITE_IMU_DRIVER_BMI088` |
| `PX4LITE_IMU_BMI088_BUS_I2C` | 1，I²C选择值 |
| `PX4LITE_IMU_BMI088_BUS_SPI` | 2，SPI选择值 |
| `PX4LITE_IMU_BMI088_BUS` | 默认`PX4LITE_IMU_BMI088_BUS_I2C` |

采用SPI时改总线选择，不改驱动型号。回到MPU6050时改驱动选择，并恢复其实际接法。修改固件配置后须重新构建和装载对应固件，不能以另一候选的成功记录代替。

## 3. 接线前确认

1. 断电，确认模块正反面丝印、商家原理图及PS/CS/SDO焊盘位置；不按线色猜引脚。
2. 确认模块VCC输入规格及实际VDDIO电平。芯片VDD为2.4～3.6V、VDDIO为1.2～3.6V；模块是否另带稳压或电平转换不能从芯片名称推定。本板信号域为3.3V，模块接口须与其匹配。[Bosch电气规格与接线表](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bmi088-ds001.pdf)
3. 确认旧MPU6050已从默认替换位置断开。BMI088陀螺与MPU6050可能使用相同I²C地址；默认方案不同时接入两个地址冲突的器件。
4. 不直接给芯片或未经确认的模块接5V、12V；模块若明确带稳压，VCC仍按该模块规格供电，不能因此把IO当作5V电平。

## 4. 默认I²C接法

现有I²C1为100kHz，与BME280共用；不改变其PB6/PB7分配。

| BMI088模块信号 | STM32侧 | 说明 |
|---|---|---|
| SCL或SCK | PB6 | I²C1时钟，须确认模块当前为I²C模式 |
| SDA或SDI | PB7 | I²C1数据，SDA/SDI为复用名 |
| GND | 开发板GND | 供电与信号共地 |
| VCC | 经确认的模块供电 | 优先核对3.3V接入条件，不凭名称假定支持5V |

芯片I²C模式下PS应为VDDIO；CSB1保持VDDIO或按官方允许的上拉方案，CSB2为该模式未使用脚。模块若已经用电阻或焊桥固定这些脚，遵循其原理图，勿再向相反电平硬接。SDO1、SDO2分别决定加速度、陀螺地址，不是I²C数据线。

| 单元 | 7位I²C地址候选 | 寄存器0x00应读到的ID |
|---|---|---|
| 加速度 | 0x18、0x19 | 0x1E |
| 陀螺 | 0x68、0x69 | 0x0F |

必须两部分ID均正确；仅有地址应答不等于识别成功。BME280的0x76/0x77与上述地址不同，可继续由原sensor任务访问。表中均为7位地址；当前Driver在调用BSP_I2C_MemRead/Write前左移1位，BSP将该值直接传给HAL，现场不要把移位后的值当成器件新地址。

## 5. 可选独立SPI2接法

只有确认模块支持SPI且片选/模式脚可用后才采用本表。此分配避开源码中的电机PA6/PA7、背光PB15及SD的SPI3；源码未占用不等于实板未连接。PC4/PC5等可能接有板载以太网PHY，须先核对板卡原理图、器件是否驱动该信号及实体排针引出，确认可用后才配置输出或改选片选脚。

| BMI088模块信号 | STM32侧 | 说明 |
|---|---|---|
| SCK | PB13 | SPI2 SCK，AF5 |
| MISO或SDO | PC2 | SPI2 MISO，AF5；模块须正确汇接两单元的输出 |
| MOSI或SDI | PC3 | SPI2 MOSI，AF5 |
| CS_ACCEL或CSB1 | PC4 | 加速度独立片选，低有效 |
| CS_GYRO或CSB2 | PC5 | 陀螺独立片选，低有效 |
| GND、VCC | 同I²C供电原则 | 共地并核对实际供电与IO电平 |

陀螺PS接GND。两片选空闲保持高，不用一根片选同时选中两单元；若模块分别引出SDO1、SDO2，只有在确认未选中输出可共线且符合模块电路后才汇到MISO。模块仅有一个CS时不能直接按本表推定其内部连接。

加速度SPI初始化包含接口激活，读寄存器还须处理额外dummy字节；陀螺读取不套用同一字节偏移。时序由BSP/Driver处理，不在业务层拼SPI帧。协议实现参考[Bosch BMI08x SensorAPI](https://github.com/boschsensortec/BMI08x_SensorAPI)。

## 6. 当前采集设置

| 项目 | 当前实现 | 不应混同的能力 |
|---|---|---|
| 服务周期与ODR | sensor每10ms服务；加速度与陀螺均配置100Hz | 轮询频率不等于硬件同步采样 |
| 量程 | 加速度±12g，陀螺±1000°/s | 不沿用MPU6050的±8g换算系数 |
| 新加速度 | 读取ACC_STATUS的DRDY，读数据后清除；硬件时间辅助去重 | 自由运行的sensortime本身不能证明有新测量 |
| 新陀螺 | 使用芯片FIFO；最多取4帧，并采用本批最新帧，积压或溢出则丢弃等待下一轮 | 不是每10ms固定重发上次值，也未启用两MEMS硬件DataSync |
| 温度 | 加速度器件温度约1.28s更新；首次无效时等待，0x80不换算为正常值 | 六轴采样100Hz不代表温度也100Hz |
| 启动检查 | 两部分ID、配置读回与错误位检查 | 不代表已执行MEMS激励自检 |

上述实现已完成第9节的软件验证，通信接通由用户首轮确认，完整实板验收仍待完成。硬件FIFO当前已用于陀螺新样本判定，并未采用高频中断/FIFO批量姿态解算方案。

## 7. 初次上电操作

1. 完成断电接线与模式检查，确认固件所选总线一致后上电。
2. 核对两部分ID及初始化结果。未接线、单元缺失或ID不符时保留故障事实，不用全零样本冒充有效姿态。
3. 静止放平，检查加速度模长接近1g、三轴角速度接近静止基线、温度可解释且数据持续更新。
4. 进行六面静置与绕三轴正向旋转，确认正负号、轴顺序和右手关系，再按现有流程重新校准；不能直接沿用旧MPU6050的安装轴向及偏置。
5. 检查BME280、SD与电机锁状态未受影响，再进行后续实验。模式或接线不明确时先停止改线试探，补齐模块资料。

## 8. 验收记录

| 检查项 | 通过依据 | 当前口径 |
|---|---|---|
| 模块电气与模式 | VCC/VDDIO、PS/CS/地址焊盘与原理图一致 | 已接通；具体电气/模式记录待补 |
| 双单元识别 | 加速度0x1E、陀螺0x0F，地址或片选明确 | 通信接通用户首轮确认；双ID明细未归档 |
| 连续采样 | 时戳/序号推进，失败不续期，不发布伪有效零帧 | 软件和实板分别记录 |
| 轴向与量程 | 六面及三轴旋转结果符合实际安装、配置与换算 | 待实板 |
| 重校准 | 静止校准完成，偏置与结果可复核 | 待实板 |
| 热插拔或故障恢复 | 恢复由sensor所有者执行，状态与样本有效性对应 | 待实板 |
| 共存与上报 | BME280/SD正常，屏幕与上报物理单位一致 | 待集成及实板验证 |

平台统一输出加速度mg、角速度mdps、温度0.01℃，继续通过`app_data_api.h`供业务读取。芯片寄存器、两接口差异和模式选择不向Business扩散。两部分在同一轮读取不自动等于硬件同步采样；当前仅使用陀螺FIFO的小批量最新帧，未据此宣称启用DataSync或高频批量融合。
