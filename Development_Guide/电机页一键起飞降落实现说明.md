# 电机页一键起飞/降落实现说明

## 1. 文档目的

本文档记录电机控制页新增“一键起飞 / 急停 / 一键降落”三段式按钮后的固件实现方案、代码落点、控制行为、显示字库处理和验证边界。

本功能只实现用户在电机页上提出的简单油门动作：

```text
一键起飞：姿态和环境传感器均在线时，四路电机油门按斜坡升到 60%
一键降落：四路电机油门按斜坡降到 0%
急停：保留原电机页急停位置中间入口
```

本次实现不引入气压高度、GPS 高度、姿态高度闭环、起落状态机或飞控判定逻辑。按钮只负责向既有电机油门链路写入目标百分比。

## 2. 用户界面布局

电机页原急停按钮区域保持原位置和总体宽度，高度不变，横向拆分为三段：

| 位置 | 文案 | 行为 |
|---|---|---|
| 左侧 | 一键起飞 | 姿态和环境传感器均在线时，启动当前油门到 60% 的自动油门斜坡 |
| 中间 | 急停 | 沿用电机页原急停入口，将四路油门目标置 0 |
| 右侧 | 一键降落 | 启动当前油门到 0% 的自动油门斜坡 |

显示实现位于：

```text
Display/Src/display_lvgl.c
```

关键入口：

```text
Display_LvglCreateMotorPage()
Display_LvglTakeoffEventCb()
Display_LvglEstopEventCb()
Display_LvglLandingEventCb()
```

按钮文字使用 `display_lvgl_font_zh_16`，因此新增文案所需的中文字符必须存在于中文字体子集。

## 3. 控制链路

本功能继续沿用既有电机控制分层，不从 Display 直接写 BSP/PWM。

```text
LVGL 电机页按钮
  -> Display_RequestMotorAutoTakeoff()/Display_RequestMotorAutoLanding()
  -> App_StartMotorAutoTakeoff()/App_StartMotorAutoLanding()
  -> Px4Lite_ControlStartAutoTakeoff()/Px4Lite_ControlStartAutoLanding()
  -> Px4Lite_ControlRun()
  -> Px4Lite_MotorWritePulseUs()
  -> BSP_PWM_SetPulseUs()
```

相关文件：

```text
Display/Inc/display.h
Display/Src/display.c
Display/Src/display_lvgl.c
Business/Inc/app_data_api.h
Business/Src/app_data_api.c
Framework/Inc/px4lite_control.h

```

Control 层仍然是电机输出的唯一业务 owner。Display 和 Business 只提交业务命令，不直接操作 TIM3/TIM4 或 ESC 脉宽。

## 4. 自动油门斜坡参数

当前固定参数如下：

| 参数 | 当前值 | 说明 |
|---|---:|---|
| 一键起飞目标油门 | 60% | 四路电机统一目标百分比 |
| 一键起飞斜坡时间 | 6000 ms | 从当前油门线性升到 60% |
| 一键降落目标油门 | 0% | 四路电机统一归零 |
| 一键降落斜坡时间 | 8000 ms | 从当前油门线性降到 0% |

代码常量：

```c
#define PX4LITE_CONTROL_AUTO_TAKEOFF_TARGET_PERCENT 60U
#define PX4LITE_CONTROL_AUTO_TAKEOFF_RAMP_MS        6000U
#define PX4LITE_CONTROL_AUTO_LANDING_RAMP_MS        8000U
```

选择 6 秒起飞、8 秒降落的原因是：起飞需要比较平顺但不能过慢，降落需要比起飞更柔，避免油门快速归零造成突降手感。该参数只代表本项目当前电机页的简单油门斜坡，不代表高度闭环或正式飞控降落策略。

## 5. 运行行为

### 5.1 一键起飞

按下“一键起飞”后，Control 首先检查姿态传感器模块 `PX4LITE_MODULE_IMU` 和环境传感器模块 `PX4LITE_MODULE_BARO`。两个模块的状态必须都严格等于 `PX4LITE_STATE_ONLINE`，才允许启动自动油门斜坡。

任一模块未接入、离线、降级，或模块状态读取失败时：

```text
1. 不启动一键起飞斜坡。
2. 不改变当前四路目标油门。
3. 消息日志新增：姿态或环境未接入一键起飞失败
```

检查通过后，Control 记录四路当前目标油门作为起点，并以 60% 作为终点。该检查只在按下“一键起飞”启动斜坡时执行一次；斜坡运行过程中不再反复读取姿态快照，也不会因为某一帧姿态数据未刷新而自动切换成降落。

```text
start_percent[i] = 当前第 i 路目标油门
target_percent[i] = 60
duration = 6000 ms
```

`Px4Lite_ControlRun()` 周期运行时按时间插值更新四路目标油门：

```text
value = start + (target - start) * elapsed_ms / duration_ms
```

当 elapsed 达到 duration 后，自动斜坡状态清除，60% 目标油门继续作为普通目标油门保持。

一键起飞过程中，如果滑条或其他入口写入新的非零油门，当前起飞斜坡会被取消，改由最新手动/下行油门命令生效。

### 5.2 一键降落

按下“一键降落”后，Control 记录四路当前目标油门作为起点，并以 0% 作为终点。

```text
start_percent[i] = 当前第 i 路目标油门
target_percent[i] = 0
duration = 8000 ms
```

降落期间，如果滑条或树莓派继续写入非零油门，Control 会返回 busy 并拒绝该非零油门，以保证“一键降落”按下后继续往 0% 收。

降落期间写入 0% 仍然允许，急停和保护路径也会清除自动斜坡状态。

### 5.3 急停

电机页中间按钮保留急停入口，当前 Display 侧行为是对四路电机调用 `App_SetMotorThrottlePercent(i, 0U)` 并同步刷新四个滑块值。

需要注意：

```text
电机页按钮的急停入口是本地电机页的置零入口。
COMMAND_LONG 31090 对应的 Framework 急停锁存接口仍由 Px4Lite_ControlEmergencyStop() 处理。
```

本次没有额外改变急停锁存策略。

## 6. 与独立油门调节的关系

本功能允许起飞后继续使用滑条或树莓派下行命令独立调节四路油门。

行为规则如下：

| 场景 | 结果 |
|---|---|
| 起飞斜坡过程中拖动滑条 | 取消起飞斜坡，滑条命令生效 |
| 起飞完成后拖动滑条 | 正常按滑条油门执行 |
| 树莓派下行油门命令到达 | 正常进入 `Px4Lite_ControlSetMotorThrottlePercent()` |
| 已按一键降落后再给非零油门 | 拒绝非零油门，继续降到 0% |
| 已按一键降落后急停 | 清除自动斜坡，四路置 0 |

该设计满足“中间可能会进行油门独立调节，但是按一键降落都会降落”的要求。

## 8. 安全边界

一键起飞只新增“姿态模块在线且环境模块在线”这一项准入条件，不使用传感器数值参与起飞控制。本功能仍不做以下事情：

```text
1. 不读取气压高度。
2. 不读取 GPS 高度。
3. 不判断是否真实离地。
4. 不判断是否已经落地。
5. 不接入姿态闭环起落状态机。
6. 不直接写 TIM/PWM。
```

传感器在线检查只作用于一键起飞入口。一键降落、急停、手动油门滑条和树莓派油门控制的既有行为不变。本功能只改变四路电机目标油门百分比，最终 PWM 输出仍由 Control 周期任务统一转换和发布。

## 10. 后续调整点

如需后续调参，应优先调整以下常量：

```text
PX4LITE_CONTROL_AUTO_TAKEOFF_TARGET_PERCENT
PX4LITE_CONTROL_AUTO_TAKEOFF_RAMP_MS
PX4LITE_CONTROL_AUTO_LANDING_RAMP_MS
```

如需将“一键起飞/降落”升级为高度闭环，应另起功能设计，不应在当前简单油门斜坡函数中直接加入气压高度、GPS 高度或落地判定。
