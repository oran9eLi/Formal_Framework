# 10 轴姿态传感器（USART5）接入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 先彻底清除 MPU6050 驱动和配套的软件互补滤波姿态估计器，把工程恢复到"IMU 子系统空位、编译干净"的状态；再从零接入一体化 10 轴姿态传感器模块（片内自带传感器融合，USART5 连续帧输出），直接获得已含磁力计修正的绝对航向，解决 [MPU6050模块技术文档.md:20](../../../Development_Guide/YJ/技术文档/MPU6050模块技术文档.md) 记录的"yaw 无绝对参考、纯陀螺积分必然漂移"问题。

**Architecture:** 先删后建，两阶段执行。第一阶段（Task 1）只做清理，把 `Px4Lite_ImuInit`/`Px4Lite_ImuRead` 三个函数降级为占位桩（保持签名和调用方不变，函数体先返回"未就绪"），确保每一步都能 Keil 编译通过，不留半成品状态。第二阶段（Task 2-8）复用项目里 GNSS 已经跑通的"USART 循环 DMA + IDLE 中断 + 环形缓冲"架构接 USART5，Sensor Driver 解析连续二进制帧，Framework 侧直接透传模块融合角度——不重新实现互补滤波。

**Tech Stack:** STM32F407ZG / Keil MDK-ARM v5 / ARMCC 5.06，UART5（PC12 TX / PD2 RX，F407 固定复用引脚，不可重映射），DMA1 Stream0 Channel4（RX）。

## Global Constraints

- 不允许在 Sensor Driver 里包含 HAL 头文件或调用 `HAL_*`（[项目开发指南.md §2](../../../Development_Guide/YJ/项目开发指南.md)）；UART DMA/IDLE 这类 HAL 操作只能放在 BSP 层，与 GNSS 的分层完全一致。
- 不允许传感器各自创建独立任务，统一由 `sensor` 任务调度周期服务。
- 所有 `_ms` 字段必须是真实毫秒时间，禁止混用 RTOS tick。
- 单函数局部数组超过 128B 要审查；超过 256B 应改为静态。
- **每个任务结束必须 Keil `Rebuild All` 达到 0 Error / 0 Warning**，本项目没有 PC 单元测试框架，这是替代性验证门槛——包括 Task 1 这个纯清理任务，清理完必须保证工程仍能整体编译通过，不能留下"等下一个任务补全才能编译"的中间状态。
- **协议已按厂商权威资料确认**：实际选型为正点原子 ATK-MS901M，协议细节摘自《ATK-MS901M模块用户手册_V1.0.pdf》§2.3（非早期版本曾假设的 WitMotion 风格协议），帧格式、寄存器 ID、换算公式均有手册原文依据，见 Task 3。唯一仍需现场验证的是：模块出厂/上次配置保存的波特率、量程是否与手册默认值一致（手册明确这些参数可被上位机改写并存入 Flash）——Task 3 的初始化流程已设计成主动查询而不是假设默认值，最大程度降低这个残余风险。
- **清理决策已定**：MPU6050 驱动和 `px4lite_attitude.c` 互补滤波子系统直接删除，不保留条件编译的降级备用路径（不引入本项目目前不需要的 `PX4LITE_ENABLE_LEGACY_ATTITUDE_FILTER` 开关，YAGNI）。

### Task 3: Sensor Driver — ATK-MS901M 协议解析（帧格式已按厂商用户手册确认）

> 本任务的帧格式、寄存器 ID、换算公式全部摘自《ATK-MS901M模块用户手册_V1.0.pdf》§2.3（模块 UART 通讯协议），不再是早期版本的猜测协议。协议要点：
> - **两类帧头，一眼区分**：模块主动上报帧头是 `0x55 0x55`；上位机命令帧和模块对命令的应答帧头是 `0x55 0xAF`——不像通用协议那样靠功能码猜方向，这两类帧从第 2 个字节就能区分，解析状态机第一层判断就是这个。
> - **帧长不固定**：`帧头(2) + 帧ID(1) + 数据长度(1) + 数据(N) + 校验和(1)`，N 因帧 ID 而异（姿态帧 N=6，陀螺+加速度帧 N=12，磁力计帧 N=8，气压帧 N=10），解析器必须先读长度字段再决定还要收多少字节，不能假设定长。
> - **校验和**：帧内除校验和本身之外所有字节相加，`uint8_t` 存储（自然溢出取模 256），不是 CRC。

```c
/**
 * @file sensor_ahrs10.c
 * @brief ATK-MS901M 协议解析实现，协议依据《ATK-MS901M模块用户手册_V1.0.pdf》§2.3。
 */

#include "sensor_ahrs10.h"
#include "bsp_ahrs10.h"
#include "bsp_time.h"
#include <string.h>

/* 主动上报帧：0x55 0x55 帧ID 长度 数据[N] 校验和（§2.3.1）。 */
#define AHRS10_UPLOAD_HEAD1        0x55U
#define AHRS10_UPLOAD_HEAD2        0x55U
#define AHRS10_UPLOAD_ID_ATTITUDE  0x01U
#define AHRS10_UPLOAD_ID_QUAT      0x02U
#define AHRS10_UPLOAD_ID_GYRO_ACC  0x03U
#define AHRS10_UPLOAD_ID_MAG       0x04U
#define AHRS10_UPLOAD_ID_BARO      0x05U
#define AHRS10_UPLOAD_ID_PORT      0x06U

/* 命令/应答帧：0x55 0xAF 帧ID(读时|0x80) 长度 数据[N] 校验和（§2.3.2）。 */
#define AHRS10_CMD_HEAD1           0x55U
#define AHRS10_CMD_HEAD2           0xAFU
#define AHRS10_CMD_READ_BIT        0x80U
#define AHRS10_REG_GYROFSR         0x03U
#define AHRS10_REG_ACCFSR          0x04U
#define AHRS10_REG_ALG             0x0BU /* 0x00=六轴（yaw 上电恒为 0，无磁力计参考），0x01=九轴（yaw 为绝对航向），见手册 §2.3.2.41 */

#define AHRS10_MAX_DATA_LEN        12U /* 最长的上报帧是陀螺+加速度，N=0x0C。 */
#define AHRS10_FRAME_BUF_SIZE      (4U + AHRS10_MAX_DATA_LEN + 1U) /* 2 帧头 + 1 帧ID + 1 长度 + N 数据 + 1 校验和。 */

#define AHRS10_RX_CHUNK_SIZE       64U
#define AHRS10_CMD_TIMEOUT_MS      200U
#define AHRS10_RECOVER_RETRY_MS    1000U

/* GYRO_FSR/ACC_FSR 查表，索引即寄存器读到的档位值，见手册 §2.3.2 表 2.3.2.13/2.3.2.17。 */
static const float s_gyro_fsr_dps_table[4]  = {250.0f, 500.0f, 1000.0f, 2000.0f};
static const float s_acc_fsr_g_table[4]     = {2.0f, 4.0f, 8.0f, 16.0f};

typedef enum {
  AHRS10_PARSE_WAIT_H1 = 0,
  AHRS10_PARSE_WAIT_H2,
  AHRS10_PARSE_READ_ID,
  AHRS10_PARSE_READ_LEN,
  AHRS10_PARSE_READ_DATA,
  AHRS10_PARSE_READ_CHECKSUM
} Ahrs10_ParseState_t;

static Ahrs10_ParseState_t s_parse_state;
static uint8_t s_frame_buf[AHRS10_FRAME_BUF_SIZE];
static uint8_t s_frame_pos;
static uint8_t s_frame_id;
static uint8_t s_frame_len;
static uint8_t s_is_upload_frame; /* 1=0x55 0x55 上报帧，0=0x55 0xAF 命令应答帧 */

static Ahrs10_Snapshot_t s_snapshot;
static uint32_t s_rx_sequence;
static uint32_t s_error_count;
static uint32_t s_frame_count;
static uint32_t s_checksum_fail_count;
static uint8_t s_gyro_fsr_index;
static uint8_t s_acc_fsr_index;
static uint8_t s_yaw_absolute;
static volatile uint8_t s_reinit_request;
static uint8_t s_recover_rx_pending;
static uint32_t s_recover_rx_last_ms;

static int16_t Ahrs10_DecodeI16(const uint8_t *p)
{
  return (int16_t)((uint16_t)p[0] | ((uint16_t)p[1] << 8));
}

static int32_t Ahrs10_DecodeI32(const uint8_t *p)
{
  return (int32_t)(((uint32_t)p[0]) | ((uint32_t)p[1] << 8) | ((uint32_t)p[2] << 16) | ((uint32_t)p[3] << 24));
}

/**
 * @brief 处理一帧已收完、待校验的完整帧（上报帧或命令应答帧共用本函数判校验）。
 *
 * @param[out] matched_cmd_data 若本帧是命令应答帧且帧 ID 匹配调用方期待的 ID，则把数据段复制到这里；
 * 不关心命令应答时传 NULL、`expect_cmd_id` 传 0xFF（0xFF 不是任何合法寄存器 ID，用作"不等待应答"哨兵）。
 * @param[in] expect_cmd_id 期待的命令应答帧 ID（不含读写位），仅初始化查询流程使用。
 *
 * @return 1 表示命令应答匹配成功并已写入 matched_cmd_data，0 表示本帧不是匹配的命令应答（可能是上报帧，
 * 也可能是不相关的命令应答，调用方按返回值决定是否继续等待）。
 */
static uint8_t Ahrs10_HandleFrame(uint32_t now_ms, uint8_t *matched_cmd_data, uint8_t expect_cmd_id)
{
  uint8_t checksum = 0U;
  uint8_t i;
  uint8_t total_len = (uint8_t)(4U + s_frame_len); /* 帧头2 + ID + 长度 + 数据N，不含校验和 */

  for (i = 0U; i < total_len; i++) { checksum = (uint8_t)(checksum + s_frame_buf[i]); }
  if (checksum != s_frame_buf[total_len]) {
    s_checksum_fail_count++;
    s_error_count++;
    return 0U;
  }
  s_frame_count++;

  if (s_is_upload_frame == 0U) {
    /* 命令/应答帧：只在初始化查询流程里关心，帧 ID 即寄存器 ID（应答帧不带 0x80 读位）。 */
    if ((matched_cmd_data != 0) && (s_frame_id == expect_cmd_id)) {
      matched_cmd_data[0] = s_frame_buf[4]; /* 本计划只用到 1 字节数据的寄存器（GYROFSR/ACCFSR），够用 */
      return 1U;
    }
    return 0U;
  }

  /* 上报帧：按帧 ID 分派。 */
  switch (s_frame_id) {
    case AHRS10_UPLOAD_ID_ATTITUDE: {
      const uint8_t *d = &s_frame_buf[4];
      s_snapshot.roll_deg100  = (int32_t)(((float)Ahrs10_DecodeI16(&d[0]) / 32768.0f) * 18000.0f);
      s_snapshot.pitch_deg100 = (int32_t)(((float)Ahrs10_DecodeI16(&d[2]) / 32768.0f) * 18000.0f);
      s_snapshot.yaw_deg100   = (int32_t)(((float)Ahrs10_DecodeI16(&d[4]) / 32768.0f) * 18000.0f);
      s_rx_sequence++;
      s_snapshot.rx_sequence    = s_rx_sequence;
      s_snapshot.sample_time_ms = now_ms;
      s_snapshot.error_count    = s_error_count;
      s_snapshot.yaw_absolute   = s_yaw_absolute;
      break;
    }
    case AHRS10_UPLOAD_ID_GYRO_ACC: {
      const uint8_t *d = &s_frame_buf[4];
      float acc_fsr_g  = s_acc_fsr_g_table[s_acc_fsr_index];
      float gyro_fsr_dps = s_gyro_fsr_dps_table[s_gyro_fsr_index];
      s_snapshot.accel_mg[0] = (int32_t)(((float)Ahrs10_DecodeI16(&d[0]) / 32768.0f) * acc_fsr_g * 1000.0f);
      s_snapshot.accel_mg[1] = (int32_t)(((float)Ahrs10_DecodeI16(&d[2]) / 32768.0f) * acc_fsr_g * 1000.0f);
      s_snapshot.accel_mg[2] = (int32_t)(((float)Ahrs10_DecodeI16(&d[4]) / 32768.0f) * acc_fsr_g * 1000.0f);
      s_snapshot.gyro_mdps[0] = (int32_t)(((float)Ahrs10_DecodeI16(&d[6]) / 32768.0f) * gyro_fsr_dps * 1000.0f);
      s_snapshot.gyro_mdps[1] = (int32_t)(((float)Ahrs10_DecodeI16(&d[8]) / 32768.0f) * gyro_fsr_dps * 1000.0f);
      s_snapshot.gyro_mdps[2] = (int32_t)(((float)Ahrs10_DecodeI16(&d[10]) / 32768.0f) * gyro_fsr_dps * 1000.0f);
      break;
    }
    case AHRS10_UPLOAD_ID_MAG: {
      const uint8_t *d = &s_frame_buf[4];
      s_snapshot.mag_raw[0] = Ahrs10_DecodeI16(&d[0]);
      s_snapshot.mag_raw[1] = Ahrs10_DecodeI16(&d[2]);
      s_snapshot.mag_raw[2] = Ahrs10_DecodeI16(&d[4]);
      s_snapshot.temperature_cdeg = (int16_t)(((float)Ahrs10_DecodeI16(&d[6]) / 100.0f) * 100.0f);
      break;
    }
    case AHRS10_UPLOAD_ID_BARO: {
      const uint8_t *d = &s_frame_buf[4];
      s_snapshot.pressure_pa = Ahrs10_DecodeI32(&d[0]);
      s_snapshot.altitude_cm = Ahrs10_DecodeI32(&d[4]);
      break;
    }
    case AHRS10_UPLOAD_ID_QUAT:
    case AHRS10_UPLOAD_ID_PORT:
    default:
      /* 本工程不消费四元数和端口状态帧，正常解析、丢弃即可，不算错误。 */
      break;
  }
  return 0U;
}

/**
 * @brief 单字节喂入解析状态机；解析出一整帧后调用 Ahrs10_HandleFrame 处理。
 *
 * @return 若本次喂入刚好收完一个与 expect_cmd_id 匹配的命令应答帧，返回 1 并写 matched_cmd_data；否则 0。
 */
static uint8_t Ahrs10_FeedByte(uint8_t byte, uint32_t now_ms, uint8_t *matched_cmd_data, uint8_t expect_cmd_id)
{
  switch (s_parse_state) {
    case AHRS10_PARSE_WAIT_H1:
      if (byte == AHRS10_UPLOAD_HEAD1) { s_parse_state = AHRS10_PARSE_WAIT_H2; s_frame_buf[0] = byte; }
      break;
    case AHRS10_PARSE_WAIT_H2:
      if (byte == AHRS10_UPLOAD_HEAD2) {
        s_is_upload_frame = 1U;
        s_frame_buf[1] = byte;
        s_parse_state  = AHRS10_PARSE_READ_ID;
      } else if (byte == AHRS10_CMD_HEAD2) {
        s_is_upload_frame = 0U;
        s_frame_buf[1] = byte;
        s_parse_state  = AHRS10_PARSE_READ_ID;
      } else if (byte == AHRS10_UPLOAD_HEAD1) {
        /* 连续 0x55，保持在等第二字节状态 */
      } else {
        s_parse_state = AHRS10_PARSE_WAIT_H1;
      }
      break;
    case AHRS10_PARSE_READ_ID:
      s_frame_id     = (uint8_t)(byte & (uint8_t)~AHRS10_CMD_READ_BIT); /* 应答帧不带读位，上报帧本来就没有这一位 */
      s_frame_buf[2] = byte;
      s_parse_state  = AHRS10_PARSE_READ_LEN;
      break;
    case AHRS10_PARSE_READ_LEN:
      if (byte > AHRS10_MAX_DATA_LEN) {
        /* 长度超出本驱动能处理的最大值（不应发生，除非帧同步丢失），丢弃重新找帧头。 */
        s_error_count++;
        s_parse_state = AHRS10_PARSE_WAIT_H1;
        break;
      }
      s_frame_len    = byte;
      s_frame_buf[3] = byte;
      s_frame_pos    = 0U;
      s_parse_state  = (s_frame_len == 0U) ? AHRS10_PARSE_READ_CHECKSUM : AHRS10_PARSE_READ_DATA;
      break;
    case AHRS10_PARSE_READ_DATA:
      s_frame_buf[4U + s_frame_pos] = byte;
      s_frame_pos++;
      if (s_frame_pos >= s_frame_len) { s_parse_state = AHRS10_PARSE_READ_CHECKSUM; }
      break;
    case AHRS10_PARSE_READ_CHECKSUM: {
      uint8_t matched;
      s_frame_buf[4U + s_frame_len] = byte;
      matched = Ahrs10_HandleFrame(now_ms, matched_cmd_data, expect_cmd_id);
      s_parse_state = AHRS10_PARSE_WAIT_H1;
      return matched;
    }
    default:
      s_parse_state = AHRS10_PARSE_WAIT_H1;
      break;
  }
  return 0U;
}

static void Ahrs10_FeedAndParse(uint32_t now_ms)
{
  uint8_t chunk[AHRS10_RX_CHUNK_SIZE];
  uint16_t got;
  uint16_t i;

  do {
    got = BSP_AHRS10_GetRxData(chunk, AHRS10_RX_CHUNK_SIZE);
    for (i = 0U; i < got; i++) { (void)Ahrs10_FeedByte(chunk[i], now_ms, 0, 0xFFU); }
  } while (got == AHRS10_RX_CHUNK_SIZE);
}

/**
 * @brief 发送一帧读寄存器命令并阻塞等待匹配的应答帧，仅供初始化流程调用。
 *
 * @param[in] reg_id 寄存器 ID（不含读写位），见手册 §2.3.2 表 2.3.2.3。
 * @param[out] out_value 应答帧数据段第 0 字节。
 * @param[in] timeout_ms 等待超时。
 *
 * @return 1 成功，0 超时或未收到匹配应答。
 *
 * @note 本函数含阻塞轮询，绝不能出现在周期 `Service()` 路径，只能在 `Init()` 调用（见 §3 分层约束）。
 */
static uint8_t Ahrs10_ReadRegBlocking(uint8_t reg_id, uint8_t *out_value, uint32_t timeout_ms)
{
  uint8_t cmd[6];
  uint32_t deadline_ms;
  uint8_t rx_byte;

  cmd[0] = AHRS10_CMD_HEAD1;
  cmd[1] = AHRS10_CMD_HEAD2;
  cmd[2] = (uint8_t)(reg_id | AHRS10_CMD_READ_BIT);
  cmd[3] = 1U;
  cmd[4] = 0U;
  cmd[5] = (uint8_t)(cmd[0] + cmd[1] + cmd[2] + cmd[3] + cmd[4]);

  if (BSP_AHRS10_Send(cmd, 6U, timeout_ms) != BSP_STATUS_OK) { return 0U; }

  deadline_ms = BSP_Time_GetTickMs() + timeout_ms;
  while ((int32_t)(BSP_Time_GetTickMs() - deadline_ms) < 0) {
    uint16_t got = BSP_AHRS10_GetRxData(&rx_byte, 1U);
    if (got == 0U) { continue; }
    if (Ahrs10_FeedByte(rx_byte, BSP_Time_GetTickMs(), out_value, reg_id) != 0U) { return 1U; }
  }
  return 0U;
}

Ahrs10_Result_t Sensor_AHRS10_Init(void)
{
  uint8_t value;

  memset(&s_snapshot, 0, sizeof(s_snapshot));
  s_parse_state        = AHRS10_PARSE_WAIT_H1;
  s_frame_pos          = 0U;
  s_recover_rx_pending = 0U;
  s_recover_rx_last_ms = 0U;
  s_reinit_request     = 0U;
  /* 默认值先按手册出厂默认档位兜底（GYROFSR=0x03/2000dps，ACCFSR=0x01/4G），
     查询成功后立刻覆盖；查询失败时不假装成功，返回错误。 */
  s_gyro_fsr_index = 3U;
  s_acc_fsr_index  = 1U;
  s_yaw_absolute   = 0U; /* 保守默认：查询失败前不假装绝对航向可用 */

  if (BSP_AHRS10_Init() != BSP_STATUS_OK) { return AHRS10_RESULT_IO_ERROR; }

  if (Ahrs10_ReadRegBlocking(AHRS10_REG_GYROFSR, &value, AHRS10_CMD_TIMEOUT_MS) == 0U) { return AHRS10_RESULT_IO_ERROR; }
  s_gyro_fsr_index = value;

  if (Ahrs10_ReadRegBlocking(AHRS10_REG_ACCFSR, &value, AHRS10_CMD_TIMEOUT_MS) == 0U) { return AHRS10_RESULT_IO_ERROR; }
  s_acc_fsr_index = value;

  if (Ahrs10_ReadRegBlocking(AHRS10_REG_ALG, &value, AHRS10_CMD_TIMEOUT_MS) == 0U) { return AHRS10_RESULT_IO_ERROR; }
  s_yaw_absolute = value; /* ALG 寄存器 0x00=六轴、0x01=九轴，与 yaw_absolute 语义（0/1）刚好一致，直接透传 */

  return AHRS10_RESULT_OK;
}

Ahrs10_Result_t Sensor_AHRS10_Service(uint32_t now_ms)
{
  if (s_reinit_request != 0U) {
    s_reinit_request = 0U;
    (void)Sensor_AHRS10_Init();
  }
  if (BSP_AHRS10_ConsumeRecoverRxRequest() != 0U) { s_recover_rx_pending = 1U; }
  if ((s_recover_rx_pending != 0U) && ((s_recover_rx_last_ms == 0U) || ((uint32_t)(now_ms - s_recover_rx_last_ms) >= AHRS10_RECOVER_RETRY_MS))) {
    s_recover_rx_last_ms = now_ms;
    if (BSP_AHRS10_RecoverRx() != BSP_STATUS_OK) { return AHRS10_RESULT_IO_ERROR; }
    s_recover_rx_pending = 0U;
  }

  BSP_AHRS10_RxIdleCallback(0U);
  Ahrs10_FeedAndParse(now_ms);

  return (s_snapshot.rx_sequence == 0U) ? AHRS10_RESULT_NO_DATA : AHRS10_RESULT_OK;
}

Ahrs10_Result_t Sensor_AHRS10_CopySnapshot(Ahrs10_Snapshot_t *out)
{
  if (out == 0) { return AHRS10_RESULT_INVALID_PARAM; }
  if (s_snapshot.rx_sequence == 0U) { return AHRS10_RESULT_NO_DATA; }
  *out = s_snapshot;
  return AHRS10_RESULT_OK;
}

Ahrs10_Result_t Sensor_AHRS10_GetStatus(Ahrs10_Status_t *out)
{
  if (out == 0) { return AHRS10_RESULT_INVALID_PARAM; }
  out->rx_sequence         = s_snapshot.rx_sequence;
  out->sample_time_ms      = s_snapshot.sample_time_ms;
  out->error_count         = s_error_count;
  out->frame_count         = s_frame_count;
  out->checksum_fail_count = s_checksum_fail_count;
  out->drop_count          = BSP_AHRS10_GetDropCount();
  out->gyro_fsr_index      = s_gyro_fsr_index;
  out->acc_fsr_index       = s_acc_fsr_index;
  out->yaw_absolute        = s_yaw_absolute;
  return AHRS10_RESULT_OK;
}

void Sensor_AHRS10_RequestReinit(void)
{
  s_reinit_request = 1U;
}
```

**关于"水平校准"入口**（Task 1 里保留了 `Px4Lite_RequestAttitudeLevelCalibration()` 这个占位函数）：手册 §2.3.2 没有一个"清零当前姿态"的独立指令，实际的等效操作是 `SENCAL`（0x01，加速度计/磁力计校准）或依赖模块自身的水平安装——**不是**简单发一条指令就能像旧的 `px4lite_attitude.c` 那样"以当前姿态为零点"。这件事和最初设想的不一样，需要在 Task 6 接回这个入口时明确：要么改成触发 `SENCAL` 走一次真正的传感器校准流程（几秒到几十秒，且需要模块保持特定姿态，例如加速度计校准要求水平静止），要么在 UI 层面砍掉"一键水平校准"这个按钮语义、改成"触发传感器校准"并提示用户按流程操作。这是需要与你确认的产品行为变化，不是纯技术实现细节，本计划先不替你决定，留到 Task 6 处理。

static void DebugService_ReportImu(uint32_t now_ms)
{
  App_NavigationSnapshot_t nav;
  Px4Lite_ModuleStatus_t status;
  Ahrs10_Status_t driver_status;
  Px4Lite_Result_t status_rc;
  Px4Lite_Result_t nav_rc;
  uint32_t report_ms;
  uint32_t imu_age_ms;
  uint8_t imu_fresh;

  (void)now_ms;

  status_rc = Px4Lite_GetModuleStatus(PX4LITE_MODULE_IMU, &status);
  (void)Sensor_AHRS10_GetStatus(&driver_status);
  report_ms = Px4Lite_PlatformGetMs();
  nav_rc    = App_CopyNavigation(&nav, report_ms);

  if (status_rc == PX4LITE_OK) {
    imu_age_ms = Px4Lite_ElapsedMs(report_ms, status.last_rx_ms);
    imu_fresh  = ((status.state == PX4LITE_STATE_ONLINE) && (imu_age_ms <= PX4LITE_IMU_MAX_AGE_MS)) ? 1U : 0U;
    if ((nav_rc == PX4LITE_OK) && ((nav.valid_mask & PX4LITE_NAV_VALID_ATTITUDE) != 0U)) {
      DBG_PRINT("IMU(AHRS10): state=%u err=%lu age=%lu fresh=%u frames=%lu csum_fail=%lu drop=%lu "
                "roll_cdeg=%ld pitch_cdeg=%ld yaw_cdeg=%ld rate_cdps=%ld,%ld,%ld",
                (unsigned int)status.state, (unsigned long)status.error_count, (unsigned long)imu_age_ms, (unsigned int)imu_fresh,
                (unsigned long)driver_status.frame_count, (unsigned long)driver_status.checksum_fail_count, (unsigned long)driver_status.drop_count,
                (long)nav.roll_deg100, (long)nav.pitch_deg100, (long)nav.yaw_deg100, (long)nav.roll_rate_dps100, (long)nav.pitch_rate_dps100, (long)nav.yaw_rate_dps100);
    } else {
      DBG_PRINT("IMU(AHRS10): state=%u fault=%u err=%lu age=%lu fresh=%u frames=%lu csum_fail=%lu drop=%lu no valid attitude rc=%d mask=0x%08lX",
                (unsigned int)status.state, (unsigned int)status.fault_code, (unsigned long)status.error_count, (unsigned long)imu_age_ms, (unsigned int)imu_fresh,
                (unsigned long)driver_status.frame_count, (unsigned long)driver_status.checksum_fail_count, (unsigned long)driver_status.drop_count,
                (int)nav_rc, (nav_rc == PX4LITE_OK) ? (unsigned long)nav.valid_mask : 0UL);
    }
  } else {
    DBG_PRINT("IMU(AHRS10): framework status unavailable rc=%d", (int)status_rc);
  }
}
#endif
