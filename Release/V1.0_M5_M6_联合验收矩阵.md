# CNS 箱 V1.0 M5 与 M6 联合验收矩阵

日期：2026-10-14；版本：R1。用途：内部验收技术依据及后续 Word 表格内容来源。

本表定义“何种操作应产生何种行为”。J01—J108 全部尚未逐项执行；用户报告的单机交互观察作为首轮反馈保留，不预填正式验收通过。实际状态与问题关闭统一见[执行台账](V1.0_执行台账.md)。准备条件、门限和证据要求见[M6 准备方案](V1.0_M6_准备与联合验收方案.md)。

## 1. 每轮登记和填写规则

每轮登记候选/源码、HEX SHA-256、配置校验和、板号、模块版本、供电、接线、Node ID/Channel、E22 读回预设、工具/串口、操作者与起止时间。

每一行的“实际结果”由执行人记录真实观察、测量值和证据路径；结论另填通过/失败/未执行。文档输出代理可以为 Word 增加填写栏或拆分长行，但须保留编号、全部操作、预期行为、硬件条件和门限。

- **单机：** 基础硬件与相应真实传感器。
- **RF：** 箱内 E22 加第二 E22/电脑；多组项目至少四个独立 RF 端点。
- **串口：** 对应 USART6、UART4 或 GNSS 信号工具；电脑串口写成功不等于对端收到。
- **台架：** 无桨固定电机/电调、独立供电、波形仪器；异常钩子使用单独登记的专用验收构建。
