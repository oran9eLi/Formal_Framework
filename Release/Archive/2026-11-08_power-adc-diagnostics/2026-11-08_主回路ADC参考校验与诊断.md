# 主回路ADC参考校验与诊断

用途：供固件维护者和现场调试者核对电压、电流采样偏差。来源为当前BSP/平台/Debug代码及用户现场反馈；验收状态以执行台账V1-PWR-T02为准。

## 现场事实

2026-11-08用户明确更正：主回路约12V、PA4对开发板GND约1.18V，此前报告PA4为12V是看错。撤销基于该旧值的当前过压判断，不推断ADC损坏。主页面和Details均只有7–8V；显示冻结不能解释Details偏差。当前10.1779倍分压换算应把1.18V还原为约12.01V。

## 本次变更

- ADC1检查工厂校准字、内部参考原码及计算VDDA；当前ADC为21MHz，默认参考有效窗口2400..3600mV。异常值保留计算值和具体原因，兼容回退3300mV，不能冒充实测。参考回退经平台映射为电源模块降级事实，原Health和恢复路径保留。
- ADC2复用原16次采样，缓存原码和该次实际使用的参考副本；后续电流采样不会覆盖电压所用参考。平台在sensor所有者完成Service后复制并发布诊断，失败尝试明确voltage_valid=0；Debug仅复制缓存，不增加ADC访问。
- 临时开启独立DEBUG_POWER_MONITOR_ENABLE，每1000ms通过现有USART1 Debug（115200、8N1）输出POWER、POWER-ADC、POWER-REF。关闭Debug不改变采集与诊断发布路径；未新增任务、运行期分配、页面或MAVLink字段。
- 电压分压10.1779、增益1、偏移0，以及电流零点0mV、65mV/A均未调动。第一组停用、第二组PA4/PC1、人工锁、电压门禁默认0和GPS解析/原帧双流保留。

## 看日志

```text
[DBG] POWER: input=2 ... v_mv=... current_ma=... age_ms=...
[DBG] POWER-ADC: seq=... raw=... pin_mv=... bsp_mv=... final_mv=... current_pin_mv=... age_ms=... voltage_valid=...
[DBG] POWER-REF: seq=... cal=0x.... ref_raw=... calc_vdda_mv=... used_vdda_mv=... status=... current_valid=...
```

两条ADC/REF相同seq代表同次电压尝试，单位mv均为mV。raw为PA4的12位平均原码；cal是芯片出厂参考校准字；ref_raw为VREFINT平均原码；calc_vdda_mv为计算结果，used_vdda_mv为实际用于换算的参考。pin_mv是PA4估算电压，bsp_mv是分压还原值，final_mv为Driver校准后的主回路电压。current_pin_mv仅在current_valid=1时解释，且电流零点/灵敏度仍待实测标定。

| status | 含义 |
|---|---|
| 0 | 尚无参考事实 |
| 1 | 参考换算通过检查 |
| 2 | 工厂校准字非法，回退 |
| 3 | 内部参考转换失败，回退 |
| 4 | 内部参考原码非法，回退 |
| 5 | 计算VDDA超允许窗口，回退 |

假设板端真实VDDA为3.3V，PA4约1.18V应对应raw约1464、final_mv约12010。若raw接近这个数而calc_vdda_mv仅约2000mV，优先核对内部参考/工厂码及板端VDDA；若used_vdda_mv约3300mV而raw仅约900，优先核对实际MCU脚电压、模拟配置和采样响应。不能把这两个假设直接认作已定位根因。
