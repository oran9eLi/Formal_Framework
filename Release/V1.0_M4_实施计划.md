# V1-M4 手动 LoRa 实验实施计划

日期：2026-10-12

**Goal:** 按已确认方案交付学生手动收发、Node ID 持久化、E22 信道读写与一个只读活动对端。

**Architecture:** CommTask 独占 LoRa 实验与配置事务；Platform Adapter 转换类型，Driver 解析 E22 寄存器，BSP 只收发和写 Flash。Business/Display 只经 App API 请求和复制状态；固定控件池与事件环复用。

**Tech Stack:** STM32F407 / HAL / FreeRTOS / ARMCC5 C99 / Keil / LVGL。

**Spec:** [M4 准备与设计方案](V1.0_M4_准备与设计方案.md)。用户于 2026-10-12 明确“按方案直接开始实现”，本计划细化已授权方案，不重复请求实施确认。

## 全局约束与执行裁定

- 基线为 `1cc987fd7c2a2d37686d8efdf855c8f301570db2`；固件源码已由 `v1.0.0-pre.m3.20261012` 保存。
- 本轮沿用用户工作区，在 `codex/v1-m4` 分支实施；本机 `.uvoptx` 与 `Reports/` 保留，不纳入固件改动。
- 顺序按接口依赖展开：实验接口 → 身份存储 → E22 配置 → 遥测/界面 → 全量构建与审查。保留原方案所有必需功能。
- 不新增任务、运行期内存分配、远程控制或自动实验恢复；保留 RPi 完整出口、H1/B1 与 RemoteID。
- 界面只开放 Node ID 1..250、Channel 23/26/29/32、Data 四类、Interval 1/2/5/10 s。
- Flash sector 11 保留 128 KiB，64 B 追加记录，末尾提交标记；运行时不擦除。
- 编程需要供电新鲜稳定、电机停止和 Control 维护锁；写入失败、半写、空间满不报告保存成功。
- 驱动配置模式为 E22 的 M1=1/M0=0，配置串口 9600 8N1；CH 只写 0x05，读回必须独立核对。
- 本轮未收到新增/运行 host 测试的明确请求，遵守会话约束：不新增或运行测试。必需 Keil 全量构建照常执行；软件行为用例和实板用例继续单列待验，不声称 TDD 或回归通过。
- 验证状态只由 [执行台账](V1.0_执行台账.md)维护；实现、构建、实板和长稳结论分开。

## Review Focus

1. 配置事务中 E22 热拔插/超时：有界退出，配置字节不进 MAVLink，无假成功，无自动 Start。
2. Flash 半写/低压/新电机请求：旧配置有效，维护锁拒绝启动，保护/急停继续可用。
3. 同 Node ID 多身份及身份迟到：不混合活动快照，未知身份明确，选择切换清数据。
4. Stop/改参数与多帧发送交错：取消未提交帧，已开始 DMA 有界完成，队列不积压。
5. RPi/RemoteID 独立调度及页面池复用：LoRa 配置不阻断本机消费者，切页不增加对象。
