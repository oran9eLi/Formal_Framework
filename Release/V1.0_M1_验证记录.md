### fatal 逐入口检查与台架执行准备

| 入口 | 当前实现顺序 | 上板注入方式（尚未执行） |
|---|---|---|
| Error_Handler / assert_failed / configASSERT | Core_FatalHalt → Quiesce → GPIO/PWM 撤收 → DMA 清理 → 停机 | 临时专用验收构建触发相应入口，记录触发 GPIO 与四路波形 |
| HardFault / MemManage / BusFault / UsageFault | Fault_CaptureAndHalt → Quiesce → 有界现场读取 → Halt | 专用验收入口分别触发故障；检查使能位及故障升级，记录实际进入的 handler |
| malloc failed / stack overflow hooks | Quiesce → 允许的计数/任务名记录 → Error_Handler | 临时验收入口调用相应 hook；另做真实耗尽/溢出试验，区分覆盖范围 |

验收构建不得将故障触发加入普通启动流程。台架按准备方案拆桨固定，先核对端点/最低脉宽，再在四路非零、初始化前/中/后分别触发。依次记录“主控撤收、ESC 驱动切断、转子停转”，最后断开调试器复测复位与重新预解锁；不以断点暂停时间充当保护时延。
