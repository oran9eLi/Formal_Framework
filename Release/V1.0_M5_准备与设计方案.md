## 1. 目标与本次确认

让学生在本机完成“选择对象—开始—观察—比较—停止—重置”的实验过程。屏幕提供数据、单位、操作和短反馈；教学原理、完整步骤及排查说明进入实验手册。保持六个中文主入口、短英文二级视图和固定控件，不增加重复状态栏。

用户要求“开始准备 M5”，并对以下准备范围回复“按建议范围准备（推荐）”：一个共享观察页，最多两路曲线，配套统计和定位漂移；CSV 提供手动记录；参数仅开放已有实验需要的有界项；屏内回放和通用参数编辑延期。对应 D04/D05/D06 的范围选择，具体设计仍须评审。

本次完成代码与资源核对、设计建议和验收覆盖。没有修改生产源码、工程配置或固件，没有运行测试或 Keil 构建，没有建立 M5 固件候选。详细实施计划在本方案评审后按任务拆分。

开始准备时分支为 codex/v1-m4，HEAD 为 1cc987fd7c2a2d37686d8efdf855c8f301570db2，加当时 M4 未提交修改；M4实现现已提交为f3039004193026debaf7c39dc8e1665bc16ef5a4，生产输入未变化。资源依据为 [M4 同次构建记录](V1.0_M4_验证记录.md)：主 SRAM 121216 B，余量 9856 B；HEX SHA-256 为 a778892f5440b909ce978e34092c112e56ea4e9f96f1a59b134519c687d0f0a0。M5准备未修改固件或运行构建，不将这些数字称为 M5 资源结果。

M4 的首轮交互和离线改参拒绝已获用户确认，实际 LoRa 未插接，在线收发、参数读回及多机实验继续待验。依照里程碑计划允许开展独立的 M5 准备；M1—M4 原有必需验收不关闭。

## 3. 实现取向与界面

建议采用现有控件池、独立小容量捕获环、一个共享观察工作区；曲线使用启动创建的绘图对象和固定点数组。沿用姿态仪已有的绘图方式，首批保持 LV_USE_CHART=0。该方案可以控制对象数量和主 SRAM 增量。

其他实现取向供评审核对：启用 LVGL Chart 也能表达两路曲线，但需额外核对系列分配、运行期内存和绘制开销；为各实验单独创建图表、捕获缓存及回放页面会增加内存和状态组合，不纳入已确认的共享页范围。

| 入口 | 内容 / 操作 |
|---|---|
| 飞行 | 电源、环境和实验状态；Details、Observe、Record |
| 姿态 | roll/pitch/relative yaw、角速度、BIAS/ZERO/RESTORE 实际结果；IMU、Observe |
| 定位 | fix、卫星数、HDOP、经纬度、GNSS 高度/速度和年龄；Drift、NMEA |
| 电机 | 四路 Target/Output/PWM us、Direct/Assist、Ramp up/down、E-STOP；单路步进和对比 |
| Comm | 保留 M4 Experiment/Config/Remote；增加 Inspector 和 Serial 功能选择，复用同级工作区 |

主入口到二级页始终为两层；Inspector 内 Messages/Raw/Decoded 是同级模式切换，观察项选择也不增加第三级导航。诊断和观察使用全宽内容，保留对象、告警和 Back；本机电机操作保留可达的 E-STOP。原有最近 3 条日志继续用于普通主页面，不为全宽 Raw/字段表复制完整日志栏。

## 4. MAVLink 捕获与 Inspector（T02）

### 4.1 数据路径与完整性

- LoRa RX：在原有 Driver 解析字节路径同步保留有界原始组帧窗，在生产校验报告完整帧时提供副本；副本产生在业务过滤/出队之前。Driver 仅提供字节和硬件事实，通过 Adapter 注册回调或桥接，不依赖 Framework 类型。
- RPi RX：在 Adapter 原有解析路径保留相同的独立组帧窗，完整帧到达时复制，之后正常交给 pending/H1/B1/命令处理。Inspector 不调用生产 CopyRxFrame。
- 捕获窗与生产解析器的复位、半帧超时、失败末字节复用 STX、重初始化和切速率同步。不能遇到 payload 内的 STX 就重新开始，也不能重编码 payload 生成“原始帧”。
- 首批保存校验通过的完整 MAVLink 1/2 帧，按本库最大 280 B 保留真实帧头、截断后的 payload、CRC 和存在的签名字节。签名字节可见不代表已经验证签名；连续噪声和全部坏帧历史不纳入 Raw。
- TX 在最终序列化和 RPi 重标之后保存实际提交字节及接受结果。LoRa 标 Queued，观察 DMA TC 后才能标 UART done，模块 AUX 空闲另列；RPi 阻塞发送成功才标 UART done。超时可能已有部分字节出线，此时只能显示 Attempt/Timeout，不声称完整帧发出。
- ISR 只保留完成计数/代数，Comm 任务关联捕获 token 后更新完成事实；不在 ISR 复制帧、解码或格式化。槽位被覆盖后不得把迟到的完成事实写进新帧。

### 4.2 推荐容量、筛选和操作

以下是待评审设计值，不是已测性能：4 个完整帧槽、16 个消息汇总键，单次读取一帧；LoRa/RPi 和 RX/TX 各选择一项。单捕获会话覆盖该选择，Changing filter 要先 Pause/Clear，避免不同链路或方向混入。

Start 新建会话；Pause 停止新增诊断复制，生产路径继续；Clear 只清诊断会话；退出 Inspector 暂停捕获并保留内容，再次进入需学生 Start。被选帧复制到稳定的显示工作区，生产环覆盖不改变正查看的 Raw 内容。槽满覆盖最旧并累加 Overwrite，复制失败/重同步诊断舍弃累加 Capture drop；生产队列溢出、CRC、解析错误和 Seq loss estimate 分别显示。

Messages 按链路/方向/SYSID/COMPID/MSGID 汇总，键表满后计入 Other，不无限扩容。Count 属于捕获会话：RX 为完整有效帧，TX 为接口已接受帧；发送 Attempt/Timeout/Error 独立计数，不能并入 UART done。Avg Hz 使用同键首末有效记录之间的间隔和计数计算，少于 2 帧或时间间隔为 0 时显示 N/A；另列 Age，避免历史均频冒充当前接收率。Raw 每页最多 64 B，标 offset、长度、方向、时间、版本和发送阶段。文字刷新最多 5 Hz，消息汇总最多 1 Hz。

Decoded 首批 13 类消息：HEARTBEAT、SYS_STATUS、GPS_RAW_INT、ATTITUDE、GLOBAL_POSITION_INT、SCALED_PRESSURE、BATTERY_STATUS、SERVO_OUTPUT_RAW、NAMED_VALUE_INT、TUNNEL、COMMAND_LONG、COMMAND_ACK、OPEN_DRONE_ID_BASIC_ID。解释工程实际使用字段，保留单位、未知哨兵和合法零值；未知字段不显示为有效测量。TUNNEL 0x8003 解释 H1/B1 的版本、类型、nonce、长度/文本和实际/目标速率；其他 TUNNEL 首批仅显示元数据和 Raw。库能校验但未在字段目录支持的消息显示 Raw 与 Unsupported。

## 5. NMEA 与 Serial（T03）

NMEA 建议 4 个 128 B 句子槽，保留真实句子、时间、类型和 checksum 结果。使用 sensor 任务已有完整行，不再次读取 DMA；句长溢出和诊断覆盖分别计数。坏校验句子可以进入诊断副本用于比较，但不得更新生产 GNSS 测量或在线事实。原始行的 CR/LF 是否存在按实际捕获表达，不通过重新拼接制造字节。

Start/Pause/Clear 只作用于诊断，筛选 GGA/RMC/GSA/GSV/All；MAVLink 与 NMEA 捕获互斥，切换观察对象先暂停旧捕获。长句分页、最多 5 Hz 文本更新，离开视图暂停复制。关闭 raw NMEA 串口打印不影响屏幕捕获。

Serial 复用 H1/B1：展示请求对象、最近 nonce、处理/拒绝/响应完成计数和 USART6 实际速率。F407 继续作为响应端，实验请求由 Pi/Server 或串口工具发起，屏幕提供 Capture/Clear view 和实际状态，不增加直接改 UART 的按钮。

H1 类型 1/2、B1 类型 3/4 的契约不变。类型 4 必须在 115200 完整发送后才能临时切到 57600，复位回 115200，速率不写 Flash。成功信息必须绑定本次 nonce/请求，其他事务或历史累计成功数不能冒充本次成功；没有对端响应证据时不写“Server OK”。查看/清视图不撤销真实 pending 请求。

## 6. 基础实验与共享增强（T01/T04）

### 6.1 数据与操作

| 数据组 | 首批内容和实际操作 |
|---|---|
| Power | 两路电压、电流、估算百分比、测量年龄；只有同路电压和电流有效新鲜时计算功率 |
| Environment | 温度、湿度、气压、年龄；选择观察两路，统计变化和极值 |
| Attitude / IMU | 相对姿态、角速度、原始加速度 mg/陀螺 mdps；校准/归零/恢复的排队、执行和结果分开 |
| GNSS / Drift | 定位质量、GNSS 原始高度、速度、逐域年龄；手动 Set ref、Start/Stop、Reset，显示 N/E 位移、距离和有效点数 |
| Motor | 逐路 0..100% 目标，步进 1%；显示实际输出命令及 PWM us，目标受原有保护限制；不显示虚构 RPM |

新鲜度使用所属测量时间和有效位，新增 App_CopyImuLatest、App_CopyGnssDetails 等非消费型边界；名称为接口草案。不把融合高度标为原始 GNSS 高度，不把占位垂直速度当作实测，不将 yaw 标为真北航向。

### 6.2 共享观察会话

仅观察本机，绑定数据组、两路字段和会话编号；远端继续留在 M4 只读页。建议 64 个时间点，两路各带有效位，观察间隔 200/500/1000 ms，默认 200 ms；按 biz_acq 已有周期推进，不增加任务。原始 IMU 仅复制最新副本，不能抽走估计器 FIFO。

Start 清空旧会话并开始；Stop 停止新采样但保留结果；Reset 在停止时清数据；Freeze 仅冻结画面，不停止已开始的统计，Resume 恢复观察。切页不改变观察会话或控制状态；重新进入不自动 Start。修改数据组、字段或间隔要求先 Stop，再 Start 建立新会话。上电不恢复曲线、统计、参考点或旧电机目标；这些状态表为 D11 的 M5 设计，待评审。

按测量序号与时间排除重复缓存；允许合法零值，缺测留断点，不补历史点、不在超时后突发追赶。统计使用有效新样本的 Count/Min/Max/Mean，独立记录 Missing 和 Age，不因画面 Freeze 改采样。角度跨界采用局部展开用于短时曲线和统计，显示注明 relative/unwrapped；缺测后不推断圈数，分段展示，原始姿态、控制和 CSV 原值不改。

漂移参考点必须来自新鲜有效 GNSS 位置，参考点只保留在实验服务，不修改 Navigation。建议局部近似限 1000 m，处理经度跨界；超出范围或无有效定位显示 Out of range/N/A，不伪造坐标。按 GNSS 实际更新推进，重复位置包不增加有效点数。

### 6.3 手动记录和参数

Record Start/Stop 门控现有数据 CSV，默认 Stopped；保留现有宽表字段及数据有效性口径，首批记录间隔 1/2/5/10 s，默认 1 s。观察 Start 与 Record Start 分开，启动一种实验不能悄悄启动另一种。

事件/故障记录保持原有后台服务，与学生数据记录分别统计。CSV 仍由 storage 任务写入，UI/采集/Comm/ISR 不访问 FatFs。Record Start 前核对 SD 可用；Queued、Written、Synced、Queue drop、Write drop 分别表达，并绑定数据记录类型和会话，不能用包含事件的累计 written_count 冒充当前实验写入。Stop 停止新数据入队，允许旧数据排空并请求 sync；只有本会话排空及同步成功后显示 Saved，失败显示具体 SD 状态。拔卡或写失败结束数据会话，恢复后需学生重新 Start，不自动补发缺失数据；后台挂载和故障记录恢复机制继续工作。

首批参数限观察/记录间隔、已有单路目标百分比及既有模式/操作。姿态 PD 增益、估计算法系数、保护阈值、任意消息发送与通用参数编辑不开放。新增观察/记录设置仅运行态，重启回默认；Node ID/Channel 继续沿用 M4 持久化边界。

## 7. 资源与预算（T05）

### 7.1 推荐静态预算

| 项目 | 建议容量 / 估算 |
|---|---|
| MAVLink 捕获环 | 4 ×（280 B 帧 + 约 24 B 元数据）= 约 1216 B |
| 两链路 RX 原始组帧窗 | 2 × 280 B = 560 B；TX 优先复用原有异步 pending 字节，完成关联只保存 token |
| Messages 汇总 | 16 个键，约 448 B |
| 选帧/字段解释工作区 | 共用单份，约 512 B，不为每种视图复制整表 |
| NMEA 环 | 4 ×（128 B + 约 16 B 元数据）= 约 576 B |
| 两路曲线与时间/有效位 | 64 点，按对齐估算约 1024 B |
| 统计/原始 IMU 最新副本/会话状态 | 约 384 B |
| 任务/堆/显示指标 | 约 256 B |

上述约 4976 B，仅为设计估算，预算内预留约 656 B 给对齐和辅助状态；新增工作栈必须纳入最终 map。目标主 SRAM 新增不超过 5632 B、静态剩余不少于 4096 B；相对 M4 基线目标余量为 4224 B。不能把静态余量当作 RTOS 堆可用量。

若超预算，先复用工作区、曲线点 64→32，必要时捕获槽 4→3，并记录最终采用值；保留完整单帧 280 B、两路曲线能力及独立生产路径。不能用截断 Raw、抢生产队列、移动 DMA 到 CCM 或删保护来满足预算。仍不满足时保持相应增强待验证，并记录范围调整，不能默默删掉用户已选功能。

### 7.2 刷新与测量门禁

显示每 10 ms 服务触摸，数据/Raw/曲线最多 5 Hz，Messages/资源最多 1 Hz，非当前视图不格式化或绘制。保持启动固定池，文本使用稳定缓冲和变化更新，绘图对象/控件只在启动创建；禁止运行期 RTOS 动态分配和切页新建对象。

M5-P01 首先补预算和计时：应用排版、格式化、数据复制按 2000 us 分步；LVGL 绘制与 SSD1963 同步 flush 单独测量。当前 lv_timer_handler 可能一次连续完成多条带，单纯“调用前检查时间”不能限制调用内部。必须控制无效区域和分段刷新，记录完整显示服务最大耗时；若单步不能达到 2 ms，不放宽原约束，也不把新增高负载视图标为通过。触摸从驱动读到触点至 UI 接受操作的目标最大 100 ms，切页呈现目标最大 300 ms；两项是待评审门限。

资源采集与打印开关分离：任务创建时登记句柄/配置深度，已有低优先级服务每 1 s 更新只读快照，经 App API 展示；不能关闭 DEBUG_STACK_MONITOR_ENABLE 就失去屏幕水位。FreeRTOS 堆峰值必须低于 75%；各任务最低剩余栈必须大于配置的 25% 且不少于 100 word。LVGL 建议峰值不超过其 40 KiB 的 85%、最大连续空闲块不少于 4 KiB，并记录碎片；这些是建议门限，尚无实测结果。

记录 IMU FIFO 峰值/溢出、生产 RX 溢出、诊断覆盖/舍弃、Comm 周期最大值、render/flush/完整显示服务耗时和触摸响应。RPi 当前阻塞发送超时 20 ms，不能将 Comm 的名义 10 ms 周期描述为实际最大周期已达标。验收比较相同最重生产负载在诊断关闭/开启下的结果，不新增由诊断引起的生产丢弃或保护延迟。

D10 建议课堂配置关闭非必要 GNSS/IMU/Baro 等周期打印，保留启动和实际异常，不改派生宏；该具体配置尚未确认。M4-R01 建议删除失效旧分消息计数，统一使用实际接受/UART done/模块空闲及捕获会话统计；不能把调度次数写成已完成发送。

字体按最终实际字符集核对裁剪，保留六个中文主入口和实际反馈所需字形；英文数据采用现有字体，不为长说明新增字库。实验开始/停止/重置、记录开始/结束/失败由所属服务的真实状态转移记入事件，保持后台记录和切页去重；新日志ID只追加，RPi保留消息消费兼容性另验。

## 10. 评审关注点

本次确认的是增强范围。需评审的具体建议为：捕获 4 帧/16 汇总键、NMEA 4 句、曲线 64 点及刷新频率，运行态参数清单、D11 的 M5 状态表、静态/运行门限以及 D10 课堂打印配置。实施前将最终采用值同步到台账和详细实施计划。

优先审查完整原始帧与生产队列隔离、异步 TX 完成代数、采样新鲜度、记录停止/同步及 LVGL 不可中断调用的预算。实际接线和 LoRa/RPi/SD/电机实板条件不足时保留对应待验项，独立的软件工作仍可推进。
