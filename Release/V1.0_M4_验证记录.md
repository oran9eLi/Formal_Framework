## 2. 静态调用边界

| 任务 | 已实施路径 | 软件/物理证据边界 |

| T01 | App 请求 → CommTask 单槽实验 → 冻结数据组 → MAVLink → 异步 Driver | Stop 取消未提交帧；已启动 DMA 不撤回；Queued/UART done/Module idle 与远端 RX 含义分开；空口实际频率待验 |
| T02 | 启动扫描 → Identity 固定 → 所有链路；CommConfig → Control 维护门禁 → Adapter → BSP 单字编程 | UID、CRC、提交标记、半写过滤、无运行擦除；低压/断电与输出门禁、编程暂停时间待验 |

## 5. 首轮上板顺序

1. 核对 E22 型号和课堂预设，尤其空速9.6 kbit/s；Profile mismatch 需用厂商工具手动修正。密码为只写字段，不能以固件Ready声称已验证密码。
2. 烧录同次 HEX；保留 sector11，勿用整片擦除；先确认电机停止、页面/触摸和基础身份发现。
3. 两台箱子走 Attitude Send/Start/Stop，再试其他数据和断流；核对计数含义、Freeze与逐域age。
4. Save Node/重启、Apply CH/Restore，以及配置异常/拔插；不以界面显示Saved代替掉电耐受证明。
5. 执行四机冲突与资源/保护并发矩阵，记录板卡、候选SHA、设备配置、时长与结果。
