## 8. 2026-10-13 Node ID 保存解除动力电源依赖（V1-E11）

### 反馈、原因与范围

用户报告 Save Node 显示 `Node ID save failed`，当时未接电机电源；随后明确设备绝大多数在室内直接供电，要求装配动力电源妨碍拆机测试。代码核对确认 Save Node 没有 LoRa 在线前置条件，原 Control 维护门禁却要求 Battery2 的 10.1..13.5 V 连续稳定采样，误把动力供电作为主控 Flash 保存依据。

本次在 `develop` 工作区实施最小修正，基线为 `40fb8c620cde374b9c1607c676763732054eeef2`，尚未提交或推送：

- 删除配置专用动力采样窗口、状态和三项阈值宏；正常主控供电下，无动力电源/无 LoRa 仍可请求保存 Node ID。
- Begin/Check 在同一调度互斥边界复用停止检查：Control 已有运行事实、最近 PWM 写入成功且全部最小脉宽、所有有效目标停止、无自动序列；保存期间保留启动互锁，结束仍清旧目标并重新预解锁。
- 电机运行的 Battery2 保护、急停、故障撤收和心跳规则继续生效；维护锁只检查停止事实，不因动力闭锁拒绝写入。
- 结果枚举第 4 项改为 `PX4LITE_CONFIG_INTERLOCK`，界面显示 `Motor lock`；2 s 保存超时归 `Error`。日志仍由真实保存结果产生，不将请求接受当作成功。
- Flash 后端、64 B 格式、UID/CRC/最后提交字、读回、半写槽跳过、同值不写和满槽策略保持；无新增任务、动态内存、VDD 测量或 PVD 门禁。主控供电符合原 32 位编程条件仍为运行前提，记录校验不是主控断电预警。
