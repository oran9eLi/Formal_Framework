# M2：测量与日志可信——软件验证记录

日期：2026-09-15；分支：`release/v1.0`；前置提交：`a4f72a4`（M1）。

## 结果与范围

M2 完成姿态测量、主动校准状态、显示相对基准和 CSV 有效性的代码修复。学生可见的校准流程与文案仍由 M3 完成；本记录不是实板准确度或正式发布验收。

- 去除匀速被误判静止后的角度冻结、上电自动求零偏/水平归零和隐藏慢速运动的 yaw 死区。
- 传感器零偏校准必须主动请求；相对归零和恢复基准分别通过独立动作请求。请求 OK 仅表示排队，最终结果来自状态快照。
- 校准要求连续 128 个合格样本，提供请求中、等待放稳、采集中、成功/失败及进度。运动会重置采样积累；10 秒未完成报告未放稳，样本超时报告无数据。失败保留上一次成功零偏。
- 相对基准仅影响本机显示副本；控制、遥测和日志继续读测量值。横滚与 yaw 跨 ±180° 做归一化，无姿态有效位时不扣除基准，远端不应用本机基准。
- CSV 分别检查 GNSS、姿态、温湿压、两路电池、电机输出，标记缺测/无效/过期/有效，保存所属样本时刻。v2 独立文件避免与旧表头混写。

字段、单位、文件命名与读取示例见 [CSV v2 说明](../Development_Guide/2026-09-15_CSV_v2字段与读取说明.md)。

## 交互语义和实板待验

1. M3 须提供“放稳→开始校准→进度→结果”，另设相对归零与恢复入口；当前旧按钮还未完成这些教学文案与状态展示。
2. 校准准入要求原始角速度每轴不超过 0.5°/s、加速度接近 1g 且变化小。**无法仅靠 IMU 区分阈值内恒速转动与零偏**，必须由学生实际放稳。较大硬件零偏可能无法通过准入，需实板核验；不得宣传为任意运动下自动识别静止。
3. 当前仍是互补滤波 roll/pitch 加机体 Z 轴积分的相对 yaw；没有绝对航向源，也未升级为完整三维姿态解算。M4 要验证倾斜、混合轴运动、漂移与课堂可用范围。
4. 相对归零是各显示角的参考差值，不是重新定义三维坐标系；基准和零偏保存在 RAM，重启清除。
5. M4 验证实板断流/恢复、SD 导出及实际解析工具、按键重复操作、任务抢占和运行时堆栈水位。M5 对最终候选完成至少 24 小时长稳。上述项目均未记为通过。
