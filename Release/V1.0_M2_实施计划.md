# V1-M2 数据、收发与恢复实施计划

日期：2026-09-28。依据：[里程碑计划](V1.0_里程碑计划.md)、[执行台账](V1.0_执行台账.md)、全库审查 A03—A13/A15—A17。

## 1. 前置与边界

用户授权继续下一阶段。M1 公共保护边界已完成软件实现，实板验证仍待后续功能固件一并烧录；本阶段不能关闭 M1 的待验项。

基线为 `develop / bbf917f81984cd35ad9f075d2d98f7cd981f9e90` 加工作区已有 M1 修改。开始前已在 `Tests/build/v1_m2/baseline/source/` 保存 178 个源码/工程/测试入口文件，并保存 `tracked-before.diff`；M2 差异应与该工作区基线比较，不能把 M1 改动计入 M2。

本阶段保持八个远端槽位、既有任务和静态容量。页面精简、二级导航、手动地址/信道及实验发送操作属于后续里程碑。所有软件验证与实板验证分别记录。

## 2. 实施任务与接口

### T01 解析与统计（A03/A04）

- 阅读随工程交付的 MAVLink helper，复位真实解析上下文，覆盖 LoRa 超时/串口恢复以及 RPi 初始化/波特率切换。
- CRC、解析拒绝、接收队列丢弃、链路序号缺口、DMA 覆盖分别计数，禁止将每字节输出字段误当累计计数相减。
- 保持原有每轮字节预算、静态队列和链路所有权，不增加解析任务。
- 回归：半帧后超时或重置、首个完整帧恢复、CRC 错误、噪声、连续有效帧及队列满。

### T02 新鲜度和身份（A05/A06/A07/A17、GNSS DMA）

- GNSS driver 和 Framework topic 分别增加位置、速度、UTC、高度有效位及四个更新时间；`last_rx_ms` 单独表示链路活动。GSA/GSV 不能为测量续期。
- Navigation 增加 `PX4LITE_NAV_VALID_TIME` 和真实姿态更新时间；Estimator、RTC 校时、App API、CSV 与 MAVLink TX 按字段域判断，未知速度使用协议哨兵。短 IMU 输入间隙保留尚新鲜的姿态，超时发布有效位撤销。
- Remote 增加导航子域有效/过期位及更新时间。GNSSUTC 仅更新时间域，BAROALT 仅更新高度，aggregate 标志不能授权所有字段。
- App 导航和环境复制仅暴露有效且新鲜的字段；温压、湿度、电池 1、电池 2 独立计时，电压/电流/电量分别判定。未知电流与有效零电流分开。
- 显示消费有效位，失效字段及其别名显示 `--`，有效恢复时重新绘制；失效姿态隐藏原画布，恢复复用。电池判断仅认对应电压有效位，不让粗粒度模块状态二次覆盖独立字段。
- 远端槽的查找、身份核验、复制及绑定在同一临界区内完成；淘汰使用无符号年龄。GNSS DMA 读取位置与更新环形队列使用保存/恢复 PRIMASK 的同一保护区。
- 回归：单域断流、零时刻、时间回绕、无 fix/空字段、GSV 持续但 GGA/RMC 停止、八槽换入第九节点及模拟竞争。

### T03 测量与采集（A08/A11/A12/A13）

- 横滚互补修正使用最短角差并归一化，覆盖双向跨 ±180°。
- 普通 ADC 采样保持模拟输入；浮空预充及调用由默认关闭的诊断开关完整门控。
- `Px4Lite_BaroRead(measurement, start_measurement)` 与 `Sensor_BME280_Service(now_ms, start_measurement)` 分离触发许可与状态推进。sensor 每轮推进，触发仍按 1000 ms；样本时间保守记录实际触发时刻。
- 删除 sensor 高优先级路径的临时电流打印，复用既有低优先级 Debug 电源快照日志及独立开关。
- 回归：角度跨界、ADC 引脚行为、BME 等待/完成/超时/回绕、触发周期和旧样本时间。

### T04 SD 与触摸恢复（A09/A10）

- SD open/header/seek/write/sync/close 失败进入统一降级出口：保留首因、关闭句柄、累计错误与写丢弃、2000 ms 退避重挂载。运行期 Recover 保留累计统计。
- 触摸输入设备仅在初始化注册一次。硬件恢复由显示任务推进静态状态机，将复位等待拆为非阻塞步骤；失败时返回 RELEASED，2 s 后重试。
- 显示主体保持可运行，触摸故障有独立状态，不因触摸缺席反复重建整个显示或陷入启动自检循环。
- 回归：文件各阶段注入失败、保留原始错误与计数、关闭/挂载边界；触摸缺席/出现、地址切换、等待边界、注册计数和无触点正常路径。

### T05 RemoteID 语义（A15/A16）

- LOCATION 时间使用有效 UTC 的小时内秒数；未知按仓库消息定义填写 65535。
- SYSTEM 时间转换为 2019-01-01 纪元秒数；没有有效时间时暂缓该消息，不以 uptime 代替。
- 水平速度使用北东分量模长，航迹使用 `atan2(east,north)`；按协议处理未知、静止和饱和，不能使用相对 yaw。本机没有可信垂直速度来源，该字段使用未知哨兵，不增加垂直融合。
- 回归采用真实 MAVLink 编码/解码：跨小时/午夜/闰日、纪元起点、速度与四象限航迹、极端分量和未知值。

## 3. 集成与验证顺序

1. 每组先建立可重复失败用例，再修改对应实现；host 断言使用 `Tests/stubs/assert.h` 的正常错误退出，避免 Windows CRT 弹窗。
2. T02、T03、T04/T05 分别实施，共享平台适配和测试入口由主代理串行整合。T05 依赖 T02 的时间/速度有效位合同。
3. 运行原有 17 组与新增定向回归，记录完整组名、编译和退出结果。测试替身不能作为真实总线时序证据。
4. 执行默认配置 Keil Rebuild All；核对工程配置未被工具意外改写，记录 Code/RO/RW/ZI、静态 SRAM 和产物 SHA-256。
5. 独立审查 M2 相对基线的差异，修复有证据的重要问题并重跑受影响验证；最终源码对应最后一次完整构建。
6. 更新 [M2 验证记录](V1.0_M2_验证记录.md) 和台账，区分软件完成、实板待验。无实板或长稳记录不宣布稳定版通过。

## 4. 后续统一实板验收

结合 M1 矩阵，至少覆盖 LoRa/RPi 半帧与重连、双链路并发、GNSS 单句型断流、跨 ±180°、ADC 无预充的电流读数、BME 更新间隔、SD 错误/拔插、触摸首次缺席后恢复、RemoteID 抓帧以及最重组合运行水位。记录同次固件身份、接线、设备型号和实测结果后再判定问题关闭。
