# CNS 箱 V1.0 硬件升级与外观设计方案

建立日期：2026-10-12  
版本：R1  
适用范围：首批 40 套 CNS 教学实验箱，约 40 天交付窗口  
进度入口：[V1.0 执行台账](V1.0_执行台账.md)  
发布计划：[V1.0 里程碑计划](V1.0_里程碑计划.md)

首批硬件采用统一的“固定底座＋可取放模块＋两端接插线缆”结构。底座固定在扩展板上，模块放回后稳定定位，拿起来活动时继续通过软线连接。IMU 与其他模块采用相同的取放结构，保留自身的轴向标识和安装方向要求。

V1.0 优先完成模块封装、底座、接口线束、蜂鸣器和交付标识；GNSS 按北征 BZ181 选样，兼容性验证后决定换装。每个模块的外壳本轮预留指示灯孔位，指示灯是否安装根据剩余工时决定。RGB 灯延期。

本文记录范围与设计要求。具体尺寸、连接器料号、GNSS 参数和蜂鸣器驱动电路在样件阶段冻结；任务状态和验证证据统一维护在执行台账。

## 3. 统一机械结构

### 3.1 底座与模块的关系

```text
机械连接：扩展板 → 螺钉固定底座 → 可取放模块
电气连接：扩展板插座 ↔ 配套软线 ↔ 模块插座
```

底座承担承托、定位和保持，线缆承担电气连接。首批底座采用机械配合结构；模块取下时，两端线缆仍可保持连接。

- 按扩展板现有可用孔位设计固定点，核对孔径、孔距、铜箔、器件和背面紧固空间；电气过孔是否可用于固定需实物确认。
- 用绝缘支撑控制安装高度，紧固件和模块壳体与电路保持明确间隙。
- 底座限制模块平移，并提供可释放的保持结构，避免线缆轻微牵拉使模块滑出。
- 留出手指取放空间、插头操作空间和线缆出口，模块放回时不夹线。
- 对有方向要求的模块设置明确定位方向；IMU 放回底座后方向可重复。

托座加限位边和可释放压扣可作为首个样件方案。底座可先打印验证；量产材料、卡扣形式及寿命要求根据实际取放测试和供应商工艺冻结。

### 3.2 外壳尺寸与风格

统一外观规则和模块与底座的配合规则，以共用模型生成各模块变体。实物测量后尽量收敛到少量尺寸规格，内部 PCB 支架、插座位置和功能开口分别适配。

- 外包壳体优先采用黑色铝合金，表面处理及色泽以加工样件确认。
- 统一圆角、紧固件、标签区域、接口区域和指示灯孔位风格。
- 内部用绝缘支架或螺柱固定 PCB，避免装配时直接挤压器件。
- 接口开口依据实际配套插头设计，包括插头外壳、锁扣、手指和线缆弯曲空间。
- 加工图随样件冻结，包含配合公差、孔位、表面处理和装配方向；供应商按该版本加工。

### 3.3 各模块的功能要求

| 模块或区域 | 需要保留的功能条件 |
|---|---|
| IMU | PCB 与小外壳作为整体运动；外壳前向、轴向、固件映射和上位机模型一致；接口避开主要握持区域 |
| GNSS | 陶瓷天线朝向保持正确，天线接收区域采用非金属盖板或窗口；用实际壳体验证接收表现 |
| 环境传感器 | 根据测量对象保留通气与环境接触条件，验证封装后温度、湿度或气压响应 |
| 无线通信模块 | 天线位置和接收区域按实际模块设计，封装后验证链路 |
| 各模块线缆 | 取下和放回均留有余量，插座固定可靠，拉力由壳体或支架承受 |

## 4. 插座与配套线束

两端插座的系列、针数和安装方向在样件阶段确定。JST 原厂 SH 为 1.0 mm 间距，GH 为 1.25 mm 间距并带锁扣；采购时以完整料号、配套插头和线束为准。GH1.25 是当前候选，尚未定型。[SH 规格](https://www.jst-mfg.com/product/pdf/eng/eSH.pdf)、[GH 规格](https://www.jst-mfg.com/product/pdf/eng/eGH.pdf)

模块侧优先评估以下转接路径：

```text
现有传感器 PCB／排针 → 内部短转接线 → 固定的接口小板 → 壳口插座
```

接口小板是否需要、能否共用以及如何固定，根据板卡和空间确定。仅当保留排针明显妨碍装配时，再评估拆焊或其他转接方式，并计入返工及检查工时。扩展板侧同步落实插座安装和与主板的电气连接。

定型时应给出每种配套线束的连接表，明确：

- 两端插座及插头料号、针数、针号观察方向和各端对应关系。
- 电源电压、地、信号定义、峰值电流和线规。
- 线长、插接方向、弯曲余量、固定点及两端标签。
- 外形相同但电气定义不同的接口采用的防误插措施。

优先采用预制或委托加工线束，样件通过后批量制作。可拆线缆用于连接和维修；带电插拔能力需另行核验，不能由插座可拔出推定。

当前工程 MPU6050 通过 I²C 采集，共享 I²C 配置为 100 kHz。活动线缆应结合实际长度、上拉电阻、总线电容和信号时序验证，并观察其他共享设备是否受影响。[I²C 规范](https://www.nxp.com/docs/en/user-guide/UM10204.pdf)

## 5. 模块指示灯预留

**本轮所有模块外壳预留指示灯孔位，实际安装为条件项。** 模型和加工图应包含孔位及内部安装空间，拟选 LED、灯座或导光件的尺寸先确定，再冻结孔径和位置。

- 孔位尽量位于放回底座后仍可见、手持时不易被遮挡的位置。
- 首批未安装指示灯时，用可拆黑色堵头封住孔位，便于后续安装。
- 内部预留灯体、限流电阻及短线空间，避免后续影响 PCB 固定、插头或底座配合。
- 已有板载电源灯可以作为复用候选，是否能够对应外壳孔位通过试装确认。

只有必做结构、电气样件和批量排期已稳定，且剩余工时能覆盖安装、检查与返工时，才加入电源指示灯。在批量装配前记录本批是否安装，保持交付配置可追溯。

加入时，LED 与限流电阻构成支路，并联在模块供电两端；电阻按实际供电电压和 LED 参数确定。电源灯表示供电存在，数据有效性继续由系统状态判断。

## 6. GNSS 升级

当前使用中科微 ATGM336H。目标候选为北征 BZ181 方块模块，希望减少外露天线布置并改善户外搜星体验；效果以对比实测为准。室内定位实验可考虑模拟器，模拟器不作为本轮硬件新增交付项。

当前工程 GNSS 使用 USART2、PA2／PA3、9600 8N1，并解析 NMEA 的 GGA、RMC、GSV、GSA。新模块的供电、波特率、输出协议和语句需逐项核验，不将候选模块默认配置视为现有固件兼容配置。

样件换装决定前应完成：

1. 确认实际 SKU、硬件版本、供电、接口针序和串口电平。
2. 确认所需 NMEA 输出、更新率、波特率及配置掉电保持；核对定位、时间、速度与卫星显示。
3. 在相同户外条件下记录启动条件、首次定位时间、连续数据和重新上电表现，与现用模块比较。
4. 用实际壳体、底座和整机布置验证天线朝向及金属结构对接收的影响。
5. 冻结线束和配套固件配置后再批量换装；未完成验证前保留现用方案。

产品资料入口：[BZ181 厂商资料](https://docs.speedybee.cn/fpv/gps/bz181-gps/bz181.html)。参数以本批样件和配置读回为准。

## 7. 蜂鸣器与固件接入

选样对象为用户确认的 Pixhawk 2.4.8 配套两线蜂鸣器。两根线只能确定接线形式，有源／无源、压电／电磁、额定电压、电流、极性和配套插头仍需确认。为了实现不同音高的提示音，采购目标为可用 PWM 驱动的无源款。[有源与无源蜂鸣器说明](https://ardupilot.org/copter/docs/common-buzzer.html)

```text
主板 PWM 输出 → 配套驱动转接板 → 两线插座 → 蜂鸣器
```

- 驱动电路根据实际蜂鸣器类型及电压设计，沿用成套插头和线束；样件验证后冻结。
- 使用独立定时器产生音调。当前代码未使用 PB9／TIM11，可作为候选，实际引出、复用和板上连接确认后才分配。
- 现有电机输出使用 TIM3／TIM4、50 Hz；蜂鸣器音调调整应与电机输出资源隔离。
- 蜂鸣器固定在箱体合适位置，留出声孔，并与 IMU 底座拉开距离；验证发声时的姿态数据。[安装说明](https://ardupilot.org/copter/docs/common-buzzer.html#mounting-the-buzzer)

固件采用非阻塞音符序列播放，由硬件产生音调、软件推进时长；业务调用不能阻塞采集、控制、显示或通信。复位和停止播放时输出处于静音状态。

首批提示音建议覆盖启动完成、实验开始或结束、操作拒绝、关键故障。具体触发条件、优先级、重复间隔、静音和恢复规则在实施前冻结，避免正常课堂操作持续鸣响。

实施时遵守工程分层和完整初始化要求，包含 BSP／平台适配、HAL 配置、Keil 源码列表、定时器和 GPIO 初始化及必要的调度集成。软件构建、提示音实测和对其他任务的影响分别验收。

## 8. 制作安排与工作量

下表为约 40 天窗口的目标安排，实际启动日、供应商周期和人员投入确认后调整。

| 目标窗口 | 主要工作 | 本阶段应形成的交付物 |
|---|---|---|
| D1—D7 | 盘点模块及孔位、确定接口候选、采购 GNSS 和蜂鸣器样件、建立共用模型并打印首个完整模块 | 模块清单、测量数据、候选连接表、首个取放样件及实际建模工时 |
| D8—D12 | 各模块试装、线束与驱动验证、加工询价和实际材料样件确认 | 冻结图纸与模型、样件结论、加工周期和装配安排 |
| D13—D28 | 按确认图纸加工，开展固件与上位机联调，验证完整一套装配 | 实际加工件、完整样机、问题闭环及每套装配工时 |
| D29—D40 | 完成批量装配、逐套检查、最终候选验收、长稳和返工 | 40 套配置及检查记录、配套交付包和剩余限制 |

加工前至少完成一套完整装配，记录各模块和每套整箱的实际工时。总数量按实际模块清单核算，并根据加工损耗和返工安排备件；不把 40 套整箱直接当作 40 个外壳或底座。

若同一人兼顾固件、建模和上位机，应尽早冻结共用结构和接口，把可交接的重复建模、加工、压接与装配工作明确分配。首批围绕已有实验闭环收敛上位机；模块指示灯依据剩余工时决定，RGB 留待后续。

阶段窗口不替代供应商周期承诺。加工延迟或验证失败时及时回填台账，不缩减最终候选验收和返工余量来维持表面进度。

## 9. 样件与交付检查

| 检查对象 | 验收内容 |
|---|---|
| 外壳与内部固定 | 装配完整、器件有间隙、绝缘可靠、接口可操作，指示灯预留孔及未装灯堵头落实 |
| 底座 | 固定点可靠，模块放回不滑动；取放、轻微线缆牵拉和重复操作后保持有效，方向可重复 |
| 两端插座与线束 | 针序、电压和标识一致；锁扣与固定可靠；活动及放回不夹线、不拉松，供电和通信正常 |
| IMU | 按外壳标识转动时，上位机姿态方向一致；手持活动、放回和静止时数据连续 |
| GNSS | 本批模块与固件兼容，配置保持有效，实际壳体和整机布置下接收通过；记录对比结果 |
| 蜂鸣器 | 提示含义与声音一致、静音有效、复位无意外持续鸣响；发声不破坏采集、显示和通信 |
| 可选电源灯 | 若安装，核验供电分支、亮度、可见性和固定；若未安装，记录配置并封好预留孔 |
| 整套交付 | 每套编号、模块与线束清单、硬件版本、固件与上位机版本、检查结果和返工闭环可追溯 |

硬件改动后的全机验收衔接 V1-M6，最终配套候选按 V1-M7 完成至少 24 小时长稳，交付资料与配置记录衔接 V1-M8。样件通过、批量逐套检查和最终候选长稳分别留证，详细记录关联执行台账。
