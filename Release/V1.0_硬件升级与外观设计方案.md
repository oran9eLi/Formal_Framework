## 1. 当前确定的版本边界

| 版本或事项 | 已确定范围 | 实施口径 |
|---|---|---|
| V1 | 现有 STM32F407 主板、现有模块和现有连接方式，组装一台完整设备 | 优先完成装配、接线修复、全功能联调、使用及展示流程 |
| V2 | 原 R2 硬件与外观升级：统一外壳/底座、可取放模块、两端插座与新线束、P25 Pro 候选换装、蜂鸣器等 | 保留候选与验证条件；罗盘和实际装灯继续为条件项，RGB 仍为后续候选 |
| H743 | V1 完成后再评估 | 未承诺引入，也未固定为 V2 或 V3 必做项 |
| 数量与时间 | 当前 V1 目标为一台完整设备 | 原 40 套、约 40 天不作为当前 V1 或 V2 交付承诺；V2 数量及排期重新评估 |

V1 不以新外壳、新底座、新接口、P25 Pro、罗盘或新增蜂鸣器/指示灯作为完成前提。现有功能和原有必需验收继续按里程碑与执行台账推进，延期的硬件升级不用于关闭既有缺陷。

## 2. V1 装配要求

- 使用现有主板、扩展板、传感器、通信模块、显示屏、电源及电机实验部件；先盘点实物型号、数量、可用状态和接线。
- 保留现有接口与连接体系，修复错接、松脱、接触不良及影响正常使用的线缆问题；完成必要的固定、绝缘、线缆整理和接口标识。
- 现有 GNSS 先完成正常使用验证，不将 P25 Pro 换装提前作为 V1 阻塞项。室内无有效定位时如实显示状态，定位能力在适合接收的实际环境下验证。
- 布置应便于操作触摸屏、观察数据、移动需要活动的模块及连接既有实验外设；活动后不得牵拉松脱其他接线。
- 一台交付设备不等于仅做单机验证。LoRa 收发、冲突及多节点场景配合现有对端或测试工装完成，记录实际节点和覆盖范围；工装无法覆盖的必需用例继续待验，不以单台目标免除验证。

具体尺寸与接线以现有实物为准。本次仅确认范围，未完成实物盘点、组装或可用性验证。

## 3. 完整使用与展示的验收内容

以下是 V1 整机验收清单，尚未表示任何项目已通过；逐项结果回填执行台账及相关验证记录。

| 验收对象 | 应形成的实际结果 |
|---|---|
| 上电、启动与自检 | 现有供电条件下可正常启动，模块与健康状态可信；故障和离线可见，重启后必要配置恢复正确 |
| 显示与触摸 | 页面、返回、开始/停止等已纳入操作可连续使用，状态与实际动作一致；未发现阻断使用的显示或交互问题 |
| 传感器与姿态 | 现有电源、环境、IMU 等数据可观察，单位/有效性明确；活动模块后方向、连续性及连接可靠性有记录 |
| GNSS | 现有模块的 NMEA、定位、时间及卫星信息按有效性显示；在适合接收的环境验证定位，室内未定位不伪装为有效数据 |
| LoRa 与协议观察 | 与既有对端完成配置、发送、接收、停止、断流和恢复；Inspector/NMEA 等观察功能按已纳入范围可操作，配置与 RF/多节点验收另留证 |
| RPi 与既有上位机 | 按现有接口完成数据观察及已纳入的 H1/B1、串口和 RemoteID 路径核对；屏幕、线帧和上位机结果能对应 |
| SD 与记录 | 已纳入的记录流程能够开始、停止和保存，文件可在电脑核对；异常、恢复和数据有效性按既有验收要求记录 |
| 电机与保护 | 完成既有无桨实验的目标设置、输出、停止及保护验证；PWM/目标值不表述为实测 RPM，页面切换不影响保护 |
| 教学观察操作 | 已纳入的曲线、统计、定位漂移等能完成开始—观察—比较—停止，缺测、暂停及重启语义正确 |
| 整机连续流程 | 同一装配和候选上完成上电—进入实验—操作—观察/记录—停止—异常恢复—重启的完整使用与展示流程，并保存结果 |

展示可按现有课程分段进行。涉及室外定位、通信对端或电机实验的部分，记录所需环境及配套设备，不能用预录或模拟结果代替规定的真实硬件验收。

## 4. 候选、验收与交付记录

1. 盘点并记录唯一示范机编号、主板/模块型号与版本、供电、接线表和装配照片，明确展示所需的现有对端及工装。
2. 绑定固件提交、候选与校验和、上位机/测试工具版本、Node ID 和信道；本轮不因文档范围确认而改变当前软件候选。
3. 修复装配及联调发现的问题，按原 M1—M5 待验项和 M6 全机矩阵逐项验证；记录实际结果与剩余限制。
4. 形成可以照着操作的完整使用与展示步骤，完成同机、同候选实操，保留关键观察、抓帧与记录文件。
5. 正式稳定版放行继续满足 M7 最终候选至少 24 小时长稳及 M8 文档/产物一致性要求。展示流程通过、构建通过和正式发布分别记录，不能相互替代。

当前目标不是批量生产。本阶段不安排统一壳体加工和 40 套装配；交付配置先围绕这一台设备冻结。
