# V1-M5 教学操作与诊断实施计划（草案）

> 执行者：按 superpowers:executing-plans 逐步实施，每步用复选框维护实际结果；本草案待设计评审，不把准备状态写为功能完成。

日期：2026-10-13；版本：R1；状态：待设计评审，未实施。

**目标：** 在现有教学数据和控制能力上增加可手动操作的轻量诊断、共享观察和数据记录。

**架构：** Framework 管理非消费型数据副本、捕获会话与资源事实，Driver 经 Adapter 提交原始字节和硬件事实。Business 经 App API 采样并统计；Display 复用固定控件，只显示模型和短操作反馈。storage 独占 CSV 入队、写卡和同步，不新增任务、UART、DMA或后台自动实验。

**技术栈：** STM32F407、HAL、FreeRTOS、ARMCC5.06/C99、LVGL、SSD1963/GT911、MAVLink、FatFs；唯一工程为 `MDK-ARM/formal_framework.uvprojx`。

**设计依据：** [M5 准备方案 R2](V1.0_M5_准备与设计方案.md)，含16组验收覆盖；[执行台账](V1.0_执行台账.md)是唯一状态入口。

**生产基线：** 已推送的 `06e6a211519e181627f798ef78497e6b15db763b` / `v1.0.0-pre.m4.20261013`；主SRAM121200 B，余9872 B。文档后续提交不改变该固件身份。M4-R02用户验证通过，前序其余必需验收保持待验证。

## 全局约束

- 沿用 `Core -> Business -> Framework -> Platform Adapter -> Driver -> BSP -> HAL`；Business读取只经 `app_data_api.h`。
- 不消费生产MAVLink队列或IMU FIFO；原始报文来自实际收发字节，不靠重编码生成Raw。
- 建议最多4个完整280 B帧、16个消息键、4句128 B NMEA；两种捕获共用互斥区。
- 建议共享观察两路64点，间隔200/500/1000 ms，默认200 ms；CSV间隔1/2/5/10 s，默认1 s。
- 静态SRAM新增≤5632 B，静态余量≥4096 B；heap_4峰值<75%；任务剩余栈>配置25%且≥100 word。
- 不增大既有40 KiB heap_4/40 KiB LVGL堆，不新增切页控件池，不在启动后分配RTOS内存；DMA留在主SRAM。
- 触摸优先，每10 ms服务；Raw/数据/曲线≤5 Hz，汇总/资源≤1 Hz；完整显示单步预算2000 us，实际超限不得标通过。
- 启动Stopped/Paused；新实验由学生开始；不恢复曲线、参考点、记录或旧电机目标。控制保护不因诊断、Freeze或切页暂停。
- D10已采用：GNSS/IMU/Baro周期打印改0，启动保持1，异常与屏幕观察/资源统计继续可用，派生宏不手改。
- 新源码/公开接口使用中文Doxygen；新增源加入uvprojx，固件步骤结束须Keil Rebuild All达到0 Error(s), 0 Warning(s)。

上述容量、状态表和运行门限是待评审建议，D10及已确认的增强范围除外。经授权的行为验证、实板、资源/时序和长稳证据分别记录；本准备阶段没有新增或运行测试。

## 评审重点

| 风险 / 输入 | 预期处理 | 所属步骤 / 验收 |
|---|---|---|
| 单缓冲LVGL同步刷新、一轮多条带 | 计时完整服务；禁止把延迟flush_ready当可跨次续刷；分步方案须覆盖缓冲生命周期 | P01；C13/C14/C15 |
