# M3：教学操作可理解——软件验证记录

日期：2026-09-16；分支：`release/v1.0`；前置提交：`a1a4ade`（M2）。

## 结果与范围

M3 把姿态、通信和无桨电机实验中的关键状态放到学生可见界面，并将需要理解的选择留给学生操作。本记录只证明代码回归、工程编译和静态资源预算通过；屏幕观感、触摸命中、实物传感器、ESC 和双机链路仍须在 M4 实板验收。

- 电机页改为“电机实验”，操作使用“同步升速、缓降停机、本机急停”。
- 四路电机同时显示学生设定、控制器实际输出和最终 PWM 脉宽；页面显示直控/姿态辅助及停止、ESC 准备、手动运行、同步升速、缓降、动力闭锁等阶段。
- 默认模式改为直控。同步升速和缓降只改变四路目标，不替学生切换模式；姿态辅助必须由学生点击选择。
- 姿态页分开提供“校准零偏、设为零位、恢复基准”，并显示等待放稳、采集进度、成功和失败原因。yaw 明确标为“相对偏航”。
- 远端节点列表在节点集合不变时原位更新 RX/Loss；只有节点上下线或状态变化才重建页面。
- 远端视图继续只读；学生设定显示 `--`，控制模式、过程状态显示“远端未上报/远端状态”，不把现有协议中的最终输出冒充未传输的状态。

课堂步骤和预期反馈见 [v1.0 课堂实验台操作说明](../Development_Guide/2026-09-16_v1.0课堂实验台操作说明.md)。

## 回归证据

入口：`Tests/run_tests.sh`（Git Bash + GCC 16.1.0）。结果：**11 组通过**。

| 测试范围 | 主要验证 |
|---|---|
| control | 默认直控；辅助模式显式选择；同步升速/缓降保持学生选择；目标、实际输出、PWM 和运行阶段一致 |
| display | 本地校准动作和模式选择透传；远端拒绝；目标/输出/脉宽分离；姿态过程状态映射 |
| 既有 9 组 | 电源、IMU 映射、命令事务、告警、姿态测量/操作、估计、相对基准和存储回归 |

“同步升速/缓降不得自动打开姿态辅助”的断言在修改前实际失败，移除隐式切换后通过。测试使用硬件桩，不证明真实触摸、ESC 脉宽或电机转速。

独立代码复核最初发现 3 个 Important：ESC 准备阶段把目标显示成实际输出、远端电机快照失效后模式/阶段残留、反馈文案缺少“受/功”字模。三项均已修复并复核关闭，未发现新的 Critical/Important。仍有 1 个 Minor：PC 测试未直接执行 LVGL 的远端 RX/Loss 原位刷新路径，M4 必须用实屏覆盖。

## 交互口径

1. “设”是学生给控制器的基础目标；“出”是控制器加入当前逻辑后的输出命令；`us` 是写给 ESC 的 PWM 脉宽。三者不能表述成实测转速。
2. 姿态辅助是显式教学选择。直控便于观察输入输出，姿态辅助便于比较闭环修正；安全闭锁和急停在两种模式下都有效。
3. 零偏校准要求设备放稳并持续采样；“请求已接受”不等于成功，必须等到成功或失败状态。相对零位只改变本机显示参考，重启后清除。
4. 当前 yaw 来自陀螺积分，是相对偏航，没有磁力计/GNSS 绝对航向，静止漂移属于 M4 要记录的实际限制。
5. 命令拒绝原因继续进入页面消息日志，例如动力不足、传感器未就绪或缓降中拒绝非零油门。

- 记录任务最小剩余栈、FreeRTOS 堆、LVGL 内存/碎片和长时间重复操作结果。
