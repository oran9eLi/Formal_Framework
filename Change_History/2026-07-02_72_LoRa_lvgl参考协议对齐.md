# 2026-07-02 LoRa lvgl 参考协议对齐

## 背景

两块板分别烧录为 `DCDW-001` / `DCDW-002` 后，界面发送计数持续增加但远端状态仍不同步。复核 `W:\WORK\Project\ff613\Formal_Framework13\Formal_Framework\lvgl` 后确认，参考工程不使用按本机编号强制静默的固定 TX slot，而是使用 MAVLink catalog round-robin 调度和 LoRa BUSY retry。

## 改动

- 取消 `PX4LITE_MAVLINK_TX_SLOT_MS` / `PX4LITE_MAVLINK_TX_SLOT_COUNT` 和 `MavTx_InOwnTransmitSlot()`，发送恢复为参考工程的 round-robin catalog。
- LoRa 教学链路周期对齐参考工程：姿态/位置 500 ms，电机 500 ms，模块状态/告警摘要 700 ms，电池/气压/湿度/SYS_STATUS/GNSS 1000 ms，retry 50 ms。
- `LOGSYNC` 暂时关闭，避免消息日志抢占姿态、模块状态、告警、电机、湿度等核心显示数据。
- 湿度帧名从 `ENVHUM` 改为参考工程的 `HUMIDITY`；接收端继续兼容 `ENVHUM`。
- 模块状态发送从 `MODSTAT0` / `MODSTAT1` 改为参考工程单帧 `MODSTAT`，包含 GNSS、IMU、BARO、5G、STORAGE、CONTROL 和 system_ready；接收端继续兼容旧分片。
- 电机帧 `MOTOR12` / `MOTOR34` 位布局对齐参考工程：`duty0 | duty1<<8 | run_state<<16 | speed_level<<24`。
- `ALRMHI` 只携带 `fault_code/source/severity`，告警数量以 `ALRMMSK` 位图为准，避免高 4 bit 被误判为 active_count。

## 栈和内存

- 未新增 FreeRTOS task。
- 未扩大 `PX4LITE_STACK_COMM` 或其他任务栈。
- 新增接收解析只使用局部标量和既有远端 telemetry 槽位，不在 comm 栈上放大 payload 或整表快照。
