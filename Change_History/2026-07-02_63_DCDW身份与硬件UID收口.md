# 2026-07-02 DCDW 身份与硬件 UID 收口

## 背景

当前教学和后续 5G/RemoteID 接入不再需要主机/从机人工身份。设备对外统一显示 `DCDW-001` 这类编号，5G 和后续云端绑定使用 STM32 硬件唯一 UID 区分真实设备。

## 改动

- `px4lite_config.h` 删除 `PX4LITE_BOARD_UNIT_ID`、`PX4LITE_PAIR_MASTER_ID` 和主从角色派生，唯一人工配置改为 `PX4LITE_DEVICE_NAME`。
- `px4lite_identity` 从 `PX4LITE_DEVICE_NAME` 的后三位数字派生 LoRa node id 和 MAVLink system id。
- `app_data_api` 和 `px4lite_remote_telemetry` 删除主从角色过滤，远端选择只过滤本机 DCDW 后缀对应节点。
- `px4lite_platform_f407.c` 增加 `Px4Lite_PlatformGetHardwareUid()`，通过 HAL 读取 STM32 96-bit UID。
- `px4lite_remoteid_tx.c` 使用 DCDW 名称作为 RemoteID UAS ID / Self ID，并把 STM32 UID 填入 OpenDroneID `id_or_mac`。

## 栈和 RAM

- 未新增任务，未扩大任何任务栈。
- UID 读取只复制 3 个 32 位 word。
- RemoteID 仍使用文件级静态 MAVLink message/frame/字段缓存。

## 验证

- Keil Rebuild All：通过。
- Program Size: `Code=265296 RO-data=91352 RW-data=1328 ZI-data=97680`
- 结果：`0 Error(s), 0 Warning(s)`
