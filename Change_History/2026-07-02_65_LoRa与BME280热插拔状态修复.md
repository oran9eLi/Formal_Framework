# 2026-07-02 LoRa 与 BME280 热插拔状态修复

## 背景

台架测试发现 LoRa 未与对端连上时仍显示绿色，拔掉 LoRa 后显示黄色；BME280 气压计拔掉后变红，但插回后不能稳定恢复绿色。复查确认 LoRa 驱动把 E22 AUX 空闲事实直接当作对端链路 ONLINE 证据，BME280 连续读失败后的重初始化请求不够直接。

## 修改

- LoRa 状态判定拆分为本机硬件 presence 和对端链路 freshness：E22 AUX 长期不可用或初始化 AUX 超时进入本机离线红灯；本机存在但没有最近合法 MAVLink RX 时进入链路降级黄灯；最近收到对端合法 MAVLink 帧才显示绿色。
- LoRa 初始化保持非阻塞：AUX 短时间未就绪先返回 `BUSY` 并保留 re-init 请求，超过初始化窗口后返回 I/O 错误，由 Framework 状态和恢复链路处理。
- BME280 连续读失败达到阈值后立即安排重新初始化，并清除初始化 backoff；Health recovery 触发的 `Sensor_BME280_RequestReinit()` 也会清除 backoff，插回后由 sensor task 执行 I2C recover 和 BME280 init。
- 同步更新 `Development_Guide/02_架构边界与数据流.md` 中 LoRa E22 re-init 的状态语义。
