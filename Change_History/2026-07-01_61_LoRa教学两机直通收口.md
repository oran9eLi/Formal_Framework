# 2026-07-01 LoRa 教学两机直通收口

## 背景

教学现场优先需要两块板通过 LoRa 互发数据、观察调试计数和丢包率，不再以多从机远端查看、stream lease 或 REMOTE_* 中继作为 LoRa 默认路线。

## 改动

- `px4lite_config.h`：LoRa/MAVLink 默认切到 `PX4LITE_MAVLINK_LINK_MODE_GCS`，关闭节点 poll 和 REMOTE_STATUS / REMOTE_MOTOR / REMOTE_ALARM / REMOTE_LOG。
- `px4lite_config.h`：遥测周期对齐参考 `Formal_Framework/lora`，心跳 1 s、姿态 500 ms、位置 500 ms、状态/电源/气压/湿度 1 s、STATUSTEXT 2 s、重试 50 ms。
- `lora_e22.c`：LoRa 模块 ONLINE 改为本机 E22 初始化且 AUX 近期就绪；对端 RX 新鲜度仅作为通信调试统计。
- `px4lite_mavlink_rx.c`：教学模式下不再按远端查看租约过滤完整 MAVLink 数据。
- `px4lite_mavlink_tx.c`：教学模式下不发送 LORASUM，旧远端查看接口不再发 stream start/stop，收到旧 stream 控制命令保持兼容 ACK 但不改变发送门控。
- `px4lite_platform_f407.c` / `px4lite_modules.c`：LoRa 初始化遇到 AUX 未就绪时返回 BUSY、保持 STARTING 并由 comm 任务重试，MAVLink TX 调度器先完成初始化。

## 边界

- 架构分层不变：LoRa Driver 只做帧事实和统计，MAVLink TX/RX 负责编解码，Business/Display 继续通过 App API 读取数据。
- RemoteID UART4 链路本次不关闭，它与 LoRa 空口独立；本次只放弃 LoRa 上的远端查看主路线。
- 未扩大任务栈，新增逻辑只使用已有文件级静态状态。

## 验证

- Keil Rebuild All：`0 Error(s), 0 Warning(s)`。
- Program Size：`Code=269084 RO-data=91608 RW-data=1368 ZI-data=103072`。
- 需要双板实机验证：不同 `PX4LITE_BOARD_UNIT_ID` 烧录后，TX/RX 计数递增、丢包率稳定、姿态/环境/电源字段互通，E22 拔插后可恢复。
