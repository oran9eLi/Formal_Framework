# 2026-07-03 LoRa 教学版红绿灯与只收开关

## 背景

- 当前教学目标改为：学生只需要把两块板的 E22 LoRa 参数调成一致，即可验证通信收发和远端数据显示。
- 旧 VIEW 租约、TDMA 时隙、主从角色和命令握手会增加调试复杂度，不适合作为当前教学基线。

## 代码调整

- `Driver/Comm/Src/lora_e22.c`：`Lora_E22_GetState()` 不再用对端 RX 超时判断本机 LoRa 在线状态；本机 E22 初始化完成且 AUX/USART/DMA 可用即返回 ONLINE。
- `Framework/Src/px4lite_modules.c`：LoRa 模块灯色改为本机硬件红/绿语义。拔掉或初始化失败为 OFFLINE/红灯，插上且服务健康为 ONLINE/绿灯；对端数据新鲜度只进入远端遥测。
- `Framework/Src/px4lite_mavlink_tx.c`：移除 VIEW 租约运行路径和遥测发送门控，新增 `Px4Lite_MavlinkSetTxEnabled()` / `Px4Lite_MavlinkGetTxEnabled()`。TX 关闭时本机只收不发；TX 开启时按原 MAVLink catalog 发送姿态、状态、环境、告警、电机等分项遥测。
- `Business/Src/app_data_api.c` 与 `Display/Src/display_lvgl.c`：进入远端列表或选择远端节点时关闭本机 MAVLink TX，返回本地时恢复 TX。
- `Framework/Src/px4lite_command.c`：当前教学链路不再消费 VIEW_REQ/VIEW_STOP 命令，COMMAND_LONG 统一通过命令执行器返回 unsupported。
- `Framework/Inc/px4lite_config.h`：心跳周期恢复为固定 1000 ms，移除 TDMA/VIEW 租约配置宏。

## 丢包率口径

- 发送方只负责正常发送 MAVLink 帧；MAVLink header `seq` 即发送帧编号。
- 丢包率必须在接收侧计算：LoRa Driver 和 Framework MAVLink RX 按 `system_id + seq` 跳号统计 `rx_sequence_lost_count`，并输出 `rx_loss_rate_x10`。
- TX 计数只说明本机已把帧提交给 E22，不证明对端收到。
