# 2026-07-02 MPU6050 掉线恢复收口

## 背景

台架测试发现 MPU6050 可能反复掉线，表现为姿态数据消失或需要拔插后才恢复。代码复查确认主要风险来自 IMU OFFLINE 判定窗口过紧，以及驱动只把寄存器读取失败计入自动重初始化门限，未覆盖全零帧、超范围帧和尖峰帧。

## 修改

- 将 `PX4LITE_IMU_OFFLINE_MS` 从 500 ms 调整为 2000 ms，避免 I2C recover、MPU6050 re-init 和 3 帧稳定门控期间被 Health 过早判为 OFFLINE。
- MPU6050 驱动新增坏样本重初始化计数口径：连续读失败、全零帧、超范围帧和尖峰帧达到 5 次后，由 sensor task 执行 I2C 恢复和 MPU6050 重新初始化。
- MPU6050 重新初始化成功后清理 `s_next_init_ms` 和 `s_reinit_request`，避免旧重试状态残留。
- IMU debug 输出补充驱动阶段、驱动返回值、重初始化次数、最近芯片 ID 和 BSP I2C 状态，便于现场区分真实掉线、坏样本和总线错误。
- 同步更新 `Development_Guide/02_架构边界与数据流.md` 和 `Development_Guide/04_调试验证与发布门禁.md`。
