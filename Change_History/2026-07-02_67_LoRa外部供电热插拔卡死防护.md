# 2026-07-02 LoRa 外部供电热插拔卡死防护

## 背景

台架测试反馈 LoRa 已改为外部供电，但连接 LoRa 后系统仍会卡死。复查 USART3 RX 路径确认：外部供电热插拔、未共地、地弹或电平异常会让 USART3 产生 FE/NE/ORE/PE 错误。原中断路径在错误分支仍调用 `HAL_UART_IRQHandler()`，持续错误时可能形成高频中断，表现为系统卡住。

## 修改

- USART3 错误中断改为 LoRa BSP 专用轻量处理：ISR 中只记录 SR、清除错误标志、关闭 LoRa UART 错误/IDLE 中断并置位恢复请求。
- LoRa RX DMA 恢复仍由 `comm` task 执行，恢复时重新启动 DMA、关闭 RX DMA half-transfer 中断，并重新打开 USART3 错误/IDLE 中断。
- LoRa RX DMA 初始化后关闭 half-transfer 中断，减少无业务意义的中断负载。
- 同步更新 `Development_Guide/02_架构边界与数据流.md`：LoRa 外部供电必须共地，USART3 信号必须为 3.3V TTL，ISR 不得执行完整恢复。

## 验证

- Keil MDK-ARM Rebuild All 通过：`.\Objects\formal_framework.axf - 0 Error(s), 0 Warning(s)`。
- 构建大小：`Code=266184 RO-data=91648 RW-data=1340 ZI-data=97684`。

## 现场注意

如果本次软件防护后连接 LoRa 仍立即卡死，优先按硬件问题处理：确认外部电源 GND 与 STM32 GND 共地；确认 E22 的 TXD/AUX 输出不超过 3.3V；确认 M0/M1/AUX/TXD/RXD 未接反；确认外部电源上电顺序不会通过信号线反向给 STM32 供电。
