# 2026-07-02 LoRa 显示数据同步收口

## 背景

实机表现为两板 LoRa 已能发现对端，但远端显示页仍有关键数据不同步：姿态无数据、消息日志不同步、警告不同步、油门/电机状态不同步。

## 改动

- 远端姿态显示不再被陈旧的远端 MODSTAT 强制清空；只要收到合法 ATTITUDE 且未过期，`App_CopyRemoteDisplaySnapshot()` 就允许显示姿态。
- MAVLink TX 增加 `MOTORPWM` 分项，按固定周期发送 4 路电机占空比、run state 和 speed level；RX 解码后写入远端遥测槽位并映射到 Display 快照。
- MAVLink TX 增加 `LOGSYNC` 分项，每帧同步一条本机结构化消息日志；RX 解码后写入远端固定日志缓存，`App_CopyRemoteMessageLog()` 不再是空实现。
- 告警同步继续使用 `STATUSTEXT`，当告警序号变化但没有活动告警时也发送 clear 帧，接收侧按文本解析模块来源并在 App 层合成远端告警行。
- `Px4Lite_RemoteTelemetry_t` 增加 MOTOR/LOG 有效位和静态有界缓存；未新增任务，未扩大 `PX4LITE_STACK_COMM` 或其他任务栈。

## 栈和内存

- 本次没有新增 FreeRTOS task，没有扩大任何任务栈。
- 新增远端日志/电机字段为远端遥测表内静态有界存储，Keil Rebuild 后 ZI-data 为 `100816`，相比上一轮 LoRa 状态收口约增加 3.1KB，仍低于近期从机 SRAM 收口前风险水位。
