## 事实边界

静态复核不表示原生 DRC/ERC、生产、线束导通、供电或整机功能验收已通过。目标导通表需要逐条实测。

- 蜂鸣器正端使用 `5V-BEC`，RGB与电平转换器使用 `5V-407`；两路电源不是同一网络。PE5经驱动电路控制蜂鸣器，PC9为RGB数据。
- PE5/TIM9一次经典启动音已有固件候选；外接HW-508模块试听反馈良好，扩展板本体仍需供电和实测确认。PC9的RGB驱动尚未实现。
- 当前GM v1.0电流计模拟输出最高5V，ADC按约3.3V参考域工作；扩展板现有直连模拟信号路径不提供5V转3.3V适配。不得直接连接5V满量程信号；硬件分压/标定或更换兼容电流计仍待处理。
- 2026-11-03现场屏幕能显示但触摸失效，GT911诊断`err=65`；根因尚未确定。断开扩展板和回刷旧版后故障仍在，不能据此直接认定某器件损坏。

上述事项的后续进度统一维护到 `Release/V1.0_执行台账.md`，不能从旧复核报告中的驱动状态推断当前代码。
